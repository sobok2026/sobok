# 첫 플레이 버전의 구현 규칙

사용자는 2026-09-23에 제공 자료의 공개 사용과 미확인 절차의 임시 게임 규칙 적용을 허용했다. 이 문서는 실제 자료에서 가져온 부분과 플레이를 위해 정한 값을 구분한다.

## 자료

`apps/cafe/references/`의 다음 파일을 레포 루트에서 `bun run --filter=@sobok/cafe import:references`로 읽는다. 원본은 수정하지 않는다. 일반 빌드는 이미 생성된 JSON을 사용하므로 원본 엑셀이 없어도 동작한다.

| 파일                         | 사용 시트                 |
| ---------------------------- | ------------------------- |
| `26_pre-autumn_recipes.xlsx` | 음료 제조, 폼·베이스 제조 |
| `best_by_core.xlsx`          | 제조 베이스, 코어 원재료  |
| `best_by_special.xlsx`       | 특화 원재료               |
| `ingredient_prep_guide.xlsx` | 부재료 제조               |

변환 결과에는 14개 음료 형태, 6개 준비 배합, 170개 품질 기준행, 14개 준비 가이드행과 원본 해시가 있다. 행 수는 고유 SKU 개수와 다르다. 메뉴명·공통 배합 조건만 해당 묶음 안에서 이어 읽는다. 수량·단위의 빈칸은 0이나 이전 행의 값으로 채우지 않는다.

초기 메뉴의 제조 단계·순서·설명·주의사항은 변환한 레시피에서 읽는다. 새 자료에서 단계 수나 의미가 바뀌면 작업대 연결과 재고 차감도 함께 검토한다. 품질 기준 연결은 아래의 초기 재료를 기준으로 한다.

`reference-links.ts`는 메뉴명·HOT/ICED·배합 이름과 단계 의미를 유일하게 찾아 단위·수량·순서를 검사한다. 배열과 물리적인 행 위치가 바뀌어도 같은 항목을 사용한다. 실제 제조 순서가 바뀌거나 항목이 누락·중복되면 자동으로 다른 단계에 연결하지 않고 확인할 자료를 표시한다. 가져오기는 열 제목도 확인하며, 모든 검사와 포맷을 마친 뒤 생성 JSON을 교체한다. `check:references`는 개발 시작·빌드에서도 실행한다.

샷·펌프·드리즐·토핑 수량과 펌프당 ml는 각 음료의 Tall 행을 사용한다. 폼의 크림·우유·펌프와 블렌딩 시간, 바모카의 봉·온수 L, 콜드 브루의 추출 시간도 해당 준비 자료에서 읽는다. 보관·품질 기한은 초기 재료 8개의 이름과 개봉·소분·제조 조건으로 연결한다. 바모카와 콜드 브루는 준비 자료의 보관·기한을 품질 표와 대조한다. 아래 행 번호는 현재 원본의 위치이며 코드의 조회 키로 사용하지 않는다.

| 재료               | 자료 근거                                                            |
| ------------------ | -------------------------------------------------------------------- |
| 원두               | core / 제조 베이스 13행                                              |
| 우유·휘핑크림      | core / 코어 원재료 23행·22행                                         |
| 글레이즈드 소스    | special / 특화 원재료 72행                                           |
| 번트 카라멜 파우더 | special / 특화 원재료 51행의 소분후 기준                             |
| 바모카             | prep / 부재료 제조 13행, core / 제조 베이스 20행, 사용자 동일성 확인 |
| 글레이즈드 폼      | recipes / 폼·베이스 제조 7~10행                                      |
| 콜드 브루          | recipes / 폼·베이스 제조 24~26행, core / 제조 베이스 11행            |

바모카 **원팩**은 준비 가이드의 봉 단위만 근거로 삼는다. 게임의 개봉 후 7일은 직접 대응하는 품질 기준이 없는 임시값이며, 제조한 **바모카 배합**의 24시간과 구분한다. 번트 카라멜 파우더는 소분후 7일, 글레이즈드 소스는 개봉후 3일을 선택한다. 2026-09-24 사용자는 모든 ‘N일’ 기한에 시작일 포함 N일의 마지막 날 종료 기준을 적용하도록 결정했다. 예를 들어 9월 1일 15시에 개봉한 우유는 9월 3일 0시에 만료된다. 24시간 기한인 휘핑크림은 같은 조건에서 9월 2일 15시에 만료된다.

레시피의 Tall 폼 50ml는 텀블러 계량값이다. 현재 일회용 컵 기준선의 재고 차감은 기존 추정치 45ml를 유지한다. 폼 450ml·바모카 1500ml·콜드 브루 3000ml 수율과 샷당 원두 9g, 원팩 크기·가격도 자료 갱신만으로 실제 규격이라고 간주하지 않는다.

## 직접 제조

직원은 카운터 안쪽 타일 통로에서 시작한다. 제조대·POS·픽업대는 직원 쪽 접근을 확인한 뒤 상호작용을 허용한다. 준비·세척·도구 정리·재고 관리도 안쪽에서 수행한다. POS 옆 직원 출입구로 나가면 객석 청소와 분리수거를 할 수 있다. 손님의 대기 위치와 객석은 카운터 바깥에 둔다.

E로 컵을 집거나 작업대에 내려놓고, G로 해당 단계의 도구를 집거나 놓는다. 클릭 또는 Space를 유지하면 붓기·젓기가 진행되고, 펌프·얼음·파우더는 한 번 누를 때마다 한 회를 더한다. 목표량에 도달하면 도구를 놓고 F로 확인한다. 완성된 컵은 픽업대에 놓고 F로 전달한다. 다음 단계가 같은 작업대면 그대로 이어서 작업한다.

근무 시작·재개 후에는 마우스 버튼을 누르지 않아도 시점이 움직인다. 컵을 내려놓거나 부재료 준비·세척을 시작하면 시점이 작업물을 향하고 마우스 커서가 풀려 HUD의 버튼을 사용할 수 있다. WASD 이동, 컵·피처 집기, 작업 종료 후에는 다시 마우스로 시점을 조작한다. 작업대에 컵·준비 배합·세척 작업이 남아 있다는 이유로 시점 복귀를 막지 않는다. 준비·세척 작업대를 다시 바라보고 E를 누르면 커서 조작으로 전환한다. 오류가 난 컵은 화면 버튼 또는 F로 폐기한다.

화면 하단에 실제 입력 모드를 표시한다. 브라우저에서 마우스 고정을 허용하지 않으면 드래그·방향키 시점을 안내한다. 입력 모드는 저장 데이터에 넣지 않는다.

HOT은 피처에 우유를 직접 계량한 뒤 스팀을 시작한다. 스팀 피처는 우유를 컵에 붓거나 컵을 폐기할 때 세척 대상으로 보낸다. ICED는 샷 글라스에 추출한 뒤 혼합대에서 직접 컵에 이관하고 젓는다. 샷 글라스는 컵과 함께 운반되는 것으로 단순화한다. 스팀 우유는 이미 계량한 피처 잔량까지만 붓고, 젓기·샷 이관은 완료 시 자동 정지한다.

재료는 실제 입력 진행량에 비례해 차감한다. 펌프·얼음·토핑은 클릭한 횟수를 반영한다. 허용량 초과는 컵의 오류·작업대 오염으로 기록되고 재제조해야 한다. 이미 투입한 재료는 폐기하거나 저장을 다시 불러와도 자동으로 반환되지 않는다. 화면의 컵 높이·액체 층은 진행 상태를 표현하는 비율이며 실제 ml 눈금이 아니다.

이동·시선 이탈·입력 해제·일시정지·창 포커스 이탈은 연속 투입을 멈춘다. 장비 작업 중에는 컵 이동을 막는다. 도구를 든 상태에서는 컵을 집을 수 없다. 폼·드리즐 보틀·머들러·스쿱 등의 개별 세척은 아직 단순화하고, 피처와 준비 배합 도구만 기존 세척·선반 정리 흐름에 연결한다.

세척이 끝나면 선반에서 정리해야 피처를 다시 사용할 수 있다. 준비 배합 역시 깨끗한 피처를 소모한다. 작업대의 동시 작업과 제조 중인 컵의 중복 작업을 막는다.

피처 한 개를 세척대에 놓으면 세척 대기 수량에서 분리한다. G로 스펀지를 집고 누르며 문지른 뒤 스펀지를 놓고 F로 헹구기를 선택한다. 누르는 동안 헹구고 F로 완료를 확인한다. 씻은 피처는 E로 집어 도구 선반에 E로 놓아야 깨끗한 도구 수에 포함한다. 피처를 들고 다른 제조 도구를 동시에 사용할 수 없다.

문지르기·헹구기는 손을 떼거나 이동·일시정지하면 멈추며 저장 후 이어진다. 세척 취소는 피처를 오염된 대기 수량으로 돌려놓고 진행량을 지운다. 이미 씻었거나 들고 있는 피처를 세척대에 놓으면 세척 완료 수량으로 유지한다. 테이블·작업대 청소와 쓰레기 정리도 아래의 직접 조작 흐름을 사용한다.

컵이 있는 작업대에서는 컵 조작을 우선한다. 다른 작업대에 컵을 두면 혼합 작업대의 청소 메뉴를 열 수 있다. 부재료 준비나 피처 세척 전에 컵을 내려놓아야 하는 경우 다음 업무 안내에 선행 행동을 표시한다.

잘못된 주문 입력은 전달 시 손님의 원래 요청과 대조해 알려준다. 재제조 시 이미 쓴 재료와 컵은 복구하지 않는다. 주문을 전달해야 판매 기록과 운영비가 증가한다.

## 첫 근무 안내와 작업음

첫 콜드 브루와 첫 HOT 라떼에서는 현재 작업 옆에 짧은 안내를 표시한다. 도구를 집고 놓는 순서, 부족한 재료의 개봉·준비·라벨·보관, 컵·피처 운반과 정리할 일을 현재 상태에서 계산한다. H로 숨기거나 다시 볼 수 있으며 첫 두 잔 전달 후에는 자동으로 접힌다. 이후 다시 열면 복습 안내로 사용한다. 안내는 업무를 잠그거나 재료·돈·작업 진행을 바꾸지 않는다.

작업음은 기본 음소거이고 기본 음량은 35%다. 상단 버튼이나 Esc 메뉴에서 켜고 0~100%로 조절하거나 미리 들을 수 있다. 사용자 요청에 따라 물·식기·유리·종·마찰 녹음을 가공해 컵·얼음·붓기·스팀·세척과 계량 확인·완료·전달을 구분한다. 사용자 요청에 따라 펌프·오류의 스위치 찰칵음은 제거했다. 특정 카페나 장비의 실제 녹음 재현은 아니며 [음원 크레딧](../../apps/cafe/public/audio/CREDITS.md)에 원본·라이선스·가공 내용을 기록한다.

연속 작업음은 실제 입력과 가까운 장비의 작동 상태를 따른다. 손을 떼면 붓기·닦기 소리가 멈추며, 일시정지·백그라운드·창 포커스 이탈·음소거 시 재생 중인 소리를 중단한다. 백업·자동 저장을 불러왔다고 지난 완료 알림을 다시 재생하지 않는다. 음소거·안내 표시·음량은 같은 브라우저의 별도 설정으로 저장하고 게임 백업에는 포함하지 않는다. 게임 저장 형식은 바꾸지 않으며, 소리를 끄거나 재생에 실패해도 화면 게이지·완료·오류 안내를 통해 진행할 수 있다.

## 부재료와 라벨

글레이즈드 폼 기본 배합은 원본의 200ml 휘핑크림 → 50ml 우유 → 글레이즈드 소스 7펌프(펌프당 10.2ml) → 3번 버튼 1회(약 25초)를 읽어 직접 조작에 연결한다. 바모카는 준비 가이드의 원팩 1봉·온수 1L를 읽고, 6초간 젓는 게임용 단계를 적용한다. 액체 허용 구간은 음료와 같은 게임용 ±6%이며 펌프·원팩은 정확한 횟수가 필요하다. 온수 공급은 기존 물 규칙처럼 제한하지 않는다.

준비대에 피처를 놓으면 깨끗한 도구 한 개를 예약한다. 실제 투입량만큼 재고를 차감하고, 혼합 완료 또는 배합 폐기 시 피처를 세척 대상으로 보낸다. 음료 컵이나 다른 도구를 든 상태에서는 준비를 시작할 수 없지만, 컵을 바에 두면 주문 도중 필요한 부재료를 만들 수 있다. 계량 중 다른 일을 하거나 저장을 불러와도 투입량이 유지된다.

완성된 배합은 준비대에 보관 대기 배치로 생긴다. 개봉·제조 시각, 품질 기한과 보관 조건을 확인해 라벨을 붙이고 E로 집는다. 폼은 냉장고, 바모카는 실온 선반까지 직접 운반해 E로 보관한다. 원래 작업대에 E로 다시 내려놓을 수 있으며 잘못된 보관 장소는 거부한다. 이동은 같은 배치의 위치만 바꾸고 ID·잔량·라벨·만료 시각을 바꾸지 않는다. 냉장 밖 체류에 따른 별도 변질은 구현하지 않는다.

배합 용기는 한 번에 하나만 들고 컵·제조 도구·피처·스펀지·청소용 천·회수 컵·소모품과 동시에 들 수 없다. 운반 중 만료돼 보관할 수 없으면 원래 작업대에 내려놓고 폐기한다. 창고 재고 화면에서 원격으로 준비 용기에 라벨을 붙이거나 보관하는 경로는 제공하지 않는다. 원팩은 기존처럼 창고에서 개봉·라벨·보관한다.

원재료도 개봉 후 라벨과 보관 단계를 거쳐야 사용 가능 재고에 포함한다. 라벨 없는 배치·보관 대기 배치·기한이 지난 배치는 음료와 준비 배합에 소비할 수 없다. 라벨 부착과 위치 이관은 원래의 개봉·제조 시각과 기한을 바꾸지 않는다. 진행 중인 준비와 미보관 배치는 마감 전에 완료하거나 폐기해야 한다.

폼·바모카에는 기한이 빠른 재고부터 실제로 투입한다. 여러 배치를 사용하면 투입량이 0보다 큰 배치들의 가장 빠른 만료 시각을 준비 상태에 기록한다. 빈 배치, 쓰지 않은 재고, 나중에 입고한 새 재료는 이미 기록한 기한을 늘리지 않는다. 완성 배치에는 제조 완료 후 기본 기한과 이 원재료 기한 중 이른 시각을 적용한다. 이는 제공 자료에 없던 관계를 사용자가 게임 규칙으로 확정한 것이다.

계량·혼합·블렌딩 중 원재료 기한이 지나면 작업을 중단하고 폐기해야 한다. 장비 완료 시각이 원재료 만료보다 이르면 배합을 완성하지만 그 이후에는 저장된 배합 기한을 그대로 적용한다. 만료 시각과 완료 시각이 같으면 사용할 수 없다. 라벨은 사용할 수 없는 시각을 ‘만료 시각’으로 표시하며, 원재료 때문에 짧아진 배합은 이유를 함께 안내한다.

## 시간과 저장

게임의 가상 날짜를 기준으로 근무 중 실제 시간처럼 흐른다. 일시정지·백그라운드·앱 종료 중에는 멈춘다. 다음 날 버튼으로 이동한 시간은 재료 기한과 장시간 추출에 함께 적용한다.

IndexedDB에 주요 행동 뒤와 주기적으로 저장한다. 현재 저장과 이전 정상 저장은 하나의 트랜잭션으로 교체한다. 잘못된 현재 저장은 이전 저장본 복구를 시도한다. 백업 가져오기는 형식·수치 범위를 검증한 후 저장한다. 지원 브라우저에서는 Web Locks로 같은 출처의 동시 쓰기를 제한한다.

탭 간 상태 동기화는 사용자 결정으로 구현하지 않는다. 현재처럼 앱 로딩 후 한 탭이 잠금을 갖고, 다른 탭은 기존 탭을 닫은 뒤 새로고침해 진행한다. 시작 화면의 잠금 보유도 유지하며 자동 인계·강제 가져오기·잠금 시점 변경은 추가하지 않는다. Web Locks 미지원 환경의 현재 동작과 상세 범위는 [후속 작업 분석](./next-steps.md)에 기록한다.

저장에는 컵 위치·내용물·계량 진행량·피처 잔량·도구·장비 작업, 부재료 준비 상태·라벨·보관 대기/운반 용기와 콜드 브루 계량·추출·회수 상태를 포함한다. 버튼을 누르고 있다는 입력 상태는 저장하지 않는다. 콜드 브루는 추출 완료 뒤 직접 회수·보관해야 사용할 수 있다.

사용자 요청에 따라 저장 데이터의 버전 필드와 마이그레이션은 두지 않는다. 현재 데이터 구조에 맞는 저장만 읽으며, 이전 구조의 컵·작업·플레이어 위치를 자동 변환하지 않는다. 맞지 않는 기록은 이전 정상 저장본을 확인하거나 새 근무를 시작한다.

개봉·제조 시 확정한 만료 시각은 라벨 부착이나 운반으로 바뀌지 않는다. 준비의 원재료 기한 필드는 null 또는 실제 기록 시각이어야 한다. 누락 필드 허용·보완, 레거시 형식 판별, 버전별 분기, 마이그레이션·호환 코드를 두지 않는다.

초기 배치는 즉시 플레이할 수 있도록 준비되어 있다. 폼과 바모카는 직접 준비해야 한다. 실제 레시피의 모든 세부를 구현했다는 의미는 아니며 위 표의 임시 규칙을 실제 절차 확인 후 교체한다.

## 콜드 브루 계량·추출·회수

사용자는 한 배치분을 확보해 직접 계량하는 흐름을 선택했다. 준비 시작 시 게임용 9,000원을 입고 지출로 기록하고 전용 원두 5lb 한 봉을 확보한다. 별도의 콜드 브루 원두 재고·발주는 두지 않는다. G로 봉투를 집어 누르고 전량을 넣은 뒤 내려놓고 확인한다. 원두는 한 봉의 양에서 멈추며, 물 14L는 기존 ±6% 계량 허용 구간을 사용한다. 원두·물의 기본 조작 시간 4초와 완성 수율 3L는 게임용 값이다.

계량 확인 후 Space로 20시간 추출을 시작한다. 추출 중에는 마감·다음 날 이동이 가능하지만 계량 중이거나 회수·보관할 배합이 남으면 마감을 끝낼 수 없다. 추출 완료는 완료 예정 시각을 기록하고 회수 대기로만 바뀐다. E로 용기에 회수할 때 배치를 한 번 만들고, 완료 예정 시각부터의 기한을 적용한다. 늦게 회수하거나 라벨을 붙여도 기한이 늘어나지 않는다. 라벨 부착·집기·냉장고 보관까지 마쳐야 사용 가능 재고에 포함한다.

추출 완료 전 중단·과다 계량 폐기는 원두 한 배치분 5lb의 폐기로 기록하고 준비비를 반환하지 않는다. 추출 완료 후 폐기는 완성 추출액의 양으로 기록하며 원두와 중복 집계하지 않는다. 물은 기존 무제한 공급 규칙에 따라 폐기량에 포함하지 않는다. 추출기 세척 절차·보관 온도 누적·실제 수율 정교화는 이번 범위에 포함하지 않는다.

## 청소와 하루 운영 기록

두 고객 테이블과 컨디먼트 바는 컵 수와 오염 여부를 각각 저장하며, 새 근무는 깨끗한 상태에서 시작한다. 주문 전달 때 사용한 테이블 하나를 무작위로 고르고, 컵은 90% 확률로 컨디먼트 바에 반납하거나 10% 확률로 해당 테이블에 남긴다. 사용한 테이블과 반납에 사용한 컨디먼트 바, 음료 작업대는 각각 30% 확률로 얼룩이 생긴다. 컵 위치와 얼룩 판정은 독립적이며, 계량 초과로 생기는 작업대 오염은 유지한다. 이 확률은 사용자 확인을 받은 임시 게임 규칙이다. 결과는 성공한 전달 시점에 한 번 계산해 저장하며 새로고침이나 렌더링으로 다시 뽑지 않는다. 테이블이 더러워져도 신규 주문을 잠그지 않는다. 손님의 착석·반납 이동·퇴장을 실제로 표시하며, 정해진 시점에 해당 표면에 컵과 오염을 반영한다.

테이블·컨디먼트 바 청소는 E로 컵을 하나씩 회수해 분리수거함에 옮기고, G로 천을 집어 누르고 닦은 뒤 천을 놓고 F로 마친다. 얼룩이 없는 자리는 컵 회수·분리수거만으로 완료한다. 혼합 작업대도 직접 닦는다. 현재 오염된 작업대는 한 번의 닦기로 정리한다. 쓰레기는 누르고 모아 봉투를 묶고 F로 비운다. 봉투 작업 시작 뒤 추가된 쓰레기는 이번 봉투에 포함하지 않는다. 한 번에 한 청소 작업을 진행하며, 자리를 떠나거나 저장해도 진행량·들고 있는 컵이 유지된다. 취소하면 닦기 진행만 초기화하고 이미 회수·폐기한 물건은 되돌리지 않는다. 천이나 회수한 컵을 들고 다른 도구를 동시에 사용할 수 없다.

운영 기록은 하루의 시작 잔액·판매액·입고 지출·현금 증감·현재 잔액과 재료별 폐기량이다. 원팩, 컵, 소모품, 콜드 브루 추출 준비비를 각각 기록하고 다음 날에는 당시 잔액으로 새 기록을 시작한다. 현금 증감은 판매액에서 입고 지출을 뺀 값이며 순이익으로 표시하지 않는다.

재제조 컵은 실제 소비한 재료량을 폐기로 기록한다. 아직 완성되지 않은 배합은 투입 원재료를, 완성된 배치는 남은 완성 재료량을 기록해 원재료와 중복 집계하지 않는다. 스팀 피처의 남은 우유를 정리할 때도 폐기로 기록한다. 물·얼음은 기존 무제한 공급 규칙에 따라 재고·폐기량에 포함하지 않는다.

재고 화면은 사용 가능·미개봉·라벨/보관 대기·만료를 서로 겹치지 않게 구분한다. 현재 컵의 남은 단계, 진행 중인 준비, 주문에 부족한 폼·바모카 한 배치의 원재료를 기준으로 부족 품목을 먼저 보여준다. 라벨·보관 대기는 사용 가능량에 합산하지 않는다.

## 컨디먼트 소모품

사용자 확인을 받은 임시 규칙으로 냅킨·빨대·설탕은 각각 진열 최대 20개·초기 진열 20개·후방 100개로 시작한다. 전달 성공 시 소모품 이용 의도를 정하고, 손님이 컨디먼트 바에 도착해 이용을 마칠 때 냅킨 1장, ICED 음료의 빨대 1개, 30% 확률의 설탕 1개를 진열대에서 소비한다. 품절인 품목은 음수로 차감하지 않고 보충 안내를 띄우며 주문·판매를 막지 않는다.

창고에서 비어 있는 진열 수량만큼 집으면 후방 재고에서 빠지고 운반 상태에 들어간다. 컨디먼트 바에 E로 놓아야 진열 수량이 늘어난다. 창고에서 E로 다시 내려놓으면 같은 수량을 반환한다. 운반 중 저장·복원으로 수량이나 소모품 종류가 바뀌지 않으며, 들고 있는 동안 컵·피처·다른 도구를 동시에 집지 못한다. 마감 전에 운반 중인 물품은 정리해야 하지만 진열을 가득 채우도록 강제하지 않는다.

각 품목의 추가 입고는 100개당 게임용 1,000원이며 당일 입고 지출에 포함한다. 매장 현황·결산에서 손님이 실제 사용한 소모품 수량도 확인한다.

## 손님 동선과 영업 마감

한 명씩 입장해 POS에 도착한 뒤 주문을 받는다. 주문표를 출력하면 손님이 픽업대로 이동하며, 대기 위치에 도착한 뒤에만 전달할 수 있다. 주문 번호·요청 메뉴·손님 ID를 같은 응대 동안 유지하고, 판매액은 전달 성공 시 한 번 기록한다. 이미 주문한 손님은 대기시간 때문에 퇴장하지 않는다.

수령한 손님은 컨디먼트 바에서 소모품을 챙기고 테이블에 앉아 게임 시간 10초 동안 머문다. 이후 90%는 컨디먼트 바로 컵을 가져가 반납하고, 10%는 테이블에 컵을 남긴다. 테이블 오염은 이용을 마친 시점에, 반납 컵과 반납대 오염은 반납을 마친 시점에 반영한다. 이동 속도 1.7m/s, 소모품 이용·반납 동작 각각 1.2초는 시각적 연결을 위한 임시 조작 시간이다. 한 손님이 출구로 나가야 다음 손님이 입장한다.

이동 경로의 현재 지점·위치·방향, 단계별 경과 시간, 수령 후 이용 의도를 저장한다. 일시정지·백그라운드·종료 중에는 이동이나 체류가 진행되지 않으며 저장을 불러와도 판매·소모품 소비·컵 반납을 다시 수행하지 않는다.

신규 주문 마감 시 주문 전 손님은 돌아 나가고, 이미 주문했거나 수령한 손님은 이용·반납·퇴장까지 마친다. 손님이 남아 있으면 결산할 수 없으며, 퇴장 후 생긴 컵·오염까지 정리한다. 닦는 도중 새 반납 컵이 놓이면 닦기를 확인한 뒤 컵 회수 단계로 이어진다.
