# 자료 근거와 게임용 규칙

사용자는 2026-09-23 초기 게임 규칙 적용을 허용했다. 2026-09-25에는 제조를 원문 기준으로 바꾸고 확인되지 않은 기존 물리 수치는 재고 계산에만 유지하도록 정했다.

바모카 **원팩**은 준비 가이드의 봉 단위만 근거로 삼는다. 게임의 개봉 후 7일은 직접 대응하는 품질 기준이 없는 임시값이며, 제조한 **바모카 배합**의 24시간과 구분한다. 번트 카라멜 파우더는 소분후 7일, 글레이즈드 소스는 개봉후 3일을 선택한다. 2026-09-24 사용자는 모든 ‘N일’ 기한에 시작일 포함 N일의 마지막 날 종료 기준을 적용하도록 결정했다. 예를 들어 9월 1일 15시에 개봉한 우유는 9월 3일 0시에 만료된다. 24시간 기한인 휘핑크림은 같은 조건에서 9월 2일 15시에 만료된다.

레시피의 Tall 폼 50ml는 텀블러 계량값이다. 일반 컵 기준선의 실측 용량으로 대체하지 않는다.

## 기한과 배합

2026-09-24 사용자 결정으로 준비 배치의 기한은 제조 후 기본 기한과 실제 투입 원재료의 가장 빠른 기한 중 이른 시각이다. 제공 자료에 없던 관계를 게임 규칙으로 정한 것이다. 이동·라벨 수정으로 개봉·제조 시각이나 원재료 기한을 늘리지 않는다. 준비 중 원재료가 만료되면 배합을 폐기하며 완료와 만료가 같은 시각이어도 사용할 수 없다.

냉장 밖 체류에 따른 변질은 별도 구현 범위다. 보관 방식에 따른 기한과 시그니처 초코의 정정은 [부재료 제조표 대조](./preparation-source-comparison.md)에 둔다.

## 콜드 브루 단순화

사용자는 전용 원두 재고·발주 대신 한 배치분을 게임용 9,000원에 확보하는 흐름을 선택했다. 5lb 배합과 별도 TODDY 원문의 차이는 [제조 자료 운영](./recipe-data.md#게임용-운영값과-컵-용량)을 따른다.

## 작업음과 조작 설정

2026-09-25 사용자가 고른 실제 녹음을 사용하며 특정 카페·장비의 소리를 정확히 재현한 것으로 표현하지 않는다. 완료·전달은 bell을 유지하고 계량 목표 도달·확인·주문 입력·라벨 부착은 무음으로 정했다. 컵·도구 타격음과 펌프·오류 찰칵음은 사용자 요청으로 제외했다.

작업음은 기본 꺼짐·음량 35%, 마우스 감도는 기본 100%·범위 50~200%를 선택했다. 방향키 회전 속도는 고정한다. 소리를 끄거나 재생에 실패해도 화면만으로 진행할 수 있어야 한다.

## 원두 그라인더

2026-09-29 사용자가 BUNN G3를 선택하고 드립커피·에스프레소 칩을 연결하도록 했다. 콜드 브루는 분쇄가 필요한 경우 연결하도록 요청했고, 기존 `cold-brew-batch`의 COARSE 안내·BUNN G3 설정 및 [아카데미 확인 기록](./preparation-source-comparison.md#리저브-콜드브루)을 근거로 연결했다.

- 드립: URN에 필터를 넣고 BUNN G3에서 HOT 118g·ICED 196g을 계량한 뒤 DRIP으로 분쇄한다. 분쇄 원두 용기를 직접 집어 URN 필터에 부은 뒤 기존 1/4·5분 추출을 시작한다. 수량·수율·기한·COW 원두 추적은 유지한다.
- 에스프레소 칩: 바 실온 선반의 에스프레소 원두를 원문대로 2~3스쿱, ESPRESSO로 분쇄한다. 그라인더에서 확인·라벨 작업을 마치고 완성 용기를 기존 선반·창고에 운반한다. 원문의 generic `coffee-grinder` ID는 유지하고 사용자 확인으로 BUNN G3에 연결했다. 기존 게임 산출량 4g과 제조 후 실온 24시간을 유지하며 원두 기한을 넘기지 않는다.
- 콜드 브루: 기존 한 배치분 9,000원 확보 흐름을 유지한다. [BUNN 공식 사양](https://commercial.bunn.com/22100.0000)의 호퍼 한도 3lb에 따라 5lb를 3lb와 2lb로 나누어 COARSE 분쇄하고 한 봉투에 모은다. 봉투를 추출대로 가져와 필터에 원두·정수 14L를 계량한 뒤 기존 20시간 추출·회수·라벨·냉장 보관을 이어간다. 제조표의 분쇄 설정 숫자를 일반 제품 다이얼의 숫자로 임의 대응시키지 않는다.

분쇄는 설정과 투입·완료를 확인하는 조작으로 구현했다. 원문에 없는 분쇄 시간은 추가하지 않으며 제조사의 처리 속도를 매장별 확정 시간으로 바꾸지 않는다. 원두·용기의 계량 및 이동은 기존 게임 조작 수준으로 단순화한다. 리저브 에스프레소용 `reserve-grinder`는 별도 장비이므로 BUNN G3에 연결하지 않는다.

분쇄도와 콜드 브루 분쇄량은 현재 형식 저장에 포함된다. 이전 형식을 보완·변환하지 않는 저장 정책에 따라 기존 저장은 새 근무 시작이 필요할 수 있다.

## 백룸 장비 운영

후드형 세척기는 후드를 내리면 운전하고 올리면 중단한다. 세척 주기 120초·랙 16칸, 제빙 600초당 5.2kg, 저장고 380kg·바 40kg·운반통 6kg은 게임 운영값이다. 기기 외형의 사진 근거, 수량·운반·저장·마감 경계와 생략한 위생 절차는 [백룸 장비](./backroom.md)에 둔다.
