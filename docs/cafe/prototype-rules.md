# 첫 플레이 버전의 구현 규칙

사용자는 2026-09-23에 제공 자료의 공개 사용과 미확인 절차의 임시 게임 규칙 적용을 허용했다. 이 문서는 실제 자료에서 가져온 부분과 플레이를 위해 정한 값을 구분한다.

## 자료

`apps/cafe/references/`의 다음 파일을 레포 루트에서 `bun run --filter=@sobok/cafe import:references`로 읽는다. 원본은 수정하지 않는다. 일반 빌드는 이미 생성된 JSON을 사용하므로 원본 엑셀이 없어도 동작한다.

| 파일                         | 사용 시트                 |
| ---------------------------- | ------------------------- |
| `26_pre-autumn_recipes.xlsx` | 음료 제조, 폼·베이스 제조 |
| `best_by_core.xlsx`          | 제조 베이스, 코어 원재료  |
| `best_by_special.xlsx`       | 특화 원재료               |
| `ingredient_prep_guide.xlsx` | 부재료 제조               |

변환 결과에는 14개 음료 형태, 6개 준비 배합, 170개 품질 기준행, 14개 준비 가이드행과 원본 해시가 있다. 행 수는 고유 SKU 개수와 다르다. 메뉴명·공통 배합 조건만 해당 묶음 안에서 이어 읽는다. 수량·단위의 빈칸은 0이나 이전 행의 값으로 채우지 않는다.

초기 메뉴의 제조 단계·순서·설명·주의사항은 변환한 레시피에서 읽는다. 새 자료에서 단계 수나 의미가 바뀌면 작업대 연결과 재고 차감도 함께 검토한다. 품질 기준 연결은 아래의 초기 재료를 기준으로 한다.

| 재료               | 자료 근거                                                            |
| ------------------ | -------------------------------------------------------------------- |
| 원두               | core / 제조 베이스 13행                                              |
| 우유·휘핑크림      | core / 코어 원재료 23행·22행                                         |
| 글레이즈드 소스    | special / 특화 원재료 72행                                           |
| 번트 카라멜 파우더 | special / 특화 원재료 51행의 소분후 기준                             |
| 바모카             | prep / 부재료 제조 13행, core / 제조 베이스 20행, 사용자 동일성 확인 |
| 글레이즈드 폼      | recipes / 폼·베이스 제조 7~10행                                      |
| 콜드 브루          | recipes / 폼·베이스 제조 24~26행, core / 제조 베이스 11행            |

## 직접 제조

직원은 카운터 안쪽 타일 통로에서 시작한다. 제조대·POS·픽업대는 직원 쪽 접근을 확인한 뒤 상호작용을 허용한다. 준비·세척·도구 정리·재고 관리도 안쪽에서 수행한다. POS 옆 직원 출입구로 나가면 객석 청소와 분리수거를 할 수 있다. 손님의 대기 위치와 객석은 카운터 바깥에 둔다.

E로 컵을 집거나 작업대에 내려놓고, G로 해당 단계의 도구를 집거나 놓는다. 클릭 또는 Space를 유지하면 붓기·젓기가 진행되고, 펌프·얼음·파우더는 한 번 누를 때마다 한 회를 더한다. 목표량에 도달하면 도구를 놓고 F로 확인한다. 완성된 컵은 픽업대에 놓고 F로 전달한다. 다음 단계가 같은 작업대면 그대로 이어서 작업한다.

컵을 내려놓으면 시점이 컵을 향하고 마우스 커서가 풀려 제조 HUD의 버튼도 사용할 수 있다. 컵을 집으면 다시 마우스로 시점을 조작한다. 오류가 난 컵은 화면 버튼 또는 F로 폐기한다.

HOT은 피처에 우유를 직접 계량한 뒤 스팀을 시작한다. 스팀 피처는 우유를 컵에 붓거나 컵을 폐기할 때 세척 대상으로 보낸다. ICED는 샷 글라스에 추출한 뒤 혼합대에서 직접 컵에 이관하고 젓는다. 샷 글라스는 컵과 함께 운반되는 것으로 단순화한다. 스팀 우유는 이미 계량한 피처 잔량까지만 붓고, 젓기·샷 이관은 완료 시 자동 정지한다.

재료는 실제 입력 진행량에 비례해 차감한다. 펌프·얼음·토핑은 클릭한 횟수를 반영한다. 허용량 초과는 컵의 오류·작업대 오염으로 기록되고 재제조해야 한다. 이미 투입한 재료는 폐기하거나 저장을 다시 불러와도 자동으로 반환되지 않는다. 화면의 컵 높이·액체 층은 진행 상태를 표현하는 비율이며 실제 ml 눈금이 아니다.

이동·시선 이탈·입력 해제·일시정지·창 포커스 이탈은 연속 투입을 멈춘다. 장비 작업 중에는 컵 이동을 막는다. 도구를 든 상태에서는 컵을 집을 수 없다. 폼·드리즐 보틀·머들러·스쿱 등의 개별 세척은 아직 단순화하고, 피처와 준비 배합 도구만 기존 세척·선반 정리 흐름에 연결한다.

세척이 끝나면 선반에서 정리해야 피처를 다시 사용할 수 있다. 준비 배합 역시 깨끗한 피처를 소모한다. 작업대의 동시 작업과 제조 중인 컵의 중복 작업을 막는다.

잘못된 주문 입력은 전달 시 손님의 원래 요청과 대조해 알려준다. 재제조 시 이미 쓴 재료와 컵은 복구하지 않는다. 주문을 전달해야 판매 기록과 운영비가 증가한다.

## 부재료와 라벨

글레이즈드 폼 기본 배합은 원본의 200ml 휘핑크림 → 50ml 우유 → 글레이즈드 소스 7펌프(펌프당 10.2ml) → 3번 버튼 1회(약 25초)를 읽어 직접 조작에 연결한다. 바모카는 준비 가이드의 원팩 1봉·온수 1L를 읽고, 6초간 젓는 게임용 단계를 적용한다. 액체 허용 구간은 음료와 같은 게임용 ±6%이며 펌프·원팩은 정확한 횟수가 필요하다. 온수 공급은 기존 물 규칙처럼 제한하지 않는다.

준비대에 피처를 놓으면 깨끗한 도구 한 개를 예약한다. 실제 투입량만큼 재고를 차감하고, 혼합 완료 또는 배합 폐기 시 피처를 세척 대상으로 보낸다. 음료 컵이나 다른 도구를 든 상태에서는 준비를 시작할 수 없지만, 컵을 바에 두면 주문 도중 필요한 부재료를 만들 수 있다. 계량 중 다른 일을 하거나 저장을 불러와도 투입량이 유지된다.

완성된 배합은 준비대에 보관 대기 배치로 생긴다. 개봉·제조 시각, 품질 기한과 보관 조건을 확인하고 라벨을 붙인 뒤 보관 위치를 선택한다. 폼은 냉장, 바모카는 실온이다. 잘못된 위치는 안내 후 이관을 거부하며 재료를 폐기하거나 기한을 변경하지 않는다. 실제 운반과 냉장 밖 체류에 따른 변질은 아직 단순화한다.

원재료도 개봉 후 라벨과 보관 단계를 거쳐야 사용 가능 재고에 포함한다. 라벨 없는 배치·보관 대기 배치·기한이 지난 배치는 음료와 준비 배합에 소비할 수 없다. 라벨 부착과 위치 이관은 원래의 개봉·제조 시각과 기한을 바꾸지 않는다. 진행 중인 준비와 미보관 배치는 마감 전에 완료하거나 폐기해야 한다.

## 시간과 저장

게임의 가상 날짜를 기준으로 근무 중 실제 시간처럼 흐른다. 일시정지·백그라운드·앱 종료 중에는 멈춘다. 다음 날 버튼으로 이동한 시간은 재료 기한과 장시간 추출에 함께 적용한다.

IndexedDB에 주요 행동 뒤와 주기적으로 저장한다. 현재 저장과 이전 정상 저장은 하나의 트랜잭션으로 교체한다. 잘못된 현재 저장은 이전 저장본 복구를 시도한다. 백업 가져오기는 형식·수치 범위를 검증한 후 저장한다. 지원 브라우저에서는 Web Locks로 같은 출처의 동시 쓰기를 제한한다.

저장에는 컵 위치·내용물·계량 진행량·피처 잔량·도구·장비 작업과 부재료 준비 상태·라벨·보관 대기 배치를 포함한다. 버튼을 누르고 있다는 입력 상태는 저장하지 않는다. 장시간 콜드 브루 준비는 완료 후 자동 이관한다.

사용자 요청에 따라 저장 데이터의 버전 필드와 마이그레이션은 두지 않는다. 현재 데이터 구조에 맞는 저장만 읽으며, 이전 구조의 컵·작업·플레이어 위치를 자동 변환하지 않는다. 맞지 않는 기록은 이전 정상 저장본을 확인하거나 새 근무를 시작한다.

초기 배치는 즉시 플레이할 수 있도록 준비되어 있다. 폼과 바모카는 직접 준비해야 한다. 실제 레시피의 모든 세부를 구현했다는 의미는 아니며 위 표의 임시 규칙을 실제 절차 확인 후 교체한다.
