# 첫 플레이 버전의 구현 규칙

사용자는 2026-09-23에 제공 자료의 공개 사용과 미확인 절차의 임시 게임 규칙 적용을 허용했다. 이 문서는 실제 자료에서 가져온 부분과 플레이를 위해 정한 값을 구분한다.

## 자료

`apps/cafe/references/`의 다음 파일을 레포 루트에서 `bun run --filter=@sobok/cafe import:references`로 읽는다. 원본은 수정하지 않는다. 일반 빌드는 이미 생성된 JSON을 사용하므로 원본 엑셀이 없어도 동작한다.

| 파일                         | 사용 시트                 |
| ---------------------------- | ------------------------- |
| `26_pre-autumn_recipes.xlsx` | 음료 제조, 폼·베이스 제조 |
| `best_by_core.xlsx`          | 제조 베이스, 코어 원재료  |
| `best_by_special.xlsx`       | 특화 원재료               |
| `ingredient_prep_guide.xlsx` | 부재료 제조               |

변환 결과에는 14개 음료 형태, 6개 준비 배합, 170개 품질 기준행, 14개 준비 가이드행과 원본 해시가 있다. 행 수는 고유 SKU 개수와 다르다. 메뉴명·공통 배합 조건만 해당 묶음 안에서 이어 읽는다. 수량·단위의 빈칸은 0이나 이전 행의 값으로 채우지 않는다.

초기 메뉴의 제조 단계·순서·설명·주의사항은 변환한 레시피에서 읽는다. 새 자료에서 단계 수나 의미가 바뀌면 작업대 연결과 재고 차감도 함께 검토한다. 품질 기준 연결은 아래의 초기 재료를 기준으로 한다.

| 재료               | 자료 근거                                                            |
| ------------------ | -------------------------------------------------------------------- |
| 원두               | core / 제조 베이스 13행                                              |
| 우유·휘핑크림      | core / 코어 원재료 23행·22행                                         |
| 글레이즈드 소스    | special / 특화 원재료 72행                                           |
| 번트 카라멜 파우더 | special / 특화 원재료 51행의 소분후 기준                             |
| 바모카             | prep / 부재료 제조 13행, core / 제조 베이스 20행, 사용자 동일성 확인 |
| 글레이즈드 폼      | recipes / 폼·베이스 제조 7~10행                                      |
| 콜드 브루          | recipes / 폼·베이스 제조 24~26행, core / 제조 베이스 11행            |

## 임시 수치와 단순화

| 항목                  | 첫 버전 규칙                                                                | 실제 기준과의 관계                               |
| --------------------- | --------------------------------------------------------------------------- | ------------------------------------------------ |
| 범위                  | Tall, 한 번에 주문 한 건, 세 음료 형태                                      | 게임 범위 선택                                   |
| 고객                  | 대기시간으로 퇴장하지 않는 학습형 주문                                      | 임시 난이도                                      |
| 조작                  | 컵을 든 채 작업대에서 각 단계를 시작                                        | 물건별 집기·기울이기를 단계 조작으로 단순화      |
| 컵 기준선 → 재고량    | 콜드 브루 추출액 90ml, HOT 우유 200ml, ICED 우유 180ml, 폼 45ml, 드리즐 5ml | **재고 계산용 추정치. 실제 컵 기준의 ml가 아님** |
| 에스프레소            | 자료의 샷 수, 재고 소비는 샷당 원두 9g                                      | g 환산만 임시                                    |
| 펌프                  | 초기 소스는 자료의 Tall 펌프 수와 해당 펌프 용량 사용                       | 원본에 근거                                      |
| 준비량                | 폼 450ml, 바모카 1500ml, 콜드 브루 3000ml                                   | **완성 수율 추정치**                             |
| 일반 제조 작업        | 2초, 스팀 5초                                                               | 임시 동작 시간                                   |
| 세척·청소             | 세척 4초, 테이블·작업대 3초                                                 | 실제 위생 절차의 시간·단계를 의미하지 않음       |
| 바모카 배합           | 원팩 1봉과 온수 배합, 동작 6초                                              | 투입 원칙은 자료, 혼합 시간과 완료 수율은 임시   |
| 폼 블렌딩             | 기본 배합의 자료에 있는 작동 시간 사용                                      | 원본에 근거                                      |
| 라벨·보관             | 개봉·준비 완료 때 자동 라벨 부착과 위치 이관                                | 수동 표기·운반은 후속 구현                       |
| 일 단위 기한          | 배치 시각부터 N × 24시간                                                    | 달력 계산 관례 확인 전 임시                      |
| 미개봉 원팩           | 개봉 전 만료 없음                                                           | 공급자 소비기한 미구현                           |
| 준비 배치             | 준비 완료 시점부터 해당 배치 기한 적용                                      | 원재료의 남은 기한과의 관계는 후속 확인          |
| 물·얼음               | 공급 제한 없음                                                              | 공급·위생 관리 미구현                            |
| 콜드 브루 장시간 준비 | 자료의 추출 시간 경과 후 자동 배치 생성·보관                                | 원두·물 계량, 장비 종료·이관 조작은 후속 구현    |
| 돈                    | 초기 운영비, 메뉴 가격, 원팩 가격과 추출 준비비는 게임용                    | 실제 원가·매장 판매가격이 아님                   |
| 공간·장비             | 단순 도형으로 만든 독자 매장과 장비                                         | 특정 매장·기종의 정확한 외형 재현이 아님         |

스팀은 피처 한 개를 사용하고 세척 대상으로 보낸다. 세척이 끝나면 선반에서 정리해야 다시 사용할 수 있다. 준비 배합 역시 깨끗한 피처를 소모한다. 작업대의 동시 작업과 제조 중인 컵의 중복 작업을 막는다.

잘못된 주문 입력은 전달 시 손님의 원래 요청과 대조해 알려준다. 재제조 시 이미 쓴 재료와 컵은 복구하지 않는다. 주문을 전달해야 판매 기록과 운영비가 증가한다.

## 시간과 저장

게임의 가상 날짜를 기준으로 근무 중 실제 시간처럼 흐른다. 일시정지·백그라운드·앱 종료 중에는 멈춘다. 다음 날 버튼으로 이동한 시간은 재료 기한과 장시간 추출에 함께 적용한다.

IndexedDB에 주요 행동 뒤와 주기적으로 저장한다. 현재 저장과 이전 정상 저장은 하나의 트랜잭션으로 교체한다. 잘못된 현재 저장은 이전 저장본 복구를 시도한다. 백업 가져오기는 형식·수치 범위를 검증한 후 저장한다. 지원 브라우저에서는 Web Locks로 같은 출처의 동시 쓰기를 제한한다.

초기 배치는 즉시 플레이할 수 있도록 준비되어 있다. 폼과 바모카는 직접 준비해야 한다. 실제 레시피의 모든 세부를 구현했다는 의미는 아니며 위 표의 임시 규칙을 실제 절차 확인 후 교체한다.
