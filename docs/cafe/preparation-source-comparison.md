## 시그니처 초코 사용자 정정

- 제조한 기본 프리믹스는 실온 2일 사용하고 마감 시 백룸 냉장고에 보관한다. 남은 배치가 냉장고에 없으면 마감을 완료할 수 없다. 이동하거나 라벨을 다시 써도 제조일과 기한은 유지된다.
- 우유를 별도로 섞은 시그니처 초코는 당일까지만 사용한다.
- 현재 HOT·키즈 레시피는 주문마다 피처에 프리믹스와 우유를 각각 계량해 스팀한다. ICED도 컵에 각각 계량한다. 우유 혼합 프리믹스를 소비하는 별도 제조법은 없다. 따라서 현재 수록 메뉴에 우유 혼합 배치를 추가할 필요는 없으며 당일 사용 규칙은 제조 자료에 기록한다.
- 원문에 있던 프리믹스의 유제품 함유 안내는 유지한다. 기본 프리믹스 배합에 액상 우유를 추가하라는 뜻으로 해석하지 않는다.

근거: [HOT·키즈 제조법](../../apps/cafe/data/recipes/drinks/signature-hot-chocolate.json), [ICED 제조법](../../apps/cafe/data/recipes/drinks/iced-signature-chocolate.json), [프리믹스 제조법](../../apps/cafe/data/recipes/preparations/signature-chocolate-premix.json). 이 판단은 현재 제공·수록된 레시피 범위의 결과다.

## 아이스 커피 보관

라벨을 작성할 때 실온·냉장을 선택한다. 실온은 제조 시각 + 4시간, 냉장은 제조 시각 + 8시간이며 원두의 기한이 더 빠르면 그 기한을 적용한다. 실온은 바 선반·백룸 창고, 냉장은 바 냉장고·백룸 냉장고로 연결한다.

냉장 라벨을 미리 써도 냉장고에 넣기 전에는 기존 실온 기한이 적용된다. 보관 방식을 바꾸면 같은 제조 시각으로 라벨을 다시 쓰며, 이미 만료된 배치는 변경하거나 이동해 사용할 수 없다. 보관 방식과 투입 원재료의 가장 이른 만료 시각은 배치와 함께 저장한다.

## 추가 자료와 게임 계산 기준

- `1/4` 급수 기준은 제조사 스타벅스 전용 기술자료의 2.2L를 적용한다. 원두 흡수·증발을 생략하고 얼음이 모두 녹는 것으로 계산하는 게임 수율은 HOT 2,200ml, ICED는 얼음 660g을 정확히 넣었을 때 2,860ml다. [제조사 자료 확인](./digital-urn-proposal.md#제조사-자료의-버튼별-용량)을 참조한다.
- 로스트 1봉의 실제 무게, 에스프레소 원두 스쿱의 실제 g, 완성 수율은 사진에 없다. 기존 재고 환산값을 원문 수치로 바꾸지 않는다.
- 시그니처 초코 원팩의 입고·개봉 기한·분말 환산은 사용자 승인으로 기존 바모카 원팩의 게임 설정을 재사용한다. 별도 재료 ID로 관리한다.
- 프릿츠골드는 기존 슈크림 휘핑 원문에서 `cream`으로 연결되어 있다. 하프앤하프도 같은 연결을 사용한다.
- 콜드 폼 대용량은 배합만 2배로 하고 기존 블렌더 3번 프로그램·1회·약 25초를 유지한다.
- 일반 휘핑의 통 제조는 사용자 확인으로 슈크림 휘핑과 같은 가스 주입·30회 흔들기를 연결하고 `review`를 해소했다. 원재료를 소비하는 직접 제조로 전환했으며 게임 산출량은 기존 품목 규격인 500ml를 유지한다. 바트의 자동휘핑머신 작업은 확인 대상으로 남긴다.
