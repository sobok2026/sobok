# 카페 매장 운영 게임

## 목표

1인칭으로 매장을 돌아다니며 POS, 음료 제조, 청소, 설거지, 정리, 재고 관리를 수행하는 PC 웹 게임이다. 한 잔을 정확하게 만드는 작업과 다음 주문을 받을 준비를 함께 다룬다. 승진 단계 없이 처음부터 모든 업무를 수행한다.

초기 메뉴는 콜드 브루 ICED와 블랙 글레이즈드 라떼 HOT/ICED다. 사용자는 제공한 원부재료·레시피 자료를 공개 소스와 빌드에 사용하는 것을 허용했다. 네 엑셀을 JSON으로 변환해 근거와 함께 관리하고, 실제 규칙과 게임용 임시 규칙은 [구현 규칙](./prototype-rules.md)에서 구분한다.

## 첫 플레이 버전

작은 매장에서 한 근무를 마감까지 완료하고 저장된 상태를 이어서 플레이한다.

| 업무   | 플레이                                      | 결과                        |
| ------ | ------------------------------------------- | --------------------------- |
| POS    | 손님 요청을 읽고 메뉴·온도·매장/포장을 입력 | 입력한 주문표가 제조에 연결 |
| 제조   | 컵을 준비하고 작업대를 이용해 단계별 제조   | 재료 소비와 도구 사용 발생  |
| 전달   | 손님 요청·주문표·완성 음료를 대조           | 판매 완료 또는 재제조       |
| 청소   | 사용한 테이블과 작업대 정리                 | 고객 공간과 작업 공간 회복  |
| 설거지 | 사용한 도구를 세척하고 회수                 | 깨끗한 도구 공급            |
| 정리   | 컵·도구를 제자리에 놓고 작업 공간 확보      | 다음 주문의 준비 부담 감소  |
| 재고   | 보관 중인 배치를 확인하고 바로 보충         | 사용할 수 있는 재료 공급    |

한 손님이 입장해 주문·수령·컨디먼트 이용을 마친다. 매장 손님은 테이블 10초 체류·반납 또는 컵 방치·퇴장을 거치고, 포장 손님은 컵을 들고 바로 나간다. 앞 손님이 나간 뒤 다음 손님이 들어온다. 초기에는 한 손님의 주문을 따라가며 배우고, 이후 여러 업무 중 먼저 처리할 일을 고른다. 실수는 구체적인 원인으로 표시한다. 잘못된 POS 입력과 제조 오류를 구분한다.

## 공간과 조작

주문 카운터, 제조 바, 픽업대, 준비대, 세척대, 냉장 보관, 상온 보관, 고객 테이블과 컵 반납·소모품 보충을 위한 컨디먼트 바를 연결한다. 시선과 짧은 이동으로 작업 대상을 찾을 수 있는 크기로 시작한다.

제조는 카운터 안쪽의 직원 전용 통로에서 진행한다. 장비 조작면·노즐·컵 위치와 POS 화면은 직원 쪽을 향한다. 손님은 카운터 바깥에서 주문하고 픽업하며, 직원은 객석으로 나가지 않고 제조·전달·세척·재료 준비를 할 수 있다. 객석 청소와 분리수거는 POS 옆 직원 출입구를 이용한다. 고객 공간에서는 카운터 너머의 업무 장비를 조작할 수 없다.

WASD 이동, 마우스·방향키 시점, E 상호작용, Esc 일시정지를 기본으로 한다. 컵은 작업대에 자동 정렬해서 놓고, G로 도구를 집거나 놓는다. 클릭·Space를 누르고 붓거나 저으며, 펌핑·얼음·파우더는 클릭 횟수를 맞춘다. 도구를 놓은 뒤 F로 계량을 확인한다. 주문·운영 UI에서는 마우스로 선택한다. 키보드만으로도 시점과 작업을 조작할 수 있다. 시선 대상과 현재 가능한 행동을 보여준다.

정밀한 손가락·유체 표현보다 물건과 작업 상태를 구분하는 데 집중한다. 투입량은 게임 상태로 계산하고 컵의 색·내용물 높이와 작업 애니메이션으로 표현한다.

## 한 근무의 흐름

1. 매장과 재료·도구 상태를 확인한다.
2. 주문을 POS에 입력한다.
3. 컵을 준비하고 필요한 작업대에서 음료를 만든다.
4. 주문을 확인하고 전달한다.
5. 사용한 도구 세척, 테이블·컨디먼트 바 컵 회수와 청소, 냅킨·빨대·설탕 및 재료 보충을 수행한다.
6. 다음 주문을 처리하거나 신규 주문을 마감한다.
7. 남은 업무와 재료를 정리하고 결산한다.
8. 다음 영업일로 이동한다.

근무 중 게임 시계는 실제 시간처럼 흐른다. 일시정지·비활성화·게임 종료 중에는 진행하지 않는다. 다음 날로 이동할 때만 그 구간의 게임 시간을 경과시킨다. 건너뛴 시간에 판매나 동료의 작업을 만들어 넣지 않는다.

## 재료와 준비 배치

재료는 품목 총량과 용기별 상태를 함께 가진다. 원팩, 소분 용기, 제조한 베이스는 서로 다른 배치다. 개봉·제조 시각, 위치, 잔량, 보관 조건, 라벨을 기록한다. 단순한 위치 이동은 재고 소비가 아니다.

준비 배치에 원재료를 투입할 때 소비하고, 완성 배치를 음료에 사용할 때 원재료를 다시 차감하지 않는다. 라벨 수정이나 용기 이동으로 실제 생성 시각을 초기화하지 않는다. 여러 재료가 포함된 배치의 기한 규칙은 자료 또는 사용자 확인에 근거한다.

기한의 시간·달력 날짜·당일·개월 기준을 구분한다. 미확인 규칙은 실제 매장 기준으로 단정하지 않는다. 장시간 준비 작업은 시작·완료 예정·후속 처리 상태를 저장한다.

2026-09-24 사용자 결정에 따라 ‘N일’은 시작일 포함 N일의 마지막 날 종료, ‘N시간’은 시작 시각부터의 경과 시간으로 계산한다. 폼·바모카의 기한은 제조 완료 후 기본 기한과 실제 투입한 원재료의 가장 빠른 기한 중 이른 시각이다. 준비 중 원재료 기한이 지나면 배합을 더 진행하거나 사용하지 못하며 폐기한다. 컵 계량·준비 수율·원팩 규격·샷당 원두량·스팀·세척의 미확정 세부는 사용자가 기존 임시값 유지를 선택했다.

## 운영과 성장

판매·환불·재제조·재료 사용·폐기를 구분해서 기록한다. 직접 제조의 숙련과 발주·준비량·동선 개선이 성장의 중심이다. 이후 동료 업무 분담, 장비·보관 용량, 메뉴와 작업대를 확장한다.

첫 버전에는 실제 결제·회원 서비스, 원격 데이터베이스, 멀티플레이, 외부 도시, 드라이브 스루를 포함하지 않는다.

## 자료와 구현의 경계

실제 절차와 게임을 위해 단순화한 동작을 구분한다. 비어 있는 실제 수치를 임의로 채워 공식 레시피처럼 표시하지 않는다. 자료는 사용자의 공개 허용 범위에 따라 포함하며, 원본 엑셀을 수정하지 않고 변환 결과를 별도 파일에 저장한다.

사용자 확인: 바모카 드리즐은 코어 모카소스와 같은 소스다. 오늘의 커피는 URN 보온이며 가이드의 실온은 비냉장 위치를 의미한다. 시그니처 초코는 영업 중 실온·마감 시 냉장으로 관리한다.

## 매장·포장 컵

매장·포장은 입장 때 50%씩 정한다. 매장은 HOT 머그·ICED 유리잔, 포장은 HOT 종이컵·ICED 일회용 컵을 제공한다. 다회용 컵은 종류별 4개로 시작해 회수→세척→컵 보관대 반납 후 재사용한다. 포장 컵에만 리드를 덮는다. 일회용 컵은 종류별 보관대 2개·후방 12개로 시작하며 종류별 보충·입고를 관리한다. 세부 수치와 실물 눈금의 표현 범위는 [임시 규칙](./prototype-rules.md)을 따른다.
