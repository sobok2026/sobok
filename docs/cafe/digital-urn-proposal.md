# URN Digital 드립커피

2026-09-27 공식 자료를 조사하고 게임 규칙을 협의했다. 사용자 확인을 받아 2026-09-28 URN 추출·COW 설정·POS 판매·재고·저장 연결을 구현했다. 원두량은 2026-09-28 사용자 확인값인 HOT 118g·ICED 196g을 사용한다. HOT·ICED 추출 5분과 HOT 보온 1시간을 사용한다. 같은 날 제공된 부재료 제조표로 1/4 설정·ICED 얼음 660g·실온 4시간·냉장 8시간을 보완했다. 이후 확인한 BUNN 스타벅스 전용 기술자료의 1/4 배치 2.2L를 앱 급수 기준으로 적용한다. 완성 수율은 원두 흡수·증발을 생략한 게임 계산이다.

## 확인한 공식 자료

- [스타벅스의 추출 장비 소개](https://about.starbucks.com/stories/2026/freshly-brewed-coffee-on-demand-how-the-innovative-clover-vertica-is-changing-starbucks-coffeehouses/)의 BUNN Digital Brewer 사진: 금속 추출 깔때기 2개, 사각 보온 서버 2개, 중앙 LCD, 측면 온수 탭과 배수 받침을 확인했다. 본문은 URN 내부 보온 장치와 추출 중 깔때기 이탈 방지를 설명한다. 미국 장비 소개이며 한국 매장의 정확한 모델 번호까지 확인한 자료는 아니다.
- [BUNN Dual SH Soft Heat DBC 33500.6001](https://commercial.bunn.com/33500.6001): 제조사가 공개한 배치 용량은 0.5·1·1.5 US gal, 표시상 약 1.9·3.8·5.7L다. 물량·바이패스·펄스·사전 적심은 커피 프로필별로 조정된다. 이 일반 제품 사양을 스타벅스 전용 기기의 `FULL`·`1/2`·`1/4` 버튼에 그대로 대응시키지 않는다.
- [BUNN 설치·운영 가이드](https://catalog.bunn.com/public/docs/52187.0000/E17/02/000/52187.0000.pdf): 필터·분쇄 원두·깔때기·빈 서버를 준비해 추출한다. 정해진 한 가지 추출 시간은 제시하지 않는다. 특정 매장의 HOT 5분 설정을 확정하는 근거는 아니다.
- [BUNN 분쇄·추출 가이드](https://resource.bunn.com/assets/web/pdfs/2021-Grinder_Equipment_Catalog_Web.pdf) 8쪽: 일반 DRIP 분쇄도의 권장 물 접촉 시간을 약 4~6분으로 제시한다. 스타벅스 전용 URN의 배치별 전체 작동 시간이나 별도 잔류액 배출 시간에 대한 규격은 아니다.
- [스타벅스 기본 추출 비율 자료](https://stories.starbucks.com/uploads/2013/09/Fact_Sheet_-_Four_Fundamentals_of_Brewing-1.pdf): 일반 안내는 분쇄 커피 10g / 물 180ml다. 검색 색인에서 본문을 확인했으며 현재 PDF 원본 URL은 404를 반환한다. 특정 URN 배치의 투입·산출 규격은 아니다.
- [스타벅스 코리아 추출 안내](https://www.starbucks.co.kr/coffee/higher_enjoy.do): 커피 메이커는 물 6온스당 2테이블스푼, 아이스 푸어 오버는 두 배로 진하게 추출한 뒤 얼음으로 희석한다. 아이스 푸어 오버 안내를 URN의 확정 레시피로 옮기지 않는다.

첨부 POS 화면은 HOT·ICED를 별도로 선택해 COW 원두를 변경하고, 확정 후 드립·아이스 드립 상품에 원두명을 표시하는 구조의 참고 자료다. 사진에 포함된 식별 정보·화면 원본은 저장소에 복사하지 않는다.

## 앱에 적용한 제조 기준

**HOT·ICED 모두 1/4 설정·급수 2.2L**를 사용한다. BUNN 스타벅스 전용 기술자료의 버튼별 배치량을 적용했다. 아래의 급수와 완성 커피량을 같게 둔 부분은 원두 흡수·증발 손실을 생략한 게임 규칙이다.

| 항목         | HOT 드립            | ICED 드립                                | 근거와 경계                                                                                                     |
| ------------ | ------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 급수 기준    | 2,200ml             | 2,200ml                                  | BUNN 스타벅스 전용 기술자료의 1/4 배치 2.2L를 적용                                                              |
| 분쇄 원두    | 118g                | 196g                                     | 2026-09-28 사용자 확인 원두량                                                                                   |
| 추출 산출량  | 2,200ml             | 농축 커피 2,200ml                        | 원두 흡수·증발을 생략한 재고 계산용 수율                                                                        |
| ICED 후처리  | 해당 없음           | 얼음 660g을 넣고 혼합, 완성 재고 2,860ml | 얼음 부피를 액체 부피로 계산하지 않음. 얼음이 전부 녹는 것으로 단순화하며 냉각·열평형은 계산하지 않는 게임 규칙 |
| 추출 시간    | 5분                 | 5분                                      | 2026-09-28 제공 제조표의 미추출 시 5분 안내·ICED 추출 5분과 일치                                                |
| 제공 전 보관 | URN 보온            | 실온·냉장 선택 후 바 선반·냉장고 보충    | HOT을 일반 냉장 재료로 처리하지 않음                                                                            |
| 품질 기한    | 제조 완료부터 1시간 | 실온 4시간·냉장 8시간                    | HOT은 2026-09-27 사용자 확인. ICED는 2026-09-28 제공 제조표                                                     |

HOT 보온 기한 1시간은 사용자 확인값으로 `data/quality.json`에 반영했다. `room`은 기존 설계의 비냉장 분류이며 일반 선반 보관을 뜻하지 않는다. 완성 HOT 배치는 `location: urn`에서만 사용할 수 있으며 일반 실온 선반이나 냉장고로 운반하지 않는다.

5분은 추출 시작부터 사용 가능한 배치가 되는 시점까지의 전체 게임 대기 시간이다. 별도 드리핑 시간을 추가하지 않는다. 추출 중에는 다른 일을 할 수 있고, 시간이 끝나면 자동으로 완료되어 그 시각부터 HOT 보온 기한 1시간을 계산한다. 완료 버튼을 늦게 누르거나 배치를 옮겨도 기한이 연장되지 않는다. 제조 시간 없이 즉시 완료를 확인하던 이전 제안은 철회한다.

계량은 기존 제조 조작의 ±5% 확인 기준을 따른다. 누르는 동안 목표에서 자동으로 멈추지 않으며, 부족하면 이어서 넣고 초과하면 배치를 폐기한다. 원두는 실제 계량량만 차감하고 ICED 완성 재고는 농축액 2,200ml에 실제 넣은 얼음 g을 더해 계산한다. 이 환산은 얼음이 모두 녹는 것으로 단순화한 게임값이다.

1/2·FULL 배치는 국내 기기 설정을 확인한 뒤 확장한다. 원두 종류별 시간 차이·펄스·바이패스·온도 설정도 이번 초안에서는 만들지 않는다.

## 작업 흐름과 POS 연결

1. POS의 **관리메뉴 → COW 설정**에서 HOT·ICED 원두를 따로 선택하고 확정한다. 첨부 화면의 하우스 블렌드·파이크 플레이스 로스트를 초기 선택으로 사용한다. 처음에는 첨부 화면에서 명확히 읽히는 하우스 블렌드·파이크 플레이스 로스트·콜롬비아·과테말라·케냐·카페 베로나·베란다 블렌드를 제공한다.
2. URN에서 온도 용도와 선택된 원두를 확인하고, 필터와 분쇄 원두를 준비한 뒤 추출한다. 물은 연결된 급수 장치에서 공급한다. HOT은 URN에서 컵에 따른다. ICED는 별도 용기에 회수해 얼음 혼합·보관 방식 선택·라벨·실온 또는 냉장 보관·바 보충으로 연결한다.
3. COW 설정을 바꿔도 이미 추출한 배치의 원두명·제조 시각·기한은 바꾸지 않는다. 새로운 원두는 다음 배치부터 적용한다. 기존 배치와 새 원두의 불일치를 표시하고, 기존 HOT 배치를 소진하거나 폐기한 뒤 새 원두를 추출한다. ICED는 완성 용기를 선택한 장소에 보관하면 추출 자리가 비며 원두가 다른 배치도 각각 유지된다.
4. POS 상품명은 **드립 / 아이스 드립**, 그 아래에는 설정한 원두명을 표시한다. 원본 제조 문서의 오늘의 커피·아이스 커피 ID와 이름은 유지한다. 검색은 두 이름과 원두명을 함께 지원한다.
5. 접수한 주문·결제 거래에는 당시 원두를 보존한다. 이후 COW 변경으로 기존 주문과 영수증의 원두가 바뀌지 않게 한다. 제조 시 해당 원두로 추출된 배치를 사용한다.
6. 원두별 재고는 기존 재료·원팩·개봉·라벨·백룸→바 보충 방식으로 연결한다. 새로운 입고 규격·가격은 실물 원가로 추측하지 않고, 기존 게임 원두의 규격·입고가·7일 개봉 기한을 같은 게임 기준으로 사용한다.

기존 Zod 게임 상태와 기능별 행동·3D 모듈 안에서 구현한다. 별도 저장소·제조 엔진·외부 API는 추가하지 않는다. 승인한 게임 수치는 `data/shop`에 두고 원문 레시피에 공식 수치처럼 섞지 않는다.

## POS 판매 연결

- `todays-coffee:hot`과 `iced-coffee:iced`는 `data/menu.json`에 가격이 있고 `data/shop/pos-menu.json`의 `coffee` 메뉴군·`brew` 분류에 등록되어 있다.
- 조사 당시 두 완성 커피 재료의 준비법이 없어 판매가 보류되어 있었다. 원본 레시피를 바꾸지 않고 공통 제조 계획에 URN 전용 준비 경로를 연결했다. 두 메뉴 모두 Tall·Grande·Venti에서 매장·포장 주문을 받을 수 있다.
- 관리메뉴의 COW 설정에서 두 원두를 따로 고르고 확정한다. 상품 카드는 드립·아이스 드립 이름과 현재 원두를 표시한다. 원래 메뉴명·드립 이름·원두명으로 검색할 수 있다.
- 접수 당시 원두는 주문 행과 제조 상태에, 결제 당시 표기는 거래·영수증에 보존한다. 수량·사이즈·커스텀 수정으로 기존 주문의 원두를 바꾸지 않으며 온도 메뉴를 바꾸면 새 메뉴의 현재 COW를 적용한다. 제조 엔진은 해당 원두의 배치만 소비한다.
- 오늘의 커피의 기존 냉장·24시간 운영값을 제거하고 사용자 확인을 받은 비냉장 분류·1시간을 품질 데이터에 반영했다. 실제 완성품 보관은 URN으로 제한한다.
- Tall 가격은 두 메뉴 모두 기존 데이터의 4,500원이다. 현재 가격 데이터와 첨부 화면의 Tall 가격은 일치한다. 다른 사이즈와 현행 매장 가격을 새로 검증한 결과는 아니다.

## 구현한 외형

`features/drip-coffee/equipment.ts`를 기존 장비 형상·재질 도구로 작성하고 메인 바의 에스프레소 머신과 콜드 브루 탭 사이에 배치했다. 사진의 두 깔때기·사각 서버·수위관·회색 추출 손잡이·빨간 온수 손잡이·LCD·금속 배수 격자를 표현한다. 사진 원본과 새로운 바이너리 모델은 포함하지 않는다.

기기 LCD와 서버 라벨에 원두·추출 남은 시간·잔량·폐기 상태를 표시한다. 추출 중 물줄기와 수위관을 갱신하고 ICED 회수 용기는 얼음 혼합·운반 상태를 따른다. HOT 컵과 붓는 줄기는 서버 토출구에 맞춘다. 게임에서 확대해 표현하는 Venti 컵이 토출구와 받침에 걸리지 않도록 보온 서버 받침 높이를 조정했다. 라벨 문구가 바뀔 때만 캔버스 텍스처를 다시 그린다.

## 파일과 저장

- `data/shop/drip-coffee.json`: 승인한 계량·추출 시간·원두 선택·초기 COW.
- `features/drip-coffee`: 추출 행동·규칙·URN 패널·COW 화면·3D 장비.
- `simulation/state.ts`: HOT·ICED 준비 상태, COW, 배치·주문의 원두, 저장 검증. 새 상태는 기존 게임 저장 안에 포함한다.
- `features/inventory`: 원두 원팩·직접 보충, 완성 배치의 라벨·운반·원두별 소비.
- `features/service`: POS 상품·주문·거래 표기. 원본 제조 문서의 ID·이름·컵 계량은 유지한다.

새 COW·추출·원두 필드가 없는 이전 저장은 기존 정책에 따라 자동 변환하지 않는다. 이 변경 전 저장에서는 새 근무가 필요하다. 이 버전으로 저장한 추출 진행·운반·주문은 그대로 복원한다.

## 확인 기록

2026-09-28 실제 제조 행동으로 원두 원팩 개봉·라벨·바 보충 → HOT·ICED 동시 추출 → ICED 얼음 혼합·라벨·냉장 보관 → 두 잔 제조·전달을 확인했다. 5분 전 사용 차단, 완료 시각 기준 HOT 1시간, 다른 원두 사용 차단, COW 변경과 주문 수정 후 기존 원두 유지, 영수증 표기, 추출·운반 중 저장 복원, 잘못된 ICED 보관 장소 거부, HOT 만료 후 사용 차단을 확인했다.

별도 로컬 브라우저의 1280×720 화면에서 URN 양쪽 추출 타이머, 원두 표시, POS COW 변경·확정, HOT·ICED 상품 카드의 원두 변경과 기존 주문의 원두 보존을 확인했다. 브라우저 오류는 없었다. 진단용 실행 파일은 저장소에 추가하지 않았다. 자동 테스트 코드는 추가하지 않았다.

현재 판매 가능 메뉴는 121개·287개 사이즈 조합이다. 동시 진행 중인 백룸·제조 변경을 포함한 확인 시점의 결과이며 다른 작업의 이후 변경까지 검증한 기록은 아니다.

최종 타입·제조 자료·폰트·Biome·Prettier 검사와 프로덕션 빌드를 통과했다. POS와 URN 패널은 열 때 불러오며 모든 JavaScript 청크가 기본 500KB 경고 기준 안에 있다. 프로덕션 미리보기에서도 POS·COW와 저장 복원 후 URN 패널의 동적 로딩을 확인했다.

## 부재료 제조표 보완

제공 제조표의 `1/4` 설정에 BUNN 스타벅스 전용 기술자료의 2.2L를 급수 기준으로 연결한다. ICED 보관 방식은 라벨 작성 시 선택하고 실온 4시간·냉장 8시간 모두 최초 추출 완료 시각부터 계산한다. 냉장고에 보관하기 전에는 기존 실온 기한을 유지한다. 이미 만료된 배치를 옮겨 기한을 되살릴 수 없다. [부재료 제조표 대조](./preparation-source-comparison.md)를 참조한다.

## 제조사 자료의 버튼별 용량

2026-09-28 사용자가 최대 7.6L와 1/4 1.9L의 관계를 제조사 자료로 확인하도록 요청해 BUNN의 스타벅스 전용 기술자료를 직접 읽었다.

[BUNN Starbucks Dual Soft Heat DBC 기술자료](https://learningcenter.bunn.com/pluginfile.php/6655/course/section/369/SPANISH%20SB%20DUAL%20COMPLETE%20TECH%20MANUAL.pdf#page=16)의 PDF 16쪽과 47쪽은 다음 용량을 기재한다. 스페인어판 자료이며 국내 기기에 같은 설정이 적용되는지는 확인하지 못했다.

| 버튼 | 문서 기재 용량 |
| ---- | -------------: |
| FULL |          5.30L |
| 1/2  |           3.4L |
| 1/4  |           2.2L |

같은 자료의 PDF 100쪽은 각 버튼의 추출량을 개별 설정하는 절차를 설명한다. 따라서 1/4라는 버튼 이름으로 FULL 용량을 네 배 역산할 수 없다. PDF 180쪽의 스타벅스 전용 장비 사양은 서버 한 통을 1.5 US gal(약 5.7L)로 기재한다. 앞서 참고한 일반 판매용 [Dual SH DBC 33500.6001](https://commercial.bunn.com/33500.6001)의 공개 배치 규격은 1.9·3.8·5.7L이며 스타벅스 전용 설정과 구분한다.

앱의 1/4 급수 기준은 제조사 자료에서 확인한 2.2L로 적용했다. 국내 매장의 개별 기기 설정을 실측한 값으로 주장하지 않는다. 원두 흡수·증발을 생략하는 기존 재고 계산에 따라 HOT 완성량은 2,200ml, ICED는 얼음 660g을 정확히 넣었을 때 2,860ml다.
