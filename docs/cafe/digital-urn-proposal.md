# URN Digital 드립커피

2026-09-27 공식 자료를 조사하고 2026-09-28 사용자 확인·부재료 제조표·BUNN 기술자료로 아래 기준을 정했다.

## 확인한 공식 자료

- [스타벅스의 추출 장비 소개](https://about.starbucks.com/stories/2026/freshly-brewed-coffee-on-demand-how-the-innovative-clover-vertica-is-changing-starbucks-coffeehouses/)의 BUNN Digital Brewer 사진: 금속 추출 깔때기 2개, 사각 보온 서버 2개, 중앙 LCD, 측면 온수 탭과 배수 받침을 확인했다. 본문은 URN 내부 보온 장치와 추출 중 깔때기 이탈 방지를 설명한다. 미국 장비 소개이며 한국 매장의 정확한 모델 번호까지 확인한 자료는 아니다.
- [BUNN Dual SH Soft Heat DBC 33500.6001](https://commercial.bunn.com/33500.6001): 제조사가 공개한 배치 용량은 0.5·1·1.5 US gal, 표시상 약 1.9·3.8·5.7L다. 물량·바이패스·펄스·사전 적심은 커피 프로필별로 조정된다. 이 일반 제품 사양을 스타벅스 전용 기기의 `FULL`·`1/2`·`1/4` 버튼에 그대로 대응시키지 않는다.
- [BUNN 설치·운영 가이드](https://catalog.bunn.com/public/docs/52187.0000/E17/02/000/52187.0000.pdf): 필터·분쇄 원두·깔때기·빈 서버를 준비해 추출한다. 정해진 한 가지 추출 시간은 제시하지 않는다. 특정 매장의 HOT 5분 설정을 확정하는 근거는 아니다.
- [BUNN 분쇄·추출 가이드](https://resource.bunn.com/assets/web/pdfs/2021-Grinder_Equipment_Catalog_Web.pdf) 8쪽: 일반 DRIP 분쇄도의 권장 물 접촉 시간을 약 4~6분으로 제시한다. 스타벅스 전용 URN의 배치별 전체 작동 시간이나 별도 잔류액 배출 시간에 대한 규격은 아니다.
- [스타벅스 기본 추출 비율 자료](https://stories.starbucks.com/uploads/2013/09/Fact_Sheet_-_Four_Fundamentals_of_Brewing-1.pdf): 일반 안내는 분쇄 커피 10g / 물 180ml다. 검색 색인에서 본문을 확인했으며 현재 PDF 원본 URL은 404를 반환한다. 특정 URN 배치의 투입·산출 규격은 아니다.
- [스타벅스 코리아 추출 안내](https://www.starbucks.co.kr/coffee/higher_enjoy.do): 커피 메이커는 물 6온스당 2테이블스푼, 아이스 푸어 오버는 두 배로 진하게 추출한 뒤 얼음으로 희석한다. 아이스 푸어 오버 안내를 URN의 확정 레시피로 옮기지 않는다.

첨부 POS 화면은 HOT·ICED를 별도로 선택해 COW 원두를 변경하고, 확정 후 드립·아이스 드립 상품에 원두명을 표시하는 구조의 참고 자료다. 사진에 포함된 식별 정보·화면 원본은 저장소에 복사하지 않는다.

## 앱에 적용한 제조 기준

| 항목         | HOT 드립            | ICED 드립                                | 근거와 경계                                                                                                     |
| ------------ | ------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 급수 기준    | 2,200ml             | 2,200ml                                  | BUNN 스타벅스 전용 기술자료의 1/4 배치 2.2L를 적용                                                              |
| 분쇄 원두    | 118g                | 196g                                     | 2026-09-28 사용자 확인 원두량                                                                                   |
| 추출 산출량  | 2,200ml             | 농축 커피 2,200ml                        | 원두 흡수·증발을 생략한 재고 계산용 수율                                                                        |
| ICED 후처리  | 해당 없음           | 얼음 660g을 넣고 혼합, 완성 재고 2,860ml | 얼음 부피를 액체 부피로 계산하지 않음. 얼음이 전부 녹는 것으로 단순화하며 냉각·열평형은 계산하지 않는 게임 규칙 |
| 추출 시간    | 5분                 | 5분                                      | 2026-09-28 제공 제조표의 미추출 시 5분 안내·ICED 추출 5분과 일치                                                |
| 제공 전 보관 | URN 보온            | 실온·냉장 선택 후 바 선반·냉장고 보충    | HOT을 일반 냉장 재료로 처리하지 않음                                                                            |
| 품질 기한    | 제조 완료부터 1시간 | 실온 4시간·냉장 8시간                    | HOT은 2026-09-27 사용자 확인. ICED는 2026-09-28 제공 제조표                                                     |

HOT의 비냉장 분류 `room`은 URN 보온을 뜻한다. 일반 실온 선반이나 냉장고 보관으로 해석하지 않는다. 5분은 추출 시작부터 사용 가능한 배치가 되는 시점까지의 전체 게임 대기 시간이며 별도 드리핑 시간을 더하지 않는다.

ICED의 보관 기한 적용은 [부재료 제조표 대조](./preparation-source-comparison.md#아이스-커피-보관)를 따른다.

1/2·FULL 배치는 국내 기기 설정을 확인한 뒤 확장한다. 원두 종류별 시간 차이·펄스·바이패스·온도 설정도 이번 범위에 포함하지 않는다.

## COW와 판매 결정

첨부 POS에서 명확히 읽히는 하우스 블렌드·파이크 플레이스 로스트·콜롬비아·과테말라·케냐·카페 베로나·베란다 블렌드를 선택지로 삼았다. 초기 HOT·ICED 선택은 첨부 화면의 하우스 블렌드·파이크 플레이스 로스트다.

COW를 바꿔도 접수한 주문과 이미 추출한 배치의 원두·제조 시각·기한은 보존한다. 원두별 입고 규격·가격·개봉 기한은 실물 원가로 추측하지 않고 기존 게임 원두의 기준을 재사용한다.

POS 표기는 드립·아이스 드립을 사용하고 원문의 오늘의 커피·아이스 커피 ID와 이름은 유지한다. 첨부 화면의 Tall 4,500원은 기존 가격 데이터와 일치했지만 다른 사이즈나 현행 매장 가격을 새로 검증한 결과는 아니다. 가격별 근거는 [판매 가격](./menu-prices.md)에 둔다.

## 제조사 자료의 버튼별 용량

2026-09-28 사용자가 최대 7.6L와 1/4 1.9L의 관계를 제조사 자료로 확인하도록 요청해 BUNN의 스타벅스 전용 기술자료를 직접 읽었다.

[BUNN Starbucks Dual Soft Heat DBC 기술자료](https://learningcenter.bunn.com/pluginfile.php/6655/course/section/369/SPANISH%20SB%20DUAL%20COMPLETE%20TECH%20MANUAL.pdf#page=16)의 PDF 16쪽과 47쪽은 다음 용량을 기재한다. 스페인어판 자료이며 국내 기기에 같은 설정이 적용되는지는 확인하지 못했다.

| 버튼 | 문서 기재 용량 |
| ---- | -------------: |
| FULL |          5.30L |
| 1/2  |           3.4L |
| 1/4  |           2.2L |

같은 자료의 PDF 100쪽은 각 버튼의 추출량을 개별 설정하는 절차를 설명한다. 따라서 1/4라는 버튼 이름으로 FULL 용량을 네 배 역산할 수 없다. PDF 180쪽의 스타벅스 전용 장비 사양은 서버 한 통을 1.5 US gal(약 5.7L)로 기재한다. 앞서 참고한 일반 판매용 [Dual SH DBC 33500.6001](https://commercial.bunn.com/33500.6001)의 공개 배치 규격은 1.9·3.8·5.7L이며 스타벅스 전용 설정과 구분한다.
