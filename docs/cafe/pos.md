# POS 결정과 옵션 가격 근거

2026-09-26 사용자 확인으로 넓은 POS 화면과 한 손님의 여러 잔·커스텀·현금/카드 분할 결제를 선택했다. 주문 확정과 매출 반영은 전액 결제 시점으로 정한다. POS는 작업 화면이므로 게임 시간을 멈추지 않는다.

환불은 사용자 요청으로 후속 작업에 남긴다. 충전·회원·쿠폰·제휴 할인·상품권은 이번 범위에 포함하지 않으며 외부 결제나 카드 정보 수집 없이 게임 내부에서 처리한다.

## 금액과 영수증의 의미

게임의 `cash`는 입고 지출에 사용하는 운영 자금이다. 현금·카드 판매를 모두 합산하며 실제 현금 서랍의 잔액을 뜻하지 않는다. 판매액에서 입고 지출을 뺀 값도 원가 배분 전의 순이익으로 표시하지 않는다.

거래는 결제 시점의 상품·규격·가격·결제수단을 보존해야 한다. 이후 메뉴 수정이나 다음 근무일 전환으로 과거 영수증을 바꾸지 않는다. 출력 횟수는 브라우저에 인쇄를 요청한 횟수이며 실제 프린터 출력·인쇄 취소를 확인한 기록이 아니다.

현금영수증은 게임 내 재현이다. 발행금액은 거스름돈을 뺀 현금 적용액이며 카드 결제액은 제외한다. 개인·사업자 식별번호는 입력 화면에서만 사용하고 게임 행동·저장·백업·영수증에는 끝 네 자리만 남긴다.

## 커스텀의 게임용 기준

사용자 확인으로 **적게는 기본 투입량의 50%, 많이는 150%**를 적용한다. 실제 매장 계량 규칙으로 단정하지 않는다. 누적 컵 선·테두리 간격 자체를 곱하지 않고 해당 단계의 투입량에 적용한다. 우유·거품 변경 시에는 원래 피처에서 제공하던 비율을 유지해 이관 부족을 피한다.

원문에 없는 계량은 `data/shop/pos-customizations.json`의 승인된 게임값으로 보완한다. 일반 휘핑 50ml, 카라멜 드리즐은 카페 브륄레 프라푸치노의 4~5바퀴 중 4바퀴, 초콜릿 드리즐은 블랙 글레이즈드 라떼의 모카 1바퀴를 기준으로 삼았다. 명시된 원문 수량은 유지한다.

저지방 우유는 일반 우유의 게임 원팩·가격·보관·기한·재고 환산값을 재사용한다. 휘핑·로스트의 제조 근거는 [부재료 제조표 대조](./preparation-source-comparison.md), COW와 접수 당시 원두를 보존하는 결정은 [URN Digital](./digital-urn-proposal.md#cow와-판매-결정), 주문 라벨의 표시 예외는 [주문 라벨](./order-stickers.md)에 둔다.
