# POS 결정과 옵션 가격 근거

2026-09-26 사용자 확인으로 넓은 POS 화면과 한 손님의 여러 잔·커스텀·현금/카드 분할 결제를 선택했다. 초기에는 주문 확정과 매출 반영을 전액 결제 시점으로 정했다. 2026-09-30 사용자 승인으로 선제공 접수와 후불 정산을 추가했다. POS는 작업 화면이므로 게임 시간을 멈추지 않는다.

환불·완료 거래 취소와 카드 충전은 후속 범위다. 회원·쿠폰·할인·저장금액 카드·상품권·통합결제·현금IC·간편결제·BC QR·외상은 게임 내부에서 처리한다. 외부 결제나 실제 회원·카드 정보 수집은 하지 않는다. 화면의 카드 명칭은 게임 브랜드인 소복다방을 쓴다.

## 금액과 영수증의 의미

게임의 `cash`는 입고 지출에 사용하는 운영 자금이다. 실제로 수납한 모든 결제수단의 금액을 합산하며 실제 현금 서랍의 잔액을 뜻하지 않는다. 외상은 판매 시 매출과 미수금에 기록하고, 나중에 수납할 때 운영 자금과 외상 회수액만 증가한다. 컵보증금은 매출에서 분리한다. 판매액에서 입고 지출을 뺀 값도 원가 배분 전의 순이익으로 표시하지 않는다.

거래는 결제 시점의 상품·규격·가격·결제수단을 보존해야 한다. 이후 메뉴 수정이나 다음 근무일 전환으로 과거 영수증을 바꾸지 않는다. 출력 횟수는 브라우저에 인쇄를 요청한 횟수이며 실제 프린터 출력·인쇄 취소를 확인한 기록이 아니다.

현금영수증은 게임 내 재현이다. 발행금액은 거스름돈을 뺀 현금·저장금액 카드·상품권·현금IC 적용액과 해당 수단으로 회수한 외상 금액이다. 일반 신용카드 결제액은 제외한다. 발행 당시 금액을 보존하므로 이후 외상을 수납해도 기존 발행 이력은 달라지지 않는다. 개인·사업자 식별번호는 입력 화면에서만 사용하고 게임 행동·저장·백업·영수증에는 끝 네 자리만 남긴다.

## 커스텀의 게임용 기준

사용자 확인으로 **적게는 기본 투입량의 50%, 많이는 150%**를 적용한다. 실제 매장 계량 규칙으로 단정하지 않는다. 누적 컵 선·테두리 간격 자체를 곱하지 않고 해당 단계의 투입량에 적용한다. 우유·거품 변경 시에는 원래 피처에서 제공하던 비율을 유지해 이관 부족을 피한다.

원문에 없는 계량은 `data/shop/pos-customizations.json`의 승인된 게임값으로 보완한다. 일반 휘핑 50ml, 카라멜 드리즐은 카페 브륄레 프라푸치노의 4~5바퀴 중 4바퀴, 초콜릿 드리즐은 블랙 글레이즈드 라떼의 모카 1바퀴를 기준으로 삼았다. 명시된 원문 수량은 유지한다.

저지방 우유는 일반 우유의 게임 원팩·가격·보관·기한·재고 환산값을 재사용한다. 휘핑·로스트의 제조 근거는 [부재료 제조표 대조](./preparation-source-comparison.md), COW와 접수 당시 원두를 보존하는 결정은 [URN Digital](./digital-urn-proposal.md#cow와-판매-결정), 주문 라벨의 표시 예외는 [주문 라벨](./order-stickers.md)에 둔다.

## 주문 접수와 보류

- 상품·수량·온도·크기·커스텀·개인컵·리드·푸드 가열 요청을 손님 주문과 대조한 뒤 접수한다.
- 선제공은 결제 전에 주문을 제조·전달할 수 있게 한다. 전부 전달했는데 미정산이면 손님이 POS로 돌아온다. 결제 완료 전에는 손님 방문 완료로 처리하지 않는다.
- 보류는 결제·제조를 시작하기 전 최대 10건이다. 손님, 음료·푸드, COW, 포장, 혜택을 함께 보관한다. 다른 손님 응대 후 선택 재개하거나 현재 손님이 퇴장한 뒤 가장 오래된 주문을 이어서 받는다.
- 접수 후 상품을 변경할 수 없다. 혜택은 첫 결제 전까지 변경할 수 있으며, 첫 결제 시 유효성을 확인한 시각을 저장한다. 부분 결제 중에는 상품과 혜택을 고정한다.
- 보류 주문이나 미정산 선제공 주문이 있으면 신규 주문 마감을 진행할 수 없다. 외상으로 완료한 거래의 미수금은 다음 근무일에도 유지한다.
- 개인컵은 컵 재고를 소비하거나 반납 수량에 포함하지 않는다. 컵의 띠와 주문 라벨에 표시한다. 컵보증금은 입력값을 저장하며 개인컵에는 부과하지 않는다.
- 음료의 포장선택은 주문·라벨·영수증에 보존한다. 푸드는 선택한 포장으로 픽업대에서 준비한 뒤 전달한다.

쿠폰·할인 중복 규칙은 공개 자료로 모두 확정할 수 없어 사용자가 승인한 게임 기준을 적용한다.

1. 상품 한 개당 쿠폰 한 장. 해당 수량은 임직원·금액/메뉴 할인에서 제외한다. 한 줄에 여러 개가 있으면 아직 쿠폰을 적용하지 않은 개수만 남는다.
2. 계산 순서는 쿠폰 → Free Extra → 임직원 → 통신사 → 개인컵 → 수동 금액/비율 할인이다. 각 단계는 상품의 남은 금액을 넘지 않는다. 컵보증금은 할인 대상이 아니다.
3. 임직원과 통신사 혜택을 함께 적용할 수 있다. 통신사 혜택은 쿠폰을 쓰지 않은 음료 한 잔에 적용한다.
4. 정액 수동 할인은 대상 상품의 순서대로 배분하고, 비율 할인은 상품 한 개의 남은 금액에 적용해 원 미만을 버린다.
5. 같은 쿠폰을 여러 주문에 적용할 수 없다. 보류 주문에서 선택한 쿠폰은 예약되며 해제하거나 결제하면 예약 상태가 바뀐다. 만료·사용 여부는 첫 결제 때 다시 확인한다.
6. Free Extra를 켜면 다른 결제수단을 선택할 수 없다. 할인 후 결제액이 0원인 경우에는 Free Extra를 적용할 수 없다. 쿠폰 등으로 0원이 된 주문은 별도 ‘0원 결제 완료’로 접수한다.
7. 저장금액 카드의 잔액은 승인한 적용액만큼 즉시 차감한다. 하나의 주문에서 최대 20개 결제수단을 사용할 수 있다. 방문별은 해당 카드 결제 합계 3,000원 이상일 때 1개를 기록한다.

## 푸드

베이글·스콘·샌드위치·치즈케이크의 상품 데이터는 `apps/cafe/data/shop/food.json`에서 관리한다. 베이글 3,300원·샌드위치 5,900원은 [공식 모닝 세트 안내](https://www.shinsegaegroupnewsroom.com/starbucks-morning-set-sandwich-expansion/)의 세트 가격과 할인액에서 Tall 아메리카노 4,700원을 뺀 추정이다. 스콘 3,300원은 [공식 온라인 판매](https://www.ssg.com/item/itemView.ssg?itemId=2097001083956)를 참고했다. 치즈케이크 6,900원은 공식 단품 가격을 확인하지 못해 사용자가 직접 승인한 게임값이다.

실제 매장의 입고·가열·진열 규정은 제공된 원재료 자료에 없어 다음 값을 사용자에게 확인했다.

- 4개씩 입고하고 매입가는 판매가의 50%. 냉장 입고 후 48시간 보관한다.
- 쇼케이스는 최대 18개. 진열하면 원래 기한과 당일 자정 중 빠른 시각을 적용하며, 그 전에 마감하면 남은 진열품을 폐기한다. 냉장고로 되돌려도 진열 기한은 늘어나지 않는다.
- 베이글·스콘 30초, 샌드위치 60초 가열. 케이크는 가열할 수 없다. 가열 중 다른 업무를 할 수 있으며 완료 시각은 저장·복원한다.
- 접수한 주문에서 다음 푸드를 집어 오븐 또는 픽업대로 옮긴다. 가열 요청과 포장이 맞아야 전달할 수 있다. 기한 초과 시 준비 중인 푸드도 폐기한다.
- 폐기 수량·입고 지출·전달 수량을 결산에 반영한다. 음료와 푸드가 모두 전달돼야 고객 응대를 마친다.
