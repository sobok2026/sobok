# 월드 공간 구분과 백룸 보충 동선

2026-09-27 조사·협의. **후방 확장과 백룸→바 직접 보충을 구현했다.** 사용자 확인을 받은 치수·운반 단위·보관 용량과 실제 배치를 기록한다.

2026-09-28 사용자 요청과 위치 확인에 따라 소모품·식기 반납·분리수거를 왼쪽 기존 컵 반납 구역의 통합 컨디먼트 바에 모았다. 오른쪽 소모품 가구와 독립 분리수거함은 제거했다. 사진 근거와 외형은 [장비 그래픽](./graphics.md#통합-컨디먼트-바)에 기록한다.

## 확인된 범위

- 자료 조사와 배치 협의 후 사용자가 구현을 요청했다.
- 14×16 월드, 폭 1.4단위의 열린 직원 출입구를 사용한다.
- 원팩·완성 용기는 한 번에 하나씩 운반하고 백룸에서 개봉·라벨 작업을 한다.
- 바의 재료는 품목별 2용기, 일회용 컵은 종류별 12개, 컨디먼트는 품목별 20개다. 컵은 최대 6개씩 운반한다.
- 백룸에는 재고·준비·세척 기능을 포함한다. 직원 휴게·사무 공간은 사용자 선택으로 제외한다.
- 기존 매장 뒤쪽을 확장해 백룸을 배치한다.
- 백룸의 예비 재고를 직원이 바까지 직접 운반하고 보충하는 흐름을 설계에 포함한다.
- 한국 매장을 우선 참고하고, 공개 자료가 부족한 운영 지원 공간은 해외 공식 자료와 관계 기관의 자료로 보완한다.
- 아래 네 구역은 이 게임을 위한 기능 분류다. 조사한 공개 자료에서 전 세계 매장에 공통인 정확히 네 구역의 표준 평면은 확인하지 못했다.
- 이 문서에서 **플로어**는 손님의 대기·이용·반납·이동을 포함한 고객 공간을 뜻한다.

## 확장 전 배치

확장 전 바닥은 14×12 월드 단위였다. 실측한 스타벅스 매장 치수가 아니다.

- 전면의 긴 카운터에 POS, 컵, 에스프레소·스팀, 콜드 브루 탭, 정수·얼음, 소스, 혼합, 토핑, 픽업이 줄지어 있다.
- 같은 직원 공간의 뒤쪽에 세척·도구 선반·준비·콜드 브루 추출·실온 선반·냉장고가 있고, 오른쪽 벽에 창고가 있다.
- 바와 후방 작업대 사이에 방을 나누는 벽이나 백룸 출입구가 없다.
- 직원은 POS 왼쪽 출입구로 고객 공간에 나간다. 손님 출입구는 전면 오른쪽이다.
- 두 테이블 사이 창가의 컨디먼트 바가 소모품 제공과 컵 반납을 함께 담당한다.

## 권장하는 네 구역

| 구역   | 목적                                  | 배치할 대상                                                              | 공간 경계                                                                    |
| ------ | ------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| POS    | 주문 접수·확인·결제                   | POS, 고객 주문 위치                                                      | 플로어와 만나는 카운터 한쪽. 픽업 대기와 구분한다.                           |
| 바     | 주문받은 음료의 즉시 제조·마무리·전달 | 컵, 핫 바, 콜드 바, 사용 중인 재료, 깨끗한 도구, 픽업                    | 고객에게 제조가 보이는 직원 공간. 핫·콜드 구역은 같은 바 안의 작업 묶음이다. |
| 백룸   | 다음 주문을 위한 재고·배치 준비·세척  | 예비 냉장·상온 재고, 컵·소모품 박스, 준비대, 장시간 추출, 회수·세척·건조 | 바 뒤의 벽으로 구분하고 직원 통로로 연결한다.                                |
| 플로어 | 대기·수령·매장 이용·반납·퇴장         | 주문·픽업 대기, 객석, 컨디먼트, 컵 반납, 분리수거                        | 고객의 주 통로를 비우고 직원의 컵 회수 경로와 접속시킨다.                    |

픽업은 바에서 완성품을 넘기는 접점으로 둔다. 손님이 서는 픽업 대기 공간은 플로어에 속한다. POS 역시 직원 조작면과 고객 대기면을 구분한다.

### 바 안의 배치

- **핫 바:** 컵 → 에스프레소·스팀 → 마무리로 연결한다.
- **콜드 바:** 얼음·정수·소스·주문용 블렌더·혼합을 가깝게 둔다. 콜드 브루 서빙 탭도 여기에 둔다.
- **사용 중인 재료:** 우유·폼 등은 작업용 냉장고에, 준비된 실온 재료는 작업용 선반에 둔다. 한 잔을 만들기 위해 백룸까지 재료를 찾으러 가지 않도록 한다.
- **깨끗한 컵·피처:** 사용 위치에서 꺼내고, 백룸에서 씻은 뒤 이 위치까지 가져와 정리한다.
- **픽업:** 제조의 끝에 두고, 대기 중인 손님이 POS 앞을 막지 않도록 한다.

### 백룸 안의 배치

백룸은 하나의 방 안에서 세 작업 구역으로 나눈다. 세 구역을 각각 별도 방으로 만드는 안은 아니다.

1. **세척 구역:** 직원 출입 동선 가까이에 회수 용기 놓는 자리 → 세척 → 건조 자리를 둔다. 세척 도구는 별도 수납에 둔다.
2. **준비 구역:** 계량·배합·라벨 작성과 콜드 브루 장시간 추출을 수행한다. 세척수와 회수 용기가 준비 상판을 거치지 않도록 나눈다.
3. **재고 구역:** 예비 냉장 재료, 실온 원팩, 컵·리드·소모품 박스를 보관한다. 준비 구역 및 바 보충 경로와 연결한다.

준비 완료품은 알맞은 냉장·실온 위치로 옮긴다. 영업 중 사용하는 양과 후방 예비량을 구분하고, 바에서 쓸 양은 직접 운반해 보충한다. 바에는 품목별 2용기까지 보관한다. 원팩·완성 배치는 용기째 운반하고 일회용 컵은 최대 6개씩 운반한다.

### 플로어 안의 배치

- 손님 출입구는 현재처럼 전면 오른쪽에 둔다.
- POS 대기와 픽업 대기를 카운터 양 끝에 둔다.
- 컨디먼트 바는 왼쪽 직원 출입구 가까이에 둬 소모품 보충과 컵 회수 경로를 연결한다. 손님은 픽업 후 이용한다.
- 같은 가구 안에서 새 소모품을 꺼내는 자리, 사용한 컵을 놓는 열린 선반, 분리수거구를 나눈다. 가구 앞의 화분은 창가 끝으로 옮겨 접근 통로를 비운다.
- 테이블·의자는 입구 ↔ POS ↔ 픽업을 잇는 주 통로 밖에 둔다.

## 후방 확장 배치

**확정한 방향:** 현재 바와 플로어를 기준으로 후방에 백룸을 붙인다. 외곽은 14×16 월드 단위이며 뒤쪽에 4단위를 추가했다. 백룸 분리 벽은 z=-5.85, 열린 직원 출입구는 x=-5.8을 중심으로 폭 1.4단위다. 이 치수도 사용자가 확인했다.

```text
매장 뒤쪽
┌─────────────────────────────────────────┐
│ 백룸                                    │
│ 회수·세척·건조 │ 배치 준비·추출 │ 예비 재고 │
│              직원 작업 통로             │
├── 직원 출입 ─────────────────────────────┤
│ 바: 작업용 냉장·선반·깨끗한 도구         │
│              제조 작업 통로             │
│   POS      핫 바       콜드 바     픽업   │
│ ↑ 직원 통로                             │
│ 통합 컨디먼트 바          플로어        │
│                 객석                    │
└───────────────────────────── 손님 출입 ─┘
매장 앞쪽
```

개념 배치이며 축척 도면이 아니다. 왼쪽 직원 통로는 플로어·바·백룸을 연결한다. 백룸 출입구는 직원 공간으로 열리며 회수 동선 가까이에 둔다.

이동 흐름:

- 손님: 출입구 → POS → 픽업 → 컨디먼트 → 객석 → 반납 → 출입구. 포장 손님은 객석·컵 반납을 거치지 않는다.
- 주문 제조: 바의 컵·재료 → 핫 바 또는 콜드 바 → 픽업.
- 보충·준비: 백룸 재고 → 필요한 배치 준비 → 바의 알맞은 보관 위치.
- 컵·도구 회수: 플로어·바 → 직원 통로 → 백룸 세척·건조 → 바의 컵·도구 선반.

## 백룸에서 바까지 직접 보충하는 흐름

### 재고를 놓는 장소

| 장소                     | 역할                                           | 다음 이동                                 |
| ------------------------ | ---------------------------------------------- | ----------------------------------------- |
| 백룸 냉장 보관           | 냉장 원팩과 냉장이 필요한 예비 배치            | 준비 구역 또는 바 작업용 냉장고           |
| 백룸 실온 보관           | 실온 원팩, 컵·소모품 예비 재고                 | 준비 구역, 바 보관대 또는 플로어 컨디먼트 |
| 백룸 준비 구역           | 원재료 투입, 배치 제조, 라벨 작성, 장시간 추출 | 알맞은 냉장·실온 보관 위치                |
| 운반 중인 손             | 출발지에서 집어 도착지까지 옮기는 물건         | 목적지에 놓거나 출발지로 반납             |
| 바 작업용 냉장·실온 보관 | 주문 제조에 사용할 재료                        | 각 음료의 제조 단계에서 소비              |
| 바 컵·도구 보관대        | 바로 사용할 컵과 깨끗한 도구                   | 음료 제조에 사용                          |

후방에 재료가 있어도 바의 사용량이 없으면 보충 업무가 발생한다. 물건은 도착지에 내려놓아야 그곳의 사용 가능한 재고가 된다. 준비 구역에서 사용할 원재료와 바에서 음료에 사용할 재료도 사용 위치를 구분한다.

| 시럽 등 실온 원재료  | 입고 → 백룸 실온 보관 → 집기 → 직원 통로 → 바 사용 위치     | 바에 보관하고 개봉·라벨·기한 조건을 충족했을 때 |
| 폼·소스 등 준비 배치 | 백룸 원재료 → 준비·라벨 → 집기 → 바의 냉장고 또는 실온 선반 | 해당 배치를 바에 보관했을 때                    |
| 콜드 브루            | 백룸 추출 → 회수·라벨 → 냉장 보관·운반 → 바 서빙용 공급     | 바에 공급해 서빙 탭에서 쓸 수 있게 되었을 때    |
| 일회용 컵            | 백룸 컵 재고 → 집기 → 바 컵 보관대                          | 같은 종류·사이즈의 자리에 보충했을 때           |
| 냅킨·빨대·설탕       | 백룸 소모품 재고 → 집기 → 플로어 컨디먼트                   | 해당 소모품 자리에 보충했을 때                  |
| 다회용 컵·피처       | 사용·회수 → 백룸 세척·건조 → 집기 → 바 컵·도구 보관대       | 씻은 용기를 제자리에 놓았을 때                  |

원팩의 개봉·라벨은 백룸 냉장고·창고에서 한다. 준비 배치는 백룸 준비대·추출대에서 라벨을 붙인다. 콜드 브루는 바 냉장고에 보관한 배치를 서빙 탭에서 소비하며 별도의 배관 연결 동작은 두지 않는다. 모두 게임의 작업 연결이며 스타벅스의 설비 표준을 뜻하지 않는다.

### 플레이어가 수행하는 보충

1. 바에서 부족한 품목을 확인한다. 안내는 **바에 없음 / 백룸에 있음**과 **입고 또는 준비 필요**를 구분한다.
2. 백룸의 해당 보관 위치에서 운반할 물건을 고른다.
3. 물건을 집어 직원 통로로 바까지 이동한다. 손에 든 물건과 목적지를 표시한다.
4. 품목에 맞는 냉장·실온 위치나 컵 보관대에 내려놓는다. 이때 바의 사용 가능 여부를 갱신한다.
5. 잘못된 장소이거나 공간이 부족하면 이유를 알리고 물건은 손에 남긴다. 남은 물건을 돌려놓을 때도 출발지까지 직접 운반한다.

위 조작은 기존의 E 집기·내려놓기와 한 번에 들 수 있는 물건의 제한에 맞춰 설계한다. 원팩·완성 용기는 하나씩, 일회용 컵은 기존 보충량인 최대 6개씩 운반한다.

### 재고·기한·소비 원칙

- 재고는 **백룸에 놓인 양 / 운반 중인 양 / 바에 놓인 양**을 구분한다. 물건을 집거나 내려놓는 것은 위치 이동이며 판매·소비·폐기가 아니다.
- 운반 중인 양은 출발지와 도착지 어느 쪽에도 중복해서 세지 않는다. 보충을 중단해도 실제 놓인 위치에 따라 남은 양을 관리한다.
- 이동 중에도 개봉·제조 시각, 라벨, 잔량과 기한을 유지한다. 옮기거나 라벨을 다시 쓴 시점으로 기한을 늘리지 않는다.
- 바에서 음료를 제조할 때는 바에 보충된 사용 가능한 재료를 소비한다. 백룸 준비에서는 그 작업에 확보한 원재료를 소비한다.
- 준비 배치에 투입한 원재료는 투입할 때 차감하고, 완성 배치를 음료에 사용할 때 다시 차감하지 않는다.
- 운반 중 저장·복원할 때 물건, 잔량, 원래 보관 위치와 목적지를 이어간다.

이 원칙은 현재의 용기 운반·라벨·기한·재료 소비 규칙을 공간 구분에 맞게 연결한 설계다. 컵·소모품의 기존 수량과 입고 가격은 [임시 규칙](./prototype-rules.md)을 참조하며, 추가한 재료 한도인 품목별 2용기는 사용자가 확인한 게임 규칙이다.

## 구현 연결

- 작업대 위치와 월드 범위는 `content/stations.ts`, 벽·출입구·배치는 `world/interior.ts`에서 관리한다. 이동 충돌과 시선 판정에 백룸 벽을 포함해 벽 너머 장비를 사용할 수 없게 한다.
- `prep`은 백룸 준비, `blender`는 바 주문 장비를 담당한다. 준비용과 주문용 블렌더는 서로 다른 작업 위치와 작동 상태를 사용한다.
- `fridge`·`stock`은 백룸 보관, `bar-fridge`·`shelf`는 바 보관이다. `location: 'bar'`인 사용 가능한 배치만 주문 제조에 소비한다. 준비의 `stockArea: 'backroom'`은 백룸의 개봉·라벨 완료 배치를 소비한다.
- `take-batch` → `store-batch` / `return-batch`는 용기를 옮기고 출발 위치를 기록한다. `take-cups` → `place-cups` / `return-cups`는 최대 6개를 운반하며 한도 초과분은 손에 남긴다.
- `condiment`는 컵 반납·회수·표면 청소, `supplies`는 소모품 제공·보충, `trash`는 쓰레기 비우기를 담당한다. 세 작업 구역은 왼쪽의 한 가구 안에 있으며, 시선 판정 범위를 겹치지 않게 둔다. 손님은 픽업 후 왼쪽 소모품 정리함을 이용하고, 매장 이용을 마친 뒤 같은 가구의 반납 선반으로 이동한다. 두 작업 모두 가구를 바라보도록 방향을 맞춘다.
- 월드의 z 저장 범위는 -10~6이다. 새 저장 필드 `cupDelivery`와 배치의 `carryFrom`은 필수다. 프로젝트의 현재 형식 검증 정책을 따라 이전 저장을 변환하는 코드는 두지 않는다.

## 확인 결과

- 브라우저에서 직원 출입구를 통과해 백룸 창고·냉장고에 접근하고, 같은 통로로 물건을 바까지 운반했다.
- 컵 6개를 집은 상태로 저장·새로고침한 뒤 보충했다. 후방 12→6개, 바 2→8개, 운반 0개로 수량을 확인했다.
- 백룸에서 우유 1,000ml를 개봉·라벨 작성하고 바 냉장고에 보관했다. 기존 100ml와 함께 2/2용기로 표시되며 기한이 유지됐다.
- 바에 세 번째 용기를 놓는 행동은 거부하고 물건은 손에 유지했다. 백룸으로 돌려놓은 뒤 저장 스키마가 유효했다.
- 백룸 원재료 100ml를 소비할 때 백룸 1,000→900ml, 바 1,100ml 유지로 사용 위치를 구분했다.
- 백룸에서 벽을 향해 바라볼 때 바 냉장고 상호작용은 나타나지 않았다.

현재 구현과 플레이 설명은 [게임 설계](./design.md) 및 [README](../../apps/cafe/README.md)에 반영한다.
