# 월드 공간과 백룸 동선의 근거

2026-09-27 사용자는 기존 매장 뒤쪽을 확장해 백룸을 만들고 예비 재고를 바까지 직접 운반하는 방식을 선택했다. 백룸에는 재고·준비·세척을 포함하고 직원 휴게·사무 공간은 제외한다.

초기 외곽은 14×16 월드 단위였다. 2026-09-29 사용자는 스타벅스 더북한산점 1층을 기준으로 크기와 동선도 변경하는 방향을 선택했다. 객석과 통로가 좁다는 후속 피드백을 반영해 20×24였던 외곽을 24×30 월드 단위로 넓혔다. 실측 치수가 아니라 사진의 구역 관계와 이동 여유를 반영한 크기다. 백룸으로 이어지는 폭 1.5단위의 열린 직원 출입구와 업무 기능은 유지한다. 바의 재료는 품목별 2용기까지 두고 원팩·완성 용기는 하나씩 운반한다. 컵·소모품의 수량 기준은 [게임용 규칙](./prototype-rules.md#임시-수치와-단순화)에 둔다.

한국 매장을 우선 참고하고 공개 자료가 부족한 운영 지원 공간은 해외 공식 자료와 관계 기관 자료로 보완했다. 아래 네 구역은 게임을 위한 기능 분류이며 전 세계 매장에 공통인 표준 평면으로 확인한 것은 아니다. 여기서 플로어는 손님의 대기·이용·반납·이동 공간을 뜻한다.

## 구역을 나누는 기준

| 구역   | 목적                                  | 배치할 대상                                                              | 공간 경계                                                                    |
| ------ | ------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| POS    | 주문 접수·확인·결제                   | POS, 고객 주문 위치                                                      | 플로어와 만나는 카운터 한쪽. 픽업 대기와 구분한다.                           |
| 바     | 주문받은 음료의 즉시 제조·마무리·전달 | 컵, 핫 바, 콜드 바, 사용 중인 재료, 깨끗한 도구, 픽업                    | 고객에게 제조가 보이는 직원 공간. 핫·콜드 구역은 같은 바 안의 작업 묶음이다. |
| 백룸   | 다음 주문을 위한 재고·배치 준비·세척  | 예비 냉장·상온 재고, 컵·소모품 박스, 준비대, 장시간 추출, 회수·세척·건조 | 바 뒤의 벽으로 구분하고 직원 통로로 연결한다.                                |
| 플로어 | 대기·수령·매장 이용·반납·퇴장         | 주문·픽업 대기, 객석, 컨디먼트, 컵 반납, 분리수거                        | 고객의 주 통로를 비우고 직원의 컵 회수 경로와 접속시킨다.                    |

픽업은 바에서 완성품을 넘기는 접점으로 둔다. 손님이 서는 픽업 대기 공간은 플로어에 속한다. POS 역시 직원 조작면과 고객 대기면을 구분한다.

바에는 즉시 제조에 필요한 재료·장비·깨끗한 도구를 모아 한 잔마다 백룸까지 찾으러 가지 않게 한다. 백룸의 회수·세척 동선은 출입구 가까이에 두고 세척수와 회수 용기가 배합 상판을 거치지 않게 나눈다.

후방 재고와 바의 사용량을 구분해 보충 업무가 생기도록 한다. 물건은 도착지에 내려놓아야 그곳의 재고가 된다. 운반 자체는 소비가 아니며 양쪽 위치에 중복해 세지 않는다.

## 개념 배치

```text
매장 뒤쪽
┌─────────────────────────────────────────┐
│ 백룸                                    │
│ 회수·세척·건조 │ 배치 준비·추출 │ 예비 재고 │
│              직원 작업 통로             │
├────────────────────────── 직원 출입 ────┤
│ 바: 작업용 냉장·선반·깨끗한 도구         │
│              제조 작업 통로             │
│ 쇼케이스┐ POS  머신 1 펌프 머신 2 픽업   │
│         └────────────── 반납·소모품  ↑   │
│        주문·픽업 대기         직원 통로 │
│                        원형 테이블      │
│ 계단·벽돌 구획    통로   긴 공용 테이블  │
│ 벽면 벤치·MD 진열       창가 가죽 좌석   │
└──────────────── 손님 출입 ──────────────┘
매장 앞쪽
```

개념 배치이며 축척 도면이 아니다. 오른쪽 직원 통로는 플로어·바·백룸을 연결한다. 백룸 출입구는 직원 공간으로 열리며 회수 동선 가까이에 둔다.

소모품·식기 반납·분리수거는 한 가구에 모으되 내부에서 구분한다. 처음에는 왼쪽에 두었으나, 실제 더북한산점에 맞춘 재배치 요청에 따라 확대 사진의 오른쪽 반납 가구 위치로 옮겼다. 직원의 보충·회수 경로와 손님의 이용 경로를 연결한다. 가구 자체의 참고 자료는 [통합 컨디먼트 바](./graphics.md#통합-컨디먼트-바)에 있다.

## 더북한산점 1층 적용

[공식 소개](https://www.shinsegaegroupnewsroom.com/starbucks-nature-healing-space-seoul/)는 1층 49석을 명시한다. [1층 방문 사진](https://www.koreatodo.com/starbucks-the-bukhansan)에서는 입구의 상품 진열, 벽돌로 감싼 계단 구획, 안쪽 주문 바, 긴 공용 테이블과 창가 좌석, 크림색 벽면 벤치를 확인했다. 이 구역 관계를 현재 월드에 반영했다. 사진 사이에서 보이지 않는 연결부와 가구 간격은 추정이다.

- 월드 범위는 `x=-12…12`, `z=-10…20`다. 입구는 앞쪽 중앙, 주문 바는 뒤쪽, MD 진열과 계단은 왼쪽, 공용 테이블과 창가 좌석은 오른쪽에 둔다.
- 좌석은 원형 테이블 8석, 공용 테이블 14석, 창가 암체어 6석, 벽면 벤치와 맞은편 의자 12석, 안쪽 2인 테이블 6석, 창가 스툴 3석으로 총 49석을 표현한다. 좌석별 정확한 실제 위치를 확인한 도면은 아니다.
- 주문 손님은 중앙 통로로 입장해 왼쪽 POS로 이동하고, 오른쪽 픽업·소모품 구역을 거친다. 매장 이용 테이블은 전 층에서 선택하며, 위층은 실제 계단을 따라 이동한다. 이용 후 반납하거나 테이블에 컵을 남기고 중앙 출입구로 퇴장한다.
- 1층 창가 가죽 의자는 정원 쪽 통창을 바라보는 한 줄로 배치했다. 공용 테이블은 분리된 작은 탁자 대신 이어진 긴 상판으로 표현한다.
- 직원은 오른쪽 통로를 통해 객석·바·백룸을 오간다. 회전된 의자·벤치·소파, 원형 테이블·화분, 기둥·진열대·난간·벽에 실제 형태와 층 높이를 반영한 충돌을 적용한다. 얇은 장애물을 달리기로 통과하지 않도록 이동을 짧은 구간으로 나누며, 가구 뒤의 작업대를 벽 너머로 선택할 수 없게 시선도 막는다.
- 후속 요청과 사용자 승인으로 2층·루프탑 및 실제로 오가는 계단까지 추가했다. 공개되지 않은 실측 치수와 백룸 구조는 게임용 구성이다.

실내 마감과 메뉴판의 사진 근거 및 재현 범위는 [매장 인테리어](./graphics.md#매장-인테리어와-메뉴판)에 기록한다.

## 층간 이동과 기자재 재배치

2026-09-29 사용자는 2층·루프탑과 계단 이동, 두 번째 머신의 개별 추출·스팀 조작을 승인했다.

- 1층 높이 0, 2층 높이 4, 루프탑 높이 8로 둔다. 층고는 게임용 추정치다. 왼쪽 계단의 두 경사 구간과 중간참을 따라 높이가 연속적으로 변한다. 바닥 개구부·난간·층별 장애물을 함께 적용해 층 사이로 떨어지거나 가구를 통과하지 않게 한다.
- 2층은 통창, 가죽 창가 좌석, 원형·직사각 테이블과 벽면 벤치로 138석을 표현한다. 4인 테이블 열 사이 간격을 넓히고, 중앙에 긴 공용 테이블 두 개를 둔다. 창가 라운지는 낮은 테이블을 사이에 두고 서로 마주 보게 배치했다. 루프탑은 목재 데크, 파라솔 테이블, 회색 소파와 포토존으로 66석을 표현한다. 공식 좌석 수를 맞췄지만 테이블별 배치는 공개 사진에 근거한 추정이다.
- 사용자 확인에 따라 전 층 테이블에서 컵 회수·닦기를 할 수 있다. 긴 공용 테이블과 창가 바의 구역을 포함해 총 93개 청소 표면을 관리한다. 손님도 위층을 이용하고 컵·오염을 남긴다. 회수한 컵은 1층 세척대로 운반하고 원래 테이블로 돌아와 닦는다. 플레이어가 의자에 앉거나 자기 컵을 놓는 기능은 이 요청에 포함하지 않는다.
- 테이블의 층·상판·좌석 방향·접근 동선은 `content/tables.ts`에서 함께 정의한다. 같은 배치를 렌더링, 충돌, 선택 판정, 손님 이동과 청소 상태에 사용한다. 다른 층의 테이블이나 1층 작업대를 바로 조작할 수 없고, 업무 안내 표식은 먼저 계단의 진입부·중간참을 가리킨다.
- 계단 구획은 층마다 겹친 얇은 벽 대신 층을 관통하는 불투명 벽과 중앙 구획으로 감쌌다. 바닥 개구부와 계단 벽의 좌표를 공유한다.
- 전면 바는 ㄱ자로 접속한 푸드 쇼케이스 옆의 POS·컵 → 머신 1 → 펌프 → 머신 2 → 혼합·픽업 순서다. 머신 중심 간격은 6.3에서 2.7단위로 줄여 사진의 밀집된 바 구성을 반영했다. 각 머신의 조작면과 스팀 봉은 직원 통로를 향한다. URN·콜드 브루 탭·그라인더·블렌더·아이스 빈·워터·토핑은 후방 작업대에, 바 냉장고는 상판 아래에 둔다. 실온 재료는 오른쪽 보조 선반에 둔다. 사진으로 확인한 부분과 추정은 [기자재 근거](./graphics.md#더북한산점-기자재-배치)를 따른다.
- `espresso`·`espresso-2`, `steam`·`steam-2`는 별도 작업대다. 컵이나 보조 용기를 내려놓은 곳에 맞춰 해당 음료의 추출·스팀 단계를 연결한다. 가동 작업은 시작한 작업대와 용기를 유지하고, 다른 머신을 조작해도 진행되지 않는다. 기존 한 잔씩 제조하는 주문 구조는 유지한다.

브라우저에서 1층→2층→루프탑 왕복, 계단 중간 저장·복원, 2번 머신의 2샷 추출, 2번 스팀 가동 중 1번 머신 추출과 스팀 자동 완료를 확인했다. 위치와 머신 선택을 포함한 저장 스키마도 통과했다.

후속 보완에서는 렌더링된 장애물을 기준으로 전 층 93개 테이블의 보행 접근과 손님의 착석·반납 경로를 확인했다. 실제 장면에서 93개 테이블과 28개 기자재의 선택 판정, 계단 왕복과 벽 충돌을 확인했고, 모든 테이블의 컵 회수·반납·닦기 후 컵 수량 보존과 저장 스키마를 확인했다. 실제 UI에서도 2층 테이블의 컵 2개 회수, 세척대 반납, 천 집기·닦기·완료와 저장을 확인했다. TypeScript·프로덕션 빌드·포맷 검사를 통과했다. 검증용 테스트 파일은 추가하지 않았다.
