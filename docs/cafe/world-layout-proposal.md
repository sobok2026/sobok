# 월드 공간 구분과 백룸 보충 동선

2026-09-27 조사·협의. **후방 확장과 백룸→바 직접 보충을 사용자 선택으로 확정했다.** 아래에는 확정한 방향과 이를 구체화한 설계안을 기록한다. 세부 치수와 새 운반 규칙은 구현 전에 정한다.

## 확인된 범위

- 이번 작업은 자료 조사와 배치안 정리까지다.
- 백룸에는 재고·준비·세척 기능을 포함한다. 직원 휴게·사무 공간은 사용자 선택으로 제외한다.
- 기존 매장 뒤쪽을 확장해 백룸을 배치한다.
- 백룸의 예비 재고를 직원이 바까지 직접 운반하고 보충하는 흐름을 설계에 포함한다.
- 한국 매장을 우선 참고하고, 공개 자료가 부족한 운영 지원 공간은 해외 공식 자료와 관계 기관의 자료로 보완한다.
- 아래 네 구역은 이 게임을 위한 기능 분류다. 조사한 공개 자료에서 전 세계 매장에 공통인 정확히 네 구역의 표준 평면은 확인하지 못했다.
- 이 문서에서 **플로어**는 손님의 대기·이용·반납·이동을 포함한 고객 공간을 뜻한다.

## 현재 월드

현재 바닥은 14×12 월드 단위다. 실측한 스타벅스 매장 치수가 아니다.

- 전면의 긴 카운터에 POS, 컵, 에스프레소·스팀, 콜드 브루 탭, 정수·얼음, 소스, 혼합, 토핑, 픽업이 줄지어 있다.
- 같은 직원 공간의 뒤쪽에 세척·도구 선반·준비·콜드 브루 추출·실온 선반·냉장고가 있고, 오른쪽 벽에 창고가 있다.
- 바와 후방 작업대 사이에 방을 나누는 벽이나 백룸 출입구가 없다.
- 직원은 POS 왼쪽 출입구로 고객 공간에 나간다. 손님 출입구는 전면 오른쪽이다.
- 두 테이블 사이 창가의 컨디먼트 바가 소모품 제공과 컵 반납을 함께 담당한다.

## 권장하는 네 구역

| 구역   | 목적                                  | 배치할 대상                                                              | 공간 경계                                                                    |
| ------ | ------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| POS    | 주문 접수·확인·결제                   | POS, 고객 주문 위치                                                      | 플로어와 만나는 카운터 한쪽. 픽업 대기와 구분한다.                           |
| 바     | 주문받은 음료의 즉시 제조·마무리·전달 | 컵, 핫 바, 콜드 바, 사용 중인 재료, 깨끗한 도구, 픽업                    | 고객에게 제조가 보이는 직원 공간. 핫·콜드 구역은 같은 바 안의 작업 묶음이다. |
| 백룸   | 다음 주문을 위한 재고·배치 준비·세척  | 예비 냉장·상온 재고, 컵·소모품 박스, 준비대, 장시간 추출, 회수·세척·건조 | 바 뒤의 벽으로 구분하고 직원 통로로 연결한다.                                |
| 플로어 | 대기·수령·매장 이용·반납·퇴장         | 주문·픽업 대기, 객석, 컨디먼트, 컵 반납, 분리수거                        | 고객의 주 통로를 비우고 직원의 컵 회수 경로와 접속시킨다.                    |

픽업은 바에서 완성품을 넘기는 접점으로 둔다. 손님이 서는 픽업 대기 공간은 플로어에 속한다. POS 역시 직원 조작면과 고객 대기면을 구분한다.

### 바 안의 배치

- **핫 바:** 컵 → 에스프레소·스팀 → 마무리로 연결한다.
- **콜드 바:** 얼음·정수·소스·주문용 블렌더·혼합을 가깝게 둔다. 콜드 브루 서빙 탭도 여기에 둔다.
- **사용 중인 재료:** 우유·폼 등은 작업용 냉장고에, 준비된 실온 재료는 작업용 선반에 둔다. 한 잔을 만들기 위해 백룸까지 재료를 찾으러 가지 않도록 한다.
- **깨끗한 컵·피처:** 사용 위치에서 꺼내고, 백룸에서 씻은 뒤 이 위치까지 가져와 정리한다.
- **픽업:** 제조의 끝에 두고, 대기 중인 손님이 POS 앞을 막지 않도록 한다.

### 백룸 안의 배치

백룸은 하나의 방 안에서 세 작업 구역으로 나눈다. 세 구역을 각각 별도 방으로 만드는 안은 아니다.

1. **세척 구역:** 직원 출입 동선 가까이에 회수 용기 놓는 자리 → 세척 → 건조 자리를 둔다. 세척 도구는 별도 수납에 둔다.
2. **준비 구역:** 계량·배합·라벨 작성과 콜드 브루 장시간 추출을 수행한다. 세척수와 회수 용기가 준비 상판을 거치지 않도록 나눈다.
3. **재고 구역:** 예비 냉장 재료, 실온 원팩, 컵·리드·소모품 박스를 보관한다. 준비 구역 및 바 보충 경로와 연결한다.

준비 완료품은 알맞은 냉장·실온 위치로 옮긴다. 영업 중 사용하는 양과 후방 예비량을 구분하고, 바에서 쓸 양은 직접 운반해 보충한다. 구체적인 보충 수량·운반 단위는 별도 게임 규칙 결정이 필요하다.

### 플로어 안의 배치

- 손님 출입구는 현재처럼 전면 오른쪽에 둔다.
- POS 대기와 픽업 대기를 카운터 양 끝에 둔다.
- 컨디먼트는 픽업 후 객석으로 이동하면서 이용할 수 있게 둔다.
- 반납·분리수거는 왼쪽 직원 출입구 가까이에 모아 회수 경로를 짧게 한다. 새 소모품을 꺼내는 상판과 사용한 컵을 놓는 상판을 나눈다.
- 테이블·의자는 입구 ↔ POS ↔ 픽업을 잇는 주 통로 밖에 둔다.

## 후방 확장 배치

**확정한 방향:** 현재 바와 플로어를 기준으로 후방에 백룸을 붙인다. 검토용 외곽은 약 14×16 월드 단위이며, 뒤쪽에 약 4단위를 더하는 안이다. 사용자 선택은 후방 확장 방식에 대한 것이며, 벽·통로·설비의 최종 치수는 미확정이다.

```text
매장 뒤쪽
┌─────────────────────────────────────────┐
│ 백룸                                    │
│ 회수·세척·건조 │ 배치 준비·추출 │ 예비 재고 │
│              직원 작업 통로             │
├── 직원 출입 ─────────────────────────────┤
│ 바: 작업용 냉장·선반·깨끗한 도구         │
│              제조 작업 통로             │
│   POS      핫 바       콜드 바     픽업   │
│ ↑ 직원 통로                             │
│ 반납·분리수거      플로어      컨디먼트  │
│                 객석                    │
└───────────────────────────── 손님 출입 ─┘
매장 앞쪽
```

개념 배치이며 축척 도면이 아니다. 왼쪽 직원 통로는 플로어·바·백룸을 연결한다. 백룸 출입구는 직원 공간으로 열리며 회수 동선 가까이에 둔다.

이동 흐름:

- 손님: 출입구 → POS → 픽업 → 컨디먼트 → 객석 → 반납 → 출입구. 포장 손님은 객석·컵 반납을 거치지 않는다.
- 주문 제조: 바의 컵·재료 → 핫 바 또는 콜드 바 → 픽업.
- 보충·준비: 백룸 재고 → 필요한 배치 준비 → 바의 알맞은 보관 위치.
- 컵·도구 회수: 플로어·바 → 직원 통로 → 백룸 세척·건조 → 바의 컵·도구 선반.

## 백룸에서 바까지 직접 보충하는 흐름

### 재고를 놓는 장소

| 장소                     | 역할                                           | 다음 이동                                 |
| ------------------------ | ---------------------------------------------- | ----------------------------------------- |
| 백룸 냉장 보관           | 냉장 원팩과 냉장이 필요한 예비 배치            | 준비 구역 또는 바 작업용 냉장고           |
| 백룸 실온 보관           | 실온 원팩, 컵·소모품 예비 재고                 | 준비 구역, 바 보관대 또는 플로어 컨디먼트 |
| 백룸 준비 구역           | 원재료 투입, 배치 제조, 라벨 작성, 장시간 추출 | 알맞은 냉장·실온 보관 위치                |
| 운반 중인 손             | 출발지에서 집어 도착지까지 옮기는 물건         | 목적지에 놓거나 출발지로 반납             |
| 바 작업용 냉장·실온 보관 | 주문 제조에 사용할 재료                        | 각 음료의 제조 단계에서 소비              |
| 바 컵·도구 보관대        | 바로 사용할 컵과 깨끗한 도구                   | 음료 제조에 사용                          |

후방에 재료가 있어도 바의 사용량이 없으면 보충 업무가 발생한다. 물건은 도착지에 내려놓아야 그곳의 사용 가능한 재고가 된다. 준비 구역에서 사용할 원재료와 바에서 음료에 사용할 재료도 사용 위치를 구분한다.

| 냅킨·빨대·설탕       | 백룸 소모품 재고 → 집기 → 플로어 컨디먼트                   | 해당 소모품 자리에 보충했을 때                  |
| 다회용 컵·피처       | 사용·회수 → 백룸 세척·건조 → 집기 → 바 컵·도구 보관대       | 씻은 용기를 제자리에 놓았을 때                  |

개봉·라벨 작성의 구체적인 장소와 콜드 브루 공급 용기를 연결하는 동작은 상세 설계 항목이다. 이 표는 이동 경로와 사용 조건을 정리한 것으로, 확인되지 않은 스타벅스 제조·보관 절차를 추가하지 않는다.

### 플레이어가 수행하는 보충

1. 바에서 부족한 품목을 확인한다. 안내는 **바에 없음 / 백룸에 있음**과 **입고 또는 준비 필요**를 구분한다.
2. 백룸의 해당 보관 위치에서 운반할 물건을 고른다.
3. 물건을 집어 직원 통로로 바까지 이동한다. 손에 든 물건과 목적지를 표시한다.
4. 품목에 맞는 냉장·실온 위치나 컵 보관대에 내려놓는다. 이때 바의 사용 가능 여부를 갱신한다.
5. 잘못된 장소이거나 공간이 부족하면 이유를 알리고 물건은 손에 남긴다. 남은 물건을 돌려놓을 때도 출발지까지 직접 운반한다.

위 조작은 기존의 E 집기·내려놓기와 한 번에 들 수 있는 물건의 제한에 맞춰 설계한다. 원팩·용기 전체 운반과 컵 묶음의 운반 단위는 구현 전에 정한다.

### 재고·기한·소비 원칙

- 재고는 **백룸에 놓인 양 / 운반 중인 양 / 바에 놓인 양**을 구분한다. 물건을 집거나 내려놓는 것은 위치 이동이며 판매·소비·폐기가 아니다.
- 운반 중인 양은 출발지와 도착지 어느 쪽에도 중복해서 세지 않는다. 보충을 중단해도 실제 놓인 위치에 따라 남은 양을 관리한다.
- 이동 중에도 개봉·제조 시각, 라벨, 잔량과 기한을 유지한다. 옮기거나 라벨을 다시 쓴 시점으로 기한을 늘리지 않는다.
- 바에서 음료를 제조할 때는 바에 보충된 사용 가능한 재료를 소비한다. 백룸 준비에서는 그 작업에 확보한 원재료를 소비한다.
- 준비 배치에 투입한 원재료는 투입할 때 차감하고, 완성 배치를 음료에 사용할 때 다시 차감하지 않는다.
- 운반 중 저장·복원할 때 물건, 잔량, 원래 보관 위치와 목적지를 이어간다.

이 원칙은 현재의 용기 운반·라벨·기한·재료 소비 규칙을 공간 구분에 맞게 연결한 설계다. 컵·소모품의 기존 수량과 입고 가격은 [임시 규칙](./prototype-rules.md)을 참조하며, 새로운 바 보관 용량이나 보충 수량을 이 문서에서 임의로 정하지 않는다.

## 기존 작업대의 배치 방향

| 현재 작업대                                       | 제안 위치와 역할                                                                                                      |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `pos`, `printer`                                  | POS 구역. 왼쪽 주문 접점과 바의 컵 준비 시작점을 연결한다.                                                            |
| `cups`, `rack`                                    | 바의 깨끗한 컵·피처·도구 보관. 세척 후 운반의 도착점이다.                                                             |
| `espresso`, `steam`                               | 바의 핫 바.                                                                                                           |
| `brew`, `water`, `ice`, `sauce`, `mix`, `topping` | 바의 콜드 제조·마무리 구역. 개별 레시피에 따라 핫 제조에서도 사용한다.                                                |
| `pickup`                                          | 바와 플로어가 만나는 전달 접점.                                                                                       |
| `prep`                                            | 배치 준비 기능은 백룸. 현재 여기에 연결된 주문 음료의 장비 작업은 바 쪽으로 구분해야 한다.                            |
| `cold-prep`                                       | 백룸의 장시간 추출 구역. 바의 서빙 탭 `brew`와 구분한다.                                                              |
| `wash`                                            | 백룸의 세척·건조 구역.                                                                                                |
| `stock`                                           | 백룸의 실온 원팩·컵·소모품 예비 재고. 사용 중인 실온 재료의 바 배치도 함께 정해야 한다.                               |
| `fridge`                                          | 현재 예비 냉장 원팩과 사용 가능한 재료를 함께 다룬다. 백룸 예비 냉장과 바 작업용 냉장으로 역할을 나누는 안이다.       |
| `shelf`                                           | 바의 준비 완료 실온 재료 선반. 백룸의 원팩·예비 보관과 구분한다.                                                      |
| `table`, `table-left`                             | 플로어의 객석.                                                                                                        |
| `condiment`                                       | 플로어에서 소모품 제공과 컵 반납의 물리적 자리를 구분한다. 현재 하나인 상호작용을 어떻게 연결할지는 구현 전에 정한다. |
| `trash`                                           | 플로어 반납 구역 옆.                                                                                                  |

## 구현 전에 함께 풀어야 할 연결

배치안을 구현할 때 필요한 범위다. 이번 조사에서는 문서만 추가했다.

1. **준비대와 주문 장비가 연결되어 있다.** [제조 작업 위치 선택](../../apps/cafe/src/features/production/workflow.ts)의 `stationFor`는 온수기를 제외한 `run-machine` 작업을 `prep`으로 보낸다. 준비대만 옮기면 주문 음료의 블렌딩 등도 백룸으로 따라간다. 주문 제조 장비와 배치 준비 장비의 사용 위치·점유 관계를 함께 정해야 한다.
2. **현재 재고의 `bar`는 물리적 방 위치와 일치하지 않는다.** [배치 위치](../../apps/cafe/src/features/inventory/batches.ts)와 [재고 행동](../../apps/cafe/src/features/inventory/actions.ts)은 라벨을 붙이거나 완성 배치를 보관하면 `location: 'bar'`로 두고 사용 가능하게 한다. 표시 장소는 재료에 따라 냉장고·실온 선반·창고다. 위 보충 흐름에 맞춰 백룸·운반 중·바의 보관 위치와 사용 가능 여부를 구분해야 한다. 현재 `cups` 행동은 후방 컵 수량을 바 수량으로 즉시 옮기므로 집기·운반·놓기 흐름이 필요하다.
3. **벽이 생기면 접근 판정이 달라진다.** [작업대 접근](../../apps/cafe/src/content/stations.ts)은 현재 고객용 대상인지와 플레이어의 z 좌표로 판단한다. [장면](../../apps/cafe/src/world/scene.ts)은 작업대 대상만 레이캐스트하므로, 새 벽 뒤의 장비를 바라보고 사용하는 경우도 막아야 한다.
4. **후방 확장에는 이동·저장 범위가 함께 걸린다.** [이동](../../apps/cafe/src/world/player-controls.ts)은 기존 외곽을 제한하고, [저장 스키마](../../apps/cafe/src/simulation/state.ts)는 z를 -6~6으로 제한한다. 기존 저장 위치가 새 벽·장비 안에 놓이는 경우의 시작 위치도 정해야 한다.
5. **장비 외형과 작업 위치를 함께 옮긴다.** 장비·용기 그래픽의 일부 좌표는 기능별 파일에 있다. `STATIONS`만 변경하면 그래픽과 상호작용이 어긋날 수 있다. 고객 경로·작업 표식·장소 이름도 최종 배치에 맞춘다.

## 상세 설계에서 정할 항목

- 벽·문·작업 통로의 실제 좌표와 폭. 14×16은 검토 치수다.
- 재료를 원팩·용기째 옮길지, 소분·덧채우기까지 다룰지와 컵 묶음의 운반 단위.
- 바 보관 용량과 보충량, 개봉·라벨 작업 위치, 콜드 브루의 공급 동작.
- 주문용 장비와 준비용 장비의 개수·점유 관계, 기존 저장을 이어갈 때의 위치 처리.

후방 확장과 직접 보충의 방향은 [게임 설계](./design.md)에 반영한다. 위 세부 사항은 구현을 시작할 때 사용자와 확인한다.
