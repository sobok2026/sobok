# 카페 화면 정보 설계

## 기준

매장을 보는 시간이 화면을 읽는 시간보다 길어야 한다. 항상 표시하는 정보는 현재 판단에 필요한 것만 남긴다. 한 행동은 한 영역에서 설명하며, 자세한 절차는 사용자가 도움말을 열었을 때 제공한다.

2026-09-25 사용자 선택에 따라 첫 플레이에서도 단계 안내를 자동으로 띄우지 않는다. 현재 행동과 키만 표시하고 H로 자세한 안내를 연다.

## 화면별 역할

| 화면        | 표시하는 정보                                                                   |
| ----------- | ------------------------------------------------------------------------------- |
| 시작        | 게임 이름, 시작·이어 하기. 도움말과 저장 관리는 보조 선택지                     |
| 플레이 상단 | 근무일·시각·영업 상태, H·M·Esc 진입점                                           |
| 현재 주문   | 접수한 주문의 번호·메뉴·온도·매장/포장. 요청과 다르면 수정에 필요한 정보만 추가 |
| 시선 대상   | 대상 이름, 지금 할 수 있는 행동, E. 대상이 없으면 숨김                          |
| 운반        | 들고 있는 물건과 목적지. 다른 일을 권하는 별도 목표 카드 없음                   |
| 작업        | 작업명, 현재 계량값·목표 구간 또는 남은 시간, 가능한 조작. 다음 행동만 강조     |
| H 도움말    | 현재 작업의 이유·선행 조건, 조작법, 현재 음료·배합 레시피, 업무 절차            |
| M 매장      | 기본 화면은 남은 할 일과 진행 중인 작업. 운영 기록은 별도 선택                  |
| Esc 메뉴    | 계속하기, 매장 현황, 도움말. 설정과 저장 관리는 접어서 제공                     |
| 결산        | 판매액·완료 주문·현금. 입고와 폐기는 실제 내역이 있을 때 펼쳐 보기              |

도움말과 매장 현황을 보는 동안 시간은 멈춘다. H 도움말을 닫으면 열기 전 화면으로 돌아간다. 작업 패널에서 도움말을 열었다면 해당 패널을 유지한다. 대화상자는 키보드 포커스를 안에 유지하고 Esc로 닫는다.

## 작업과 재고

- 계량 설명을 제목·게이지·버튼·알림에서 반복하지 않는다. 게이지는 값과 목표를, 버튼은 행동과 키를 담당한다.
- 계량 목표에 도달해도 누르고 있는 조작을 끊거나 자동 확인하지 않는다. 기존 작업 규칙과 직접 계량을 유지한다.
- 작업대 패널에는 선택할 항목과 실행 버튼을 둔다. 원재료 목록·보관 설명·자료 출처 문구를 상시 노출하지 않는다.
- 재고의 기본 목록은 품목과 사용 가능량이다. 부족·만료·라벨/보관 대기만 추가로 표시한다. 배치 날짜·보관 위치·개봉·입고·폐기는 품목을 펼쳐 확인한다.
- 제조 중 원재료 기한은 H 도움말에서 확인한다. 완성 배치의 라벨에는 실제 만료 시각과 원재료 기한 적용 여부를 표시한다.
- POS의 매장·포장은 두 선택지를 나란히 표시한다. 주문표와 컵 종류·제조 단계·리드 유무는 같은 이용 방식을 따른다.
- 컵 보관대에서 필요한 컵이 있으면 E로 집고, 부족하면 종류별 재고를 연다. 일회용 컵은 후방 재고로 보충하고 다회용 컵은 세척·보관 대기를 확인한다. 보충·입고 버튼은 해당 컵을 펼쳤을 때 표시한다.
- 세척대에는 실제로 씻거나 가져갈 용기만 표시한다. 씻은 피처는 도구 선반으로, 머그·유리잔은 컵 보관대로 운반하도록 안내한다.
- 취소·폐기처럼 별도로 선택하는 행동은 작업 관리에 둔다. 작업을 막는 문제와 그 해결 행동은 해당 작업에 표시한다.

## 제거한 정보

장르·입력 장치·로컬 저장 소개, 분위기를 설명하는 문구, 영문 장식 제목, 반복되는 조작법, 첫 두 주문 진도, 마우스 모드 설명, 상시 소리 토글, 일반 조작 성공 알림을 제거한다. 일반적인 상태 변화는 물건·계량값·버튼·주문표의 변화로 전달한다. 실패는 오류 알림으로, 저장 실패는 백업으로 이어지는 버튼으로 표시한다.

소리와 마우스 감도는 설정에, 정상 저장 상태는 저장 관리에만 표시한다. 게임 규칙·레시피·재료 기한 계산은 HUD가 결정하지 않는다.
