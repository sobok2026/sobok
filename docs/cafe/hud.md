# 카페 화면 정보 설계

## 기준

매장을 보는 시간이 화면을 읽는 시간보다 길어야 한다. 정보는 필요한 순간을 기준으로 나누고 같은 값은 한 자리에서만 보여준다. 월드가 전달하는 정보는 HUD가 반복하지 않는다. 한 순간에는 가능한 행동만 보여주고 그중 하나만 강조한다.

2026-09-26 사용자 결정으로 기존 배치 대신 아래 구조를 따른다. 단계별 튜토리얼은 자동으로 띄우지 않는다. 대신 주문 레일이 다음 할 일 한 줄을 항상 보여준다. 이 줄은 방법이 아니라 목표를 말한다.

## 목표의 단일 원천

[guidance.ts](../../apps/cafe/src/simulation/guidance.ts)의 `objective(state)`가 다음 장소·할 일·막힘을 한 번 계산한다. 주문 레일, 3D 표식, 가장자리 화살표가 이 값을 읽는다. 작업 카드의 막힘은 같은 파일의 `craftBlocker`·`preparationBlocker`를 쓴다. 해결 문장은 재료·컵 재고 도움말과 같은 함수에서 가져오므로 H 도움말과 어긋나지 않는다.

## 작업 카드

- 계량 설명을 제목·게이지·버튼·알림에서 반복하지 않는다. 제목은 단계, 값은 오른쪽, 게이지는 진행과 목표를 맡는다. 퍼센트로만 읽히는 목표는 게이지 아래에 목표를 적는다.
- 도구·재료 이름은 G 버튼이 말한다. 설정·시간·리드처럼 버튼과 게이지가 말할 수 없는 조건만 제목 아래에 적는다.
- 할 수 없는 행동은 비활성 버튼 대신 숨기고 막힌 이유와 해결 행동을 적는다.
- 목표 구간에 들어오면 게이지 색이 바뀐다. 누르고 있는 조작을 끊거나 자동 확인하지 않는다.
- F는 확인에만 쓴다. 폐기와 작업 취소는 Q를 길게 누르거나 버튼을 누르고 있어야 실행된다.

## 작업대와 재고

- 작업대 패널에는 선택할 항목과 실행 버튼을 둔다. 원재료 목록·보관 설명·자료 출처 문구를 상시 노출하지 않는다.
- 재고의 기본 목록은 품목과 사용 가능량이다. 부족·만료·라벨/보관 대기만 추가로 표시한다. 배치 날짜·보관 위치·개봉·입고·폐기는 품목을 펼쳐 확인한다.
- 제조 중 원재료 기한은 H 도움말에서 확인한다. 완성 배치의 작업 카드에는 만료 시각과 원재료 기한 적용 여부를 표시한다.
- POS의 매장·포장은 두 선택지를 나란히 표시한다. 메뉴·이용 방식에 맞는 사이즈에 용량과 가격을 표시한다.
- 컵 보관대에서 필요한 컵이 있으면 E로 집고 부족하면 종류·사이즈별 재고를 연다. 일회용 컵은 보관대에서 후방 재고로 보충하고 후방도 없으면 창고에서 입고한다.
- 세척대에는 실제로 씻거나 가져갈 용기만 표시한다. 씻은 피처는 도구 선반으로, 머그·유리잔은 컵 보관대로 운반한다.

## 대화상자

| 화면     | 표시하는 정보                                                        |
| -------- | -------------------------------------------------------------------- |
| 시작     | 게임 이름, 시작·이어 하기. 도움말과 저장 관리는 보조 선택지          |
| H 도움말 | 현재 작업의 이유·선행 조건, 조작법, 현재 음료·배합 레시피, 업무 절차 |
| M 매장   | 근무일, 남은 할 일과 진행 중인 작업. 운영 기록은 별도 선택           |
| Esc 메뉴 | 계속하기, 매장 현황, 도움말. 설정과 저장 관리는 접어서 제공          |
| 결산     | 판매액·전달 음료·현금. 입고와 폐기는 실제 내역이 있을 때 펼쳐 보기   |

도움말과 매장 현황을 보는 동안 시간은 멈춘다. H 도움말을 닫으면 열기 전 화면으로 돌아간다. 작업 패널에서 도움말을 열었다면 해당 패널을 유지한다. 대화상자는 키보드 포커스를 안에 유지하고 Esc로 닫는다. M 매장 현황의 할 일은 남은 음료부터 보여준다.

## 텍스트와 색

1080p 기준으로 행동 동사·값·메뉴명은 18px 이상, 보조 정보는 15px, 최소 14px이다. HUD에서 12px 글자를 쓰지 않는다. 온도는 HOT·ICED 글자와 색을 함께 쓰고 흰 글자의 대비는 4.5:1 이상이다.

## 제거한 정보

장르·입력 장치·로컬 저장 소개, 분위기 문구, 영문 장식 제목, 반복되는 조작법, 마우스 모드 설명, 상시 소리 토글, 일반 조작 성공 알림, 상단의 근무일·영업 중, 주문번호, 작업 카드의 작업대 이름·단계 번호·재료 줄, 하단 운반 문구를 제거한다. 일반적인 상태 변화는 물건·계량값·게이지 색·레일의 전달 표시로 전달한다. 실패는 오류 알림으로, 저장 실패는 백업으로 이어지는 버튼으로 표시한다.

소리와 마우스 감도는 설정에, 정상 저장 상태는 저장 관리에만 표시한다. 게임 규칙·레시피·재료 기한 계산은 HUD가 결정하지 않는다.

## 넓은 POS

2026-09-26부터 POS는 화면 대부분을 사용하는 전용 작업 화면이다. 왼쪽에는 손님 요청·주문서·합계, 오른쪽에는 상품·커스텀·결제를 표시한다. 결제 후 주문 레일이 결제한 모든 잔과 진행 중인 잔을 표시한다. 세부 흐름은 [POS 구현](./pos.md)을 따른다.
