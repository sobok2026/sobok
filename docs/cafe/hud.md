# 카페 화면 정보 설계

## 기준

매장을 보는 시간이 화면을 읽는 시간보다 길어야 한다. 정보는 필요한 순간을 기준으로 나누고 같은 값은 한 자리에서만 보여준다. 월드가 전달하는 정보는 HUD가 반복하지 않는다. 한 순간에는 가능한 행동만 보여주고 그중 하나만 강조한다.

모바일의 safe-area, 양손 터치 조작과 세로·가로 배치는 [모바일 화면과 조작](./mobile-controls.md)을 따른다. 상세 작업 카드·자료·POS는 작은 화면에서 내부를 스크롤할 수 있지만 상시 주문·목표·이동 조작은 스크롤하지 않는다.

2026-09-26 사용자 결정으로 단계별 튜토리얼을 자동으로 띄우지 않고 다음 목표 한 줄을 제공한다. 도움말은 플레이어가 필요할 때 연다.

2026-09-27 사용자 결정으로 컵 선택·품질 기한·보관 장소·레시피·계량선 읽기를 가르칠 지식으로 정했다. UI는 주문 스티커·기한표·시계·용기의 선을 제공하고 판단은 플레이어가 한다. 길 찾기와 조작은 교육 대상이 아니므로 바로 안내한다.

## 판단과 판정

- 주문 레일·프롬프트·도움말의 현재 목표는 컵 이름이나 정답 보관 장소를 알려주지 않는다. 원팩의 외형과 라벨에서도 보관 정답을 숨긴다.
- 레시피 원문은 도움말에서 찾아 읽는다. 작업 카드에는 양·설정의 정답 대신 손에 든 계기의 현재값만 표시한다. 실제 주문 라벨의 샷·시럽 요약은 [주문 라벨](./order-stickers.md)의 예외를 따른다.
- 판정은 행동한 자리에서 틀린 항목을 알려준다. 기한·계량 오류는 방향만 말하고 정답 수치를 쓰지 않는다. 계량 허용 폭은 [게임용 규칙](./prototype-rules.md#임시-수치와-단순화)을 따른다.
- 되돌릴 수 있는 선택은 거부하고 다시 고르게 한다. 되돌릴 수 없는 과다 투입은 다시 만들게 한다. 정상 선행 작업과 실수는 구분해 표시한다.
- 컵을 고르는 동안 재고량은 판단에 필요하지 않으므로 빈 컵만 수량을 표시한다. 맞는 컵이 없을 때 보충·세척 방법을 알려준다.
- 라벨의 개봉·제조 시각은 시계에서 옮기는 값이므로 자동으로 채운다. 기한은 직접 계산한다. 원재료 기한은 실제 용기에 붙은 판단 자료이므로 보여준다.
- 폐기·취소는 길게 누르도록 하며 확인 키 F와 공유하지 않는다.

## 계량 표현

2026-09-27 사용자는 용기 옆면 확대 대신 가로 높이 게이지를 선택했다. 게이지 끝은 용기 테두리이며 실제 눈금만 표시한다. 목표에 닿아도 색을 바꾸거나 붓기를 멈추지 않는다. 3D 용기와 게이지는 같은 내용물 높이와 눈금을 사용한다.

2026-09-28 사용자 선택으로 테두리 간격·층 두께에는 상단 30mm 확대 눈금과 시작 수위 점선을 더했다. 2026-09-29에는 작은 전체 수위 막대 아래에 `테두리까지 간격 (mm)` 눈금을 두는 배치를 선택했다. 0 눈금 아래에는 `테두리`만 적어 양 끝 설명을 반복하지 않는다.

입력은 버튼의 눌림으로, 진행은 계기와 수위 변화로 전달한다. 상시 붓기 상태·요령 문구는 두지 않고 상태 변경은 스크린 리더에 알린다. 수위에는 너비 전환 애니메이션을 쓰지 않는다. 과다 판정 후에도 단계명·마지막 계량값·수위를 남긴다.

작업 카드에 표시한 실패 문장은 알림으로 반복하지 않는다. 다른 오류 알림도 계량 눈금을 가리지 않게 둔다. 스팀 우유 붓기와 거품 올리기는 제목·동사로 구분한다.

## 작업대 패널

2026-09-27 사용자 결정으로 고를 것이 있을 때만 패널을 연다. 할 일이 하나면 바로 실행하고, 없으면 이유를 알려준다. 패널은 내용 높이만큼만 차지한다.

- 주문 목표에 해당하는 상황과 해결 행동 하나를 맨 위에 둔다. 제목과 버튼은 같은 말을 반복하지 않는다.
- 현재 주문에 필요하거나 확인할 항목만 먼저 보이고, 나머지는 검색으로 찾는다. 맨 위에 올린 항목은 목록에서 뺀다.
- 높이가 바뀌는 목록은 검색창 아래에 둔다. 검색 결과 때문에 입력 중인 검색창이 움직이지 않게 한다.
- 행은 이름·잔량·상태 하나·행동 하나로 구성하고 보조 행동은 강조하지 않는다.
- 원재료 목록·보관 설명·자료 출처는 상시 노출하지 않으며 라벨 쓰기 전에 계산된 기한을 보여주지 않는다.

## 이름

한 장소는 이름 하나로 부르고 플레이어가 월드에서 보는 물건을 따른다. 두 장소를 함께 말할 때는 문장으로 연결한다. 재고 위치는 `진열`과 `후방`으로 구분한다.

| 동사        | 뜻                                    | 쓰지 않는 표현   |
| ----------- | ------------------------------------- | ---------------- |
| 입고        | 돈을 내고 창고로 들여온다             | –                |
| 보관        | 원팩·배합을 제자리에 넣는다           | 넣기             |
| 보충        | 후방 재고를 진열 자리로 옮긴다        | 채우기           |
| 개봉        | 원팩을 연다. 기한이 시작된다          | –                |
| 라벨 쓰기   | 기한을 적는다. F 버튼만 `라벨 붙이기` | 날짜 라벨 붙이기 |
| 집기 · 놓기 | 손에 들거나 내려놓는다                | 꺼내기·가져오기  |
| 폐기        | 길게 눌러 버린다                      | –                |

## 읽기와 접근성

1080p 기준으로 행동 동사·값·메뉴명은 18px 이상, 보조 정보는 15px, 최소 14px이다. 온도는 HOT·ICED 글자와 색을 함께 쓰고 흰 글자의 대비는 4.5:1 이상이다.

상시 HUD는 스크롤하지 않는다. 전체 주문 라벨과 긴 자료는 별도 대화상자에서 읽는다. 대화상자는 키보드 포커스를 안에 유지하고, 닫을 때 원래 작업과 입력 상태를 복원한다.

일반적인 상태 변화는 물건·계기·수위로 전달한다. 소리·마우스 감도는 설정에, 정상 저장 상태는 저장 관리에 두며 저장 실패는 백업 행동으로 연결한다. 소리 없이도 결과와 오류를 구별할 수 있어야 한다.
