# 백룸 재구성과 장비

2026-09-30 사용자는 기존 백룸 구조를 유지할 필요 없이 일반적인 스타벅스의 백룸과 실제 기자재 사진을 참고해 재구성하도록 요청했다. 식기세척기 운전과 제빙·얼음 운반도 포함하며, 세척기는 **후드를 위아래로 올리고 내려 운전을 켜고 끄는 형태**라고 직접 설명했다.

## 공간

백룸은 1층 뒤쪽 `x=-5.7…9.3`, `z=-9.78…-5.94`로 묶고 기존 바의 직원 출입구와 연결했다. 실내 높이는 게임용 2.9단위다. 이는 게임의 확대된 매장 크기·모델에 맞춘 치수다.

- 출입구 가까운 벽면에 회수대 → 3조 싱크 → 후드형 세척기 → 건조대를 연결한다. 배관·배수구·프리린스 수전·약품 용기도 이 구역에 둔다.
- 튐 방지판 너머에 콜드 브루 추출대와 배치 준비대, 냉장고, 상온 재고 선반을 둔다. 준비 용기와 기존 제조 상판 위치도 함께 이동한다.
- 맞은편에는 컵·리드, 시럽·소스, 포장재, 원두·티 선반을 배치한다. 박스는 바닥에서 띄운 선반에 두며 중앙 통로를 비운다.
- 제빙기는 출입구 가까운 맞은편 벽에 두고, 전용 운반통 걸이·필터·배수구를 곁들인다. 입구 옆에는 별도 손 세정대를 둔다.
- 미끄럼 방지 타일, 세척 가능한 밝은 벽과 걸레받이, 낮은 격자 천장과 중성색 조명을 사용한다. 장비·벽·선반에 이동 충돌과 시선 차단을 적용한다.

## 세척기

후드를 올린 상태에서 회수한 용기를 랙에 담는다. 잔여물 제거와 랙 배치는 한 동작으로 단순화했다. 후드를 내리면 적재된 랙의 세척이 시작된다. 빈 랙이나 이미 세척한 랙은 다시 운전하지 않는다.

후드를 도중에 올리면 진행 작업을 취소하고 랙은 미세척 상태로 남는다. 다시 내리면 전체 주기를 처음부터 시작한다. 완료 후 후드를 올려 랙을 건조대에 꺼내고, 건조대에서 용기를 집어 피처는 바 도구 선반, 컵은 바 컵 보관대에 정리한다. 수동 세척도 사용할 수 있다.

주기는 게임 시간 120초, 랙은 16칸이며 피처는 4칸을 사용한다. 실제 AMX의 특정 프로그램·적재 수량·위생 기준을 재현한 수치가 아니다. 건조 시간, 예열, 세제 투입량, 온도 검증은 별도로 시뮬레이션하지 않는다. 게임의 조작은 실제 위생 절차를 대신하지 않는다.

## 제빙과 운반

자동 제빙을 켜면 600초마다 5.2kg을 저장고에 추가한다. 저장고 한도 380kg에서 멈추며, 가득 차서 멈춘 상태에서 얼음을 꺼내면 새 생산 주기를 시작한다. 제조사 정격을 참고한 게임용 배치 단위이며 실내 온도·급수 조건·실물의 탈빙 주기를 계산하지 않는다.

첫 근무는 저장고 40kg, 바 아이스 빈 10kg으로 시작한다. 바의 한도는 40kg, 운반통은 최대 6kg이다. 제빙기에서 담은 순간 저장고에서 빼고 운반통에 넣으며, 바에서 부은 만큼만 아이스 빈에 추가한다. 넘치는 양은 운반통에 남는다. 빈 통도 제빙기 옆에 돌려놓아야 손이 빈다. 남은 얼음은 원래 저장고에 되붓지 않고 반납 지점에서 버린다.

음료의 얼음 투입량은 기존 `stock-rules.json`의 질량·부피 환산 결과로 차감한다. 원문 레시피의 수량은 변경하지 않는다. ICED URN에 실제로 계량한 얼음도 같은 바 재고에서 차감하며 부족하면 더 넣지 못한다. 사용량·생산량·폐기량을 저장하고, 저장고·바·운반통 사이의 수량 보존을 상태 경계에서 확인한다.

세척·제빙은 기존 게임 시계를 따른다. 일시정지·비활성 탭·종료 중에는 진행하지 않고, 다음 날로 넘길 때는 제빙 저장고 한도까지 경과 시간을 정산한다. 제빙을 끄면 미완료 생산 주기를 취소한다. 제조 중인 랙과 운반통 반납은 마감 업무에 포함된다.

장비 상태·얼음 재고는 현재 저장 형식에 포함된다. 기존 정책대로 이전 저장에 새 필드를 자동 보완하지 않으므로 장비 필드가 없는 저장은 새 근무를 시작해야 한다.
