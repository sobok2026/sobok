# 장비 그래픽 참고 자료

2026-09-25 사용자 선택으로 실물 사진의 형태·재질을 참고하기 시작했다. 모델은 기존 Three.js 장면 안에서 코드로 작성한다. 2026-09-29에는 사용자 요청으로 더북한산점의 매장 인테리어·메뉴판·기자재 배치와 2층·루프탑까지 범위를 확장했다. 손님 그래픽은 별도 범위다.

## 매장 인테리어와 메뉴판

벤치마크는 **스타벅스 더북한산점**이다. 사용자는 기존 공간 크기·동선 변경과 2층·루프탑·계단 이동을 선택했다. [공식 매장 소개](https://www.shinsegaegroupnewsroom.com/starbucks-nature-healing-space-seoul/)와 [KoreaToDo의 층별 카운터·객석 사진](https://www.koreatodo.com/starbucks-the-bukhansan)을 참고했다.

| 사진에서 확인한 요소                                           | 구현                                                        |
| -------------------------------------------------------------- | ----------------------------------------------------------- |
| 가는 세로 홈의 목재 카운터, 검은 상판·걸레받이, 상판 아래 조명 | 오크 재질, 반복 목재 살, 어두운 상판, 연속된 따뜻한 조명 띠 |
| 크림색 직사각 타일 벽과 가로형 디지털 화면 3개                 | 타일 텍스처, 검은 프레임의 3연속 메뉴판                     |

메뉴판은 `RECIPES`의 판매 가능한 메뉴명과 Tall·Grande·Venti 가격을 읽는다. 왼쪽은 커피, 가운데는 게임에 판매 중인 글레이즈드 음료, 오른쪽은 티·프라푸치노를 표시한다. 사진 촬영 당시의 프로모션·푸드 광고를 현재 판매 목록으로 간주하지 않으며, 실매장의 현재 메뉴 전체를 복제한 것은 아니다. 컵 일러스트·벽면 그림·목재·타일·벽돌 텍스처는 코드로 직접 그렸다. 참고 사진을 앱 자산으로 배포하지 않는다.

공개 사진에는 실측 도면과 백룸이 없다. 공간 연결과 가구 간격은 사진에 근거한 추정이며, 실물과 동일한 치수의 복제라고 주장하지 않는다. 백룸은 기존 게임의 작업 흐름에 맞춘 구성이다. 공간 범위와 동선은 [월드 공간](./world-layout-proposal.md#층간-이동과-기자재-재배치)을 따른다.

창가 의자 방향은 층별 사진을 구분해 반영한다. 1층 가죽 의자는 정원 쪽 창을 바라보고, 2층 가죽 라운지 좌석은 낮은 테이블을 사이에 두고 서로 마주 본다. 2층 중앙은 긴 공용 테이블 두 개와 간격을 넓힌 4인 테이블 열로 구성했다. 좌석 수는 1층 49석·2층 138석·루프탑 66석을 유지한다. 계단은 불투명 벽돌 구획과 연속된 벽으로 감싸며, 가구·화분·기둥의 이동 충돌과 시선 차단을 배치에 맞춘다.

## 더북한산점 기자재 배치

2026-09-29 추가 대조에서는 [KoreaToDo의 카운터 사진](https://www.koreatodo.com/starbucks-the-bukhansan)과 [2024-06-06 방문기의 확대 가능한 카운터·푸드 사진](https://mysiseonblog2.tistory.com/67)을 함께 보았다. 사진 촬영 이후 장비 교체나 위치 변경까지 확인한 현장 조사 결과는 아니다.

전면 바 오른쪽의 반납 가구를 반영해 기존 왼쪽 독립 배치를 옮겼다. 소모품·컵 반납·분리수거 조작도 새 위치와 방향에 맞췄다.

두 머신은 `espresso`/`espresso-2`와 `steam`/`steam-2`로 조작한다. 용기를 놓은 위치에 따라 제조 안내와 작업이 해당 머신을 선택한다. 다른 머신의 조작으로 진행도를 올릴 수 없으며 가동 중인 스팀 작업은 원래 작업대에 남는다. 재료와 주문은 기존 저장소를 공유하고 한 잔씩 제조하는 규칙은 유지한다.

### 부족하거나 확인이 필요한 기자재

- **기능 미구현:** 제빙기의 얼음 생산·보충. 아이스 빈은 있으나 제빙기는 별도 모델·업무가 없다.
- **현장 미확인:** 추가 POS·블렌더 수량, 제빙기·정수/필터·식기세척기·냉동고·가열기의 기종과 위치, 실제 백룸 평면. 일반 매장의 필요 장비를 이 지점에서 확인한 기자재로 간주하지 않는다.
- **객석 기능:** 사용자 확인에 따라 전 층의 모든 테이블에 손님 이용·컵 회수·닦기를 연결했다. 긴 테이블의 구역을 포함한 93개 표면을 따로 관리하며, 컵은 계단을 이용해 1층 세척대로 운반한다.

2층의 통창·가죽 라운지 좌석·벽면 벤치, 루프탑의 목재 데크·검은 난간·회색 소파·파라솔 테이블·상호 포토존은 층별 사진을 참고했다. 2026-09-29 사용자 요청으로 입구·포토존·제품 라벨의 상표는 소복다방으로 표시한다. 북한산 배경은 능선과 암반을 코드로 만든 풍경 표현이며 실제 지형을 측량한 모델은 아니다.

### POS 화면 자료

제공된 NCR 이미지의 보라색 화면은 단말기 제품 이미지이며 스타벅스 매장의 주문 UI를 보여주는 자료가 아니다. [Starbucks POS 설계 담당자의 공개 사례](https://www.naomidavidson.com/portfolio/starbucks-point-of-sale-strategy-design-research/)는 2018년 북미 리워드 개편 내용이고, 기존 주문 UI는 작성자가 흐리게 처리했다. [공개 연습 자료의 POS 모니터 촬영 이미지](https://www.purposegames.com/game/drink-iced-decaf-shots-size)에서는 영문·달러 표시와 주문 목록·음료 옵션·하단 작업 버튼을 확인했다. 이 자료를 한국 매장 현행 UI라고 확인하지는 못했다.
