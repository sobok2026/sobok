## 위치와 작업 상태

- 에스프레소와 스팀은 사용자 확인에 따라 한 머신에 배치한다. `content/stations.ts`의 상호작용 위치와 각 작업의 접근 범위도 함께 맞췄다.
- HOT 컵은 배수 받침 위에서 직접 추출한다. 샷잔을 사용하는 제조에서는 음료 컵을 옆 카운터에 두고 샷잔만 같은 추출구 아래에 놓는다. 컵과 샷잔은 각각 카운터·받침 높이에 맞춘다.
- 스팀 피처는 머신 오른쪽 스팀 봉 아래에 둔다. 음료 컵은 피처 옆에 놓는다.
- 폼을 계량할 때 블렌더 커버를 열고 피처를 준비대에 둔다. 블렌딩 중에는 같은 피처를 기기에 올리고 커버와 뚜껑을 닫으며 3번 버튼·`BLENDING 03`을 표시한다. 완료·실패·운반 상태는 기존 준비 상태를 따른다.
- 콜드 브루 추출기는 계량할 때 작업대에 내려놓고 뚜껑을 열어 원두·물의 높이를 보여준다. 계량이 끝나면 받침 위에 올린다. 회수 용기는 배출 밸브 아래에 놓이며 라벨·운반 상태를 따른다. 이 위치 전환은 기존 작업 상태의 시각 표현이며 새 조작이나 제조 시간을 추가하지 않는다. 서빙 탭의 추출구와 음료 컵 위치도 맞춘다.

## 구현과 자원

- `features/crafting/espresso-machine.ts`: 머신 모델과 추출구·스팀 피처 위치.
- `features/preparation/blender.ts`: 블렌더·피처 모델, 커버와 표시창의 상태 반영. 준비 기능이 동일한 피처 모델을 사용한다.
- `features/cold-brew/equipment.ts`: 추출 용기와 서빙 탭. 추출 기능이 뚜껑·내용물·회수 상태를 반영한다.
- `shared/visuals/equipment-geometry.ts`: 실제로 여러 장비가 공유하는 둥근 모서리, 회전 단면, 관, 반복 부품, 조작면과 금속 재질.
- `world/scene.ts`: 실내 반사 환경을 시작할 때 한 번 생성해 장비 재질에만 적용한다. 장면 종료 시 환경 타깃과 재질의 색상·발광·거칠기·범프 텍스처를 해제한다.

금속에는 미세한 결, 플라스틱에는 투명도와 표면 반사를 적용한다. 배수 격자·통풍구·원두는 인스턴싱하고 버튼과 눈금은 작은 캔버스 텍스처로 만든다. 블렌더 표시창은 작동 여부가 바뀔 때만 갱신한다. 실시간 반사 캡처나 굴절용 추가 화면 렌더링은 사용하지 않는다. Three.js의 [RoomEnvironment](https://threejs.org/docs/pages/RoomEnvironment.html)를 반사 환경으로 사용하며 기존 동적 장면 로딩과 유휴 렌더링 정책을 유지한다.

레시피 수량·장비 시간·저장 형식은 변경하지 않는다. 기능의 `visuals.ts`가 게임 상태를 읽어 표현하며 장비 모델은 게임 상태를 수정하지 않는다.

## 1차 장비 확인

타입 검사·제조 자료 검사·프로덕션 빌드와 변경한 TypeScript 파일의 Biome 검사를 통과했다. 빌드의 장면 청크는 63.00KB(gzip 24.01KB)이며 기본 500KB 경고 없이 출력된다. 브라우저에서 기존 화면과 개선 화면, 샷잔 추출·스팀 피처 위치, 폼 계량 중 열린 커버·블렌딩 중 닫힌 커버와 표시창, 콜드 브루 계량·회수 용기의 위치를 직접 확인했다. 프로덕션 화면에서 에스프레소·스팀을 각각 바라보고 E로 해당 작업대를 여는 것도 확인했다.

Apple M2 Pro·ANGLE Metal, Headless Chrome 150, 실제 canvas 1920×1080·DPR 1에서 최종 프로덕션 빌드를 확인했다. 방향키로 계속 회전하며 초기 30프레임을 제외하고 600프레임을 측정한 requestAnimationFrame 간격은 평균 16.82ms(59.5fps), p95 16.8ms, 33.4ms 초과 0회였다. 브라우저 오류·콘솔 오류는 없었다. 다른 GPU·고배율 화면·전체 근무 시간의 성능을 보장하는 수치는 아니다. 자동 테스트나 측정 코드는 저장소에 추가하지 않았다.

### 확인 범위

그래픽 관련 11개 TypeScript 파일의 Biome 검사를 통과했다. 확인용 빌드(`scene-DTp5GIvV.js`)는 장면 청크 74.55KB(gzip 27.94KB)이며 기본 500KB 경고 없이 출력됐다. 로컬 브라우저에서 POS 주문·영수증, 정수 토출구와 Venti 유리잔, 클래식 펌프와 HOT 컵, 싱크 안의 Venti 유리잔 헹굼, 두 층 건조대와 냉장고 외형을 직접 확인했다. 프로덕션 화면의 POS 진입도 확인했다.

확인용 빌드를 Apple M2 Pro·ANGLE Metal, Headless Chrome 150, 실제 canvas 1920×1080·DPR 1에서 실행했다. 방향키 회전 중 초기 30프레임 이후 600프레임의 평균 간격은 16.67ms(60.0fps), p95 17.4ms, 33.4ms 초과 0회였다. 전체 근무·다른 기기 환경을 보장하는 결과는 아니다.

동시에 진행 중인 제조·메뉴 작업이 있으므로 이 결과는 확인용 빌드 시점의 그래픽에 대한 기록이다. 그 뒤의 공용 작업 디렉터리 전체에 대한 통합 빌드 결과로 간주하지 않는다. 자동 테스트 코드는 추가하지 않았다.

## 첨부 사진과 형태 재대조

2026-09-26 사용자가 제공한 NCR Voyix CX7·Marco MIX 3 Button·Krowne D278·True T-49-HC 비교 이미지를 기준으로 POS·정수기·아이스 빈·냉장고의 비율과 실루엣을 다시 맞췄다.

- POS는 은색 긴 기둥을 없애고 짧은 검정 연결부와 낮고 넓은 모서리 가공 받침으로 바꿨다. 프레임 두께·화면 기울기·하단 베젤도 수정했다.
- 정수기는 화면 패널·검정 전면판을 제거하고, 원형 관의 ㄱ자 굽힘과 원통 헤드 위의 버튼 3개로 만들었다. 토출구의 기존 위치를 유지하고 컵이 얇은 배수판 위에 놓이도록 높이만 맞췄다.
- 아이스 빈은 짧은 변을 가로지르는 슬라이딩 덮개, 검정 패킹, 레일, 배수구를 표현했다. 본체가 들어갈 빈 공간을 카운터 안에 두어 얕은 탁상형 상자 대신 매립형으로 배치한다. 외부 이동 충돌 범위는 기존 바를 따른다.
- 냉장고는 광택이 강한 테두리와 굽은 은색 손잡이를 제거하고 평평한 금속 문·검정 각진 손잡이·헤더의 작은 표시창·넓은 루버로 수정했다. 큰 전면 안내 스티커를 제거했다.
- 사용자가 확인한 Tall·Grande·Venti 반투명 플라스틱 스쿱 3종을 진열한다. [한국 매장의 공개 사진](https://biz.chosun.com/distribution/food/2023/01/26/QV2NKJZ2ERA6JE7Q4E3HDSHWXY/)에서 넓은 입구·얇은 벽·긴 손잡이를 참고했다. `shared/visuals/ice-scoop.ts`를 진열과 손에 드는 도구에 함께 사용하며, 그래픽 크기는 실제 g·ml 환산이나 제조량 계산에 쓰지 않는다.

### POS 화면 자료

제공된 NCR 이미지의 보라색 화면은 단말기 제품 이미지이며 스타벅스 매장의 주문 UI를 보여주는 자료가 아니다. [Starbucks POS 설계 담당자의 공개 사례](https://www.naomidavidson.com/portfolio/starbucks-point-of-sale-strategy-design-research/)는 2018년 북미 리워드 개편 내용이고, 기존 주문 UI는 작성자가 흐리게 처리했다. [공개 연습 자료의 POS 모니터 촬영 이미지](https://www.purposegames.com/game/drink-iced-decaf-shots-size)에서는 영문·달러 표시와 주문 목록·음료 옵션·하단 작업 버튼을 확인했다. 이 자료를 한국 매장 현행 UI라고 확인하지는 못했다. 사용자 선택에 따라 한국 매장 화면을 확인하기 전까지 기존 UI를 유지한다. 기기의 기존 게임용 화면을 실제 스타벅스 UI의 재현으로 표현하지 않는다.

### 이번 확인 범위

수정한 그래픽 파일 8개의 Biome 검사와 별도 장비 비교 뷰에서의 정면·사진 각도·스쿱 3종 표시를 확인했다. 비교 뷰에는 현재 장비 모델을 복사하고, 고정된 메뉴 스냅샷은 POS 텍스처 표시용으로만 사용했다. 동시에 변경 중인 제조·도움말의 조건 타입 오류가 전체 타입 검사에 남아 있어 전체 게임 통합 검증을 완료한 것으로 기록하지 않는다. 이 작업에서는 해당 제조 로직을 수정하지 않았다. 이전 절의 FPS·청크 크기는 당시 빌드의 측정값이며 이번 형태 수정 후의 재측정값이 아니다.
