# 주문 라벨

2026-09-28 사용자 요청으로 한국 스타벅스 실물 라벨을 참고했다. 기본 샷·시럽량과 음료 약어를 표시하고, 실제 코드를 확인하지 못한 메뉴는 영문 이름에서 약어를 만드는 방식을 선택했다. 전체 라벨은 상시 HUD에서 빼고 직접 열어 읽도록 정했다.

## 실물에서 가져온 구성

- 세로로 긴 흰 감열지, 작은 모서리 곡률과 상단 연두색 띠.
- 상단의 큰 주문번호와 작은 한글 음료명.
- 왼쪽의 `Decaf`·`Shots` 두 칸, 그 아래 `Syrup`·`Milk`·`Custom` 칸.
- 세로 구분선 오른쪽의 우유·샷·시럽 등 제조 요약과 아래쪽 결제 시각.
- 하단의 `i T)` 같은 온도·사이즈, 음료 코드, `1 of 2 (Bev 2)` 형태의 주문 순번과 매장·포장 표시.

실물 사진의 고객 이름·매장 정보·인증 로고는 옮기지 않는다. 게임 주문번호를 `A-01` 형태로 표기하고, 주문 채널별 번호 체계는 추가하지 않는다. 용지의 물리적 규격을 확인한 것은 아니며 사진의 비율을 참고한 게임용 표현이다.

## 표시 원칙

음료 마킹은 아래 자료에서 확인한 값을 먼저 사용한다. 나머지는 레시피 영문 ID의 첫 글자로 만든다(`black-glazed-latte` → `BGL`). **자동 생성 약어는 게임용이며 실제 매장 코드로 확인한 값이 아니다.** 약어를 확인하지 못한 재료나 복잡한 커스텀은 한글로 적는다.

레시피 양을 숨기는 교육 원칙의 예외는 **실제 주문 라벨에 인쇄하는 샷·시럽 요약**에 한정한다. 컵 종류·계량선·스팀 설정의 정답을 추가하지 않는다. 라벨을 컵에 붙이기 전에도 결제한 주문을 읽을 수 있게 하며, 부착 여부 때문에 HUD나 길 안내 위치를 바꾸지 않는다.
