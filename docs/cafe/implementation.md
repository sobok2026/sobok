# 카페 게임 구현 준비

## 착수 조건

게임의 목적, 핵심 업무, 초기 메뉴와 시간 흐름은 정해졌다. 실제 계량 용기의 형상, 일부 장비 시간, 세척 세부와 날짜 계산 관례는 추가 확인이 필요하다.

사용자에게 확인한 착수 결정:

- 기존 프로젝트 구조에 얽매이지 않고 구현에 맞는 방식을 선택한다. `apps/cafe`에 Vite + React + TypeScript + Three.js를 사용한다.
- 제공한 자료를 공개해도 된다. 원본 배합·품질 기준을 변환한 데이터를 소스와 빌드에 포함한다.
- 미확인 절차는 게임용 임시 규칙임을 문서에 표시하고 첫 플레이 버전을 구현한다.

## 저장소에서 확인한 기본값

- Bun workspaces의 `apps/*`에 독립 앱을 둔다.
- 기존 게임 앱은 `@sobok/next-config`의 정적 내보내기를 사용하지만 이 앱은 사용자 허용에 따라 Vite의 브라우저 전용 정적 빌드를 사용한다.
- React는 POS·운영 UI, Three.js는 매장·시점·상호작용을 담당한다. 프레임별 카메라 처리는 React 렌더와 분리한다.
- 원격 데이터베이스, API route, Server Action은 이 게임에 필요하지 않다.
- Cloudflare 원격 변경은 별도 배포 단계다. 이 작업에서는 로컬 구현과 빌드 확인을 진행한다.
- 로직은 먼저 앱 안의 호출부 근처에 두고, 다른 앱과 실제로 재사용할 때 공용 패키지를 검토한다.

## 구현 순서

### 1. 공간과 입력

매장, 작업대, 물체, 첫 시점, 이동·충돌·시선 상호작용을 만든다. 시작·일시정지와 작업 안내를 연결한다. 메뉴 UI와 게임 입력이 동시에 동작하지 않도록 한다.

### 2. 주문에서 전달까지

손님 요청과 POS 입력을 별도로 저장한다. 컵 준비, 단계별 제조, 재료 소비, 완성 판정, 전달, 재제조를 연결한다. 임시 규칙은 설정에 모으고 실제 기준과 구분한다.

### 3. 지원 업무

사용한 도구가 세척 대상으로 이어지고, 세척한 도구를 제자리로 돌려놓게 한다. 테이블 상태, 재고 보충, 용기별 잔량·라벨 확인을 연결한다. 지원 업무 없이 제조만 무한 반복할 수 없게 한다.

### 4. 시간과 근무 마감

게임 시계, 신규 주문 마감, 남은 주문 처리, 정리, 결산, 다음 날을 연결한다. 기한과 장시간 준비 작업은 같은 게임 시계를 기준으로 한다. 일시정지와 백그라운드 상태에서는 진행하지 않는다.

### 5. 저장과 복구

IndexedDB에 현재 상태를 저장한다. 형식 버전, 입력 검증, 저장 실패 안내, 이전 정상 저장, 파일 백업·복원을 제공한다. 저장 완료 전 페이지를 닫는 경우와 여러 탭의 동시 진행을 처리한다.

## 완료 기준

브라우저에서 들어가 이동하고, 주문 한 건을 접수·제조·전달할 수 있다. 그 과정에서 재료와 도구 상태가 바뀌고 청소·설거지·정리·보충으로 회복된다. 근무를 마감하고 다음 날 또는 저장한 상태로 이어진다.

소스의 타입 검사와 빌드, 실제 브라우저 플레이로 동작을 확인한다. 테스트 코드 작성은 이번 범위에 포함하지 않는다.

## 추후 확정할 실제 절차

컵·피처의 계량선 형상, 샷 이관, 원팩의 포장 규격, 배합 용기와 혼합 시간, 스팀 모드, 세척·건조 순서, 기한 계산 관례, 장시간 추출의 후속 처리다. 첫 플레이 버전의 단순화는 [구현 규칙](./prototype-rules.md)에 기록한다.

## 현재 파일 구조

- `apps/cafe/src/game/catalog.ts`: 작업대, 초기 메뉴와 재고 단위.
- `apps/cafe/src/game/state.ts`: 저장 형식과 검증.
- `apps/cafe/src/game/store.ts`: 주문·작업·재고·시간·마감 상태 전이.
- `apps/cafe/src/game/scene.ts`: 3D 공간, 이동·충돌, 시선 상호작용과 정리.
- `apps/cafe/src/game/storage.ts`: IndexedDB, 이전 저장본, 파일 백업.
- `apps/cafe/src/ui/App.tsx`: 시작 화면, POS, 작업 패널, HUD, 결산.
- `apps/cafe/references/`: 레시피·품질 기준·부재료 제조 가이드의 원본 엑셀 네 파일.
- `apps/cafe/scripts/import-references.mjs`: `apps/cafe/references/`의 원본 엑셀을 읽는 재생성 명령.
- `apps/cafe/src/data/references.generated.json`: 파일·시트·행 근거를 보존한 자료.

첫 구현은 로컬 빌드까지 진행했다. 운영 배포는 Vite가 생성하는 `dist`를 Cloudflare Workers Static Assets로
제공한다. GitHub Actions의 `Cafe Deploy` 또는 `Production Deploy`가 Worker를 배포하고,
`sobok-ops`의 `account-workers` HCP Terraform workspace가 `cafe.sobok.cc` custom domain을 소유한다.
스테이징은 구성하지 않는다.
