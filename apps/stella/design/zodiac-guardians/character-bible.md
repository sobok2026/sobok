# 캐릭터 바이블

## 1. 공통 아트 규격

### 형태

- 머리와 몸의 시각 비율은 약 6:4로 유지한다.
- 손발은 짧고 둥글게 만들며 손가락과 발가락은 묘사하지 않는다.
- 80px 썸네일에서도 캐릭터를 구분할 수 있도록 귀, 뿔, 꼬리, 외곽 형태를 우선한다.
- 가슴 왼쪽 또는 정중앙에 네 갈래 황금색 Stella 별표를 둔다.
- 속눈썹은 성별 표시가 아니라 표정 보조 요소로만 사용하며 한쪽 눈에 최대 한 가닥만 허용한다.

### 눈과 표정

- 눈동자는 짙은 보라색 단순 그라데이션으로 표현한다.
- 눈마다 큰 흰색 하이라이트 1개와 작은 하이라이트 1개만 사용한다.
- 눈동자 내부에 별, 은하, 다수의 반짝이 무늬를 넣지 않는다.
- 기본 표정 외에 각 캐릭터의 결함이 드러나는 대표 표정 두 개를 유지한다.
- 귀여움은 항상 완벽한 미소보다 당황, 삐침, 졸림, 모른 척, 지나친 집중 같은 반응에서 만든다.

### 카드 원화

- 기본 마스터 비율은 3:4로 제작한다.
- 캐릭터가 카드 면적의 55~65%를 차지하게 한다.
- 저장하는 카드 PNG는 일러스트가 캔버스 전체를 채우는 풀 블리드 원화다.
- 2:3 생성 중간본과 카드 밖 작업 여백은 저장하거나 배포하지 않는다.
- 이름, 설명 문구, 프레임, 제목 탭은 원화에 굽지 않고 UI와 다운로드 합성 단계에서 렌더링한다.
- Stella 등급의 실제 출생 차트 선과 개인 색은 별도 오버레이로 합성하며, 마스터 원화에는 개인화가 없어도 장면이 완결되는 비개인화 광륜 언더레이를 둔다.
- 원화 레이어는 배경, 캐릭터, 중심 소품, 전경, 별자리 효과로 분리한다.
- 1080×1440 소장 카드와 1080×1920 공유 카드가 모두 나오도록 중심부 안전 영역을 유지한다.

## 2. 캐릭터 기본 설정

내부 ID는 별자리 영문 소문자로 고정한다. 아래 한국어 호칭은 장면과 대사를 설계하기 위한 내부 호칭이며 공개 이름이 아니다.

공개 작업명은 한 값을 모든 언어에 공유하지 않고 `ko`, `zh`, `ja`, `en`별로 관리한다. 한 로케일의 이름을 다른 로케일에 자동 음차하지 않는다. 캐릭터의 핵심 인상은 유지하되 각 언어권에서 애칭처럼 자연스럽게 들리는 별도 이름을 사용한다.

```ts
type ZodiacGuardianPublicName = {
  ko: string
  zh: string
  ja: string
  en: string
}
```

`zh`는 중국 시장용 간체자로 작성한다. 분석, 컬렉션, 댓글 데이터는 공개 이름이 아니라 고정 ID로 연결하며 로케일이 바뀔 때 표시 이름만 바꾼다.

### 이름 설계 규칙

- 한국어는 부르기 쉬운 두세 음절과 `-이`형 애칭을 우선한다.
- 중국어는 간체자 두세 글자, 중첩어, 짧은 합성어를 우선한다.
- 일본어는 히라가나로 쓰고 의태어와 말놀이의 리듬을 살린다.
- 영어는 한두 단어의 짧은 상품형 이름을 사용하며 쌍 캐릭터는 `&`로 연결한다.
- 이름을 번역해 맞추기보다 각 로케일에서 느끼는 귀여움과 성격의 인상을 맞춘다.
- 공개 이름은 모든 화면에서 줄바꿈 없이 한 줄로 표시한다.
- 공개 전 사용자 조사에서 발음 기억률, 철자 회상률, 캐릭터 매칭률을 비교할 수 있도록 이름과 ID를 분리한다.

## 4. 관계 설계

관계는 연애 궁합의 정답이 아니라 카드 장면을 만드는 이야기 화학으로 사용한다. 같은 조합도 우정, 협업, 긴장, 연애로 해석할 수 있어야 한다.

| 조합             | 대표 관계                              | 반복 장면                               |
| ---------------- | -------------------------------------- | --------------------------------------- |
| 포피 ↔ 모루      | 다가가는 쪽과 문 뒤에서 기다리는 쪽    | 하트 배달, 첫 인사, 용기 내어 문 열기   |
| 포피 ↔ 틸리      | 먼저 행동하는 쪽과 끝까지 비교하는 쪽  | 두 개의 문, 여행 출발, 메뉴 고르기      |
| 루모 ↔ 틸리      | 무대의 주인공과 균형을 잡는 연출자     | 의상, 공연, 칭찬과 피드백               |
| 루모 ↔ 코로      | 박수받는 결과와 보이지 않는 노력       | 정상, 트로피, 연습실의 밤               |
| 로로 ↔ 코로      | 빠른 출발과 꾸준한 완주                | 여행, 등반, 길을 잃은 뒤 귀환           |
| 토토 ↔ 누리      | 만드는 쪽과 정리하는 쪽                | 별빵 작업실, 화분, 무너지는 탑          |
| 토토 ↔ 아와      | 익숙한 편안함과 엉뚱한 실험            | 새로운 레시피, 쏟아진 물감, 실패작 시식 |
| 미미·무무 ↔ 아와 | 끝없는 말과 끝없는 아이디어            | 발명, 파티, 밤샘 대화                   |
| 미미·무무 ↔ 수미 | 모든 것을 말하는 쪽과 마음을 숨기는 쪽 | 비밀 편지, 오해, 침묵 지켜주기          |
| 모루 ↔ 수미      | 포근한 보호와 단단한 충성              | 비 오는 날, 담요, 문 앞 지키기          |
| 누리 ↔ 피오·피우 | 계획과 꿈의 충돌                       | 일정표, 낮잠, 상상한 정원 만들기        |
| 수미 ↔ 피오·피우 | 깊게 감추는 마음과 흘러나오는 마음     | 심해, 꿈, 놓지 않는 리본                |

## 5. 캐릭터 사용 금지선

- 별자리 기호만 바꾼 동일 몸체 복제
- 성격과 관계가 없는 정면 포즈 카드의 반복
- 희귀도를 눈 반짝이 수와 금색 테두리만으로 표현
- 특정 캐릭터만 항상 긍정적이고 다른 캐릭터는 항상 부정적으로 표현
- 체형, 속눈썹, 색상으로 캐릭터 성별을 고정
- 한 장면에 중심 캐릭터 셋 이상 배치
- 어린이 교육물처럼 별자리 이름을 원화 안에 직접 표기
