# 네 주제 대표 카드

12별자리 설정 시트를 실제 카드 장면으로 확장할 수 있는지 검증하는 첫 대표 세트다.

## 상태

- 자기이해, 사랑, 일, 결정 각 1장: 확정 콘셉트
- 생성일: 2026-07-30
- 생성 방식: 내장 이미지 생성 도구
- 최종 마스터: 1080×1440, 3:4, RGB PNG
- 출력 형태: 풀 블리드 일러스트 · 카드 밖 여백 없음
- 2:3 중간본: 최종 자산으로 유지하지 않음
- 앱 런타임 적용: 아직 하지 않음

내장 이미지 생성 도구의 1024×1536 중간 결과에서 프레임과 빈 제목 탭을 제외한 3:4 일러스트 영역을 추출하고 균등 리샘플링했다. 최종 PNG는 일러스트 자체가 캔버스 전체를 채우므로 별도의 수작업 크롭이 필요 없다. 이름, 제목, 프레임은 UI와 다운로드 합성 단계에서 올린다.

## 공통 생성 프롬프트

- 확정 설정 시트를 캐릭터 외형 기준 이미지로 사용한다.
- 프리미엄 봉제 캐릭터 상품처럼 폭신하고 둥근 실루엣을 유지한다.
- 색연필과 수채화가 섞인 미세한 종이 질감으로 표현한다.
- 최종 3:4 크롭 안에 캐릭터와 중심 사건이 모두 들어오도록 안전영역을 유지한다.
- 눈은 짙은 보라색 단순 그라데이션으로 그리고 큰 흰 하이라이트 1개와 작은 흰 하이라이트 1개만 허용한다.
- 캐릭터, 중심 소품, 중심 감정이 한눈에 읽히게 한다.
- 원화 안에 이름, 문구, 숫자, 별자리 기호, 로고, 워터마크를 넣지 않는다.

## 카드별 프롬프트 핵심

- `cancer.self`: 보호받는 달집 안, 찻잔만 한 우주 연못, 실제 캐릭터는 한 명, 수면 속 얼굴은 반사로만 표현한다.
- `aries.love`: 몸보다 큰 하트가 초승달 우체통에 걸리고 포피와 모루가 양쪽에서 잡으며 눈이 마주친다.
- `taurus.work`: 앞치마를 입은 토토가 지나치게 높은 별쿠키 탑에 하나를 더 올리고, 누리는 떨어지는 쿠키 하나를 바구니로 받는다.
- `libra.choice`: 분홍 별 문과 파란 초승달 문 사이에서 저울과 비교 카드를 내려놓고, 틸리의 손과 가슴 별빛이 선택한 분홍 손잡이를 향한다.

## 3:4 마스터 재구성

- 내장 도구의 1024×1536 결과는 제작 중간본으로만 사용한다.
- 중간본에서 왼쪽 32px, 위쪽 80px 지점부터 960×1280 영역을 추출한다.
- 추출 영역은 정확히 3:4이며 프레임, 빈 제목 탭, 카드 밖 남색 작업 여백을 포함하지 않는다.
- 추출 결과를 균등하게 1080×1440으로 리샘플링한다.
- 가로와 세로를 서로 다른 비율로 늘이지 않는다.
- 최종 PNG만 repo에 저장하고 2:3 중간본은 런타임 자산으로 유지하지 않는다.
