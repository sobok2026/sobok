# 네 주제 대표 카드

12별자리 설정 시트를 실제 카드 장면으로 확장할 수 있는지 검증하는 첫 대표 세트다.

## 상태

- 자기이해, 사랑, 일, 결정 각 1장: 확정 콘셉트
- `aries.love` 희귀도 4종: 확정 원화
- 생성일: 2026-07-30
- 생성 방식: 내장 이미지 생성 도구
- 최종 마스터: 1080×1440, 3:4, RGB PNG
- 출력 형태: 풀 블리드 일러스트 · 카드 밖 여백 없음
- 2:3 중간본: 최종 자산으로 유지하지 않음
- 앱 런타임 적용: `/[locale]/cards` 프로토타입에 WebP로 적용

초기 대표 카드는 내장 이미지 생성 도구의 1024×1536 중간 결과에서 3:4 일러스트 영역을 추출했고, `aries.love` 희귀도 확장본은 도구가 생성한 1086×1448 원화 전체를 사용했다. 두 경우 모두 최종 결과를 1080×1440으로 균등 리샘플링했다. 최종 PNG는 일러스트 자체가 캔버스 전체를 채우므로 별도의 수작업 크롭이 필요 없다. 이름, 제목, 프레임은 UI와 다운로드 합성 단계에서 올린다.

앱에서는 같은 1080×1440 비율의 WebP를 사용한다. 카드 뒤의 어두운 남색 면, 희귀도 테두리,
이름, 제목, 배지는 모두 UI에서 표현하므로 원화에 합치지 않는다.

### Stella 개인화

- 마스터 원화의 차트 광륜은 위치, 밀도, 광량을 확인하고 비개인화 상태에서도 장면을 완결하는 기본 언더레이다.
- 실제 출생 차트 선과 개인 색은 UI 및 다운로드 합성 단계에서 사용자별로 그 위에 렌더링한다.
- 차트 합성 영역은 상단 중앙에 두며 캐릭터 얼굴, 뿔, 달집, 열린 하트를 가리지 않는다.
- 개인화가 실패하거나 공유 이미지가 축소되더라도 열린 하트와 두 캐릭터만으로 장면의 완결이 읽혀야 한다.

## 공통 생성 프롬프트

- 확정 설정 시트를 캐릭터 외형 기준 이미지로 사용한다.
- 프리미엄 봉제 캐릭터 상품처럼 폭신하고 둥근 실루엣을 유지한다.
- 색연필과 수채화가 섞인 미세한 종이 질감으로 표현한다.
- 최종 3:4 크롭 안에 캐릭터와 중심 사건이 모두 들어오도록 안전영역을 유지한다.
- 눈은 짙은 보라색 단순 그라데이션으로 그리고 큰 흰 하이라이트 1개와 작은 흰 하이라이트 1개만 허용한다.
- 캐릭터, 중심 소품, 중심 감정이 한눈에 읽히게 한다.
- 원화 안에 이름, 문구, 숫자, 별자리 기호, 로고, 워터마크를 넣지 않는다.

## 카드별 프롬프트 핵심

- `cancer.self`: 보호받는 달집 안, 찻잔만 한 우주 연못, 실제 캐릭터는 한 명, 수면 속 얼굴은 반사로만 표현한다.
- `aries.love`: 몸보다 큰 하트가 초승달 우체통에 걸리고 포피와 모루가 양쪽에서 잡으며 눈이 마주친다.
- `taurus.work`: 앞치마를 입은 토토가 지나치게 높은 별쿠키 탑에 하나를 더 올리고, 누리는 떨어지는 쿠키 하나를 바구니로 받는다.
- `libra.choice`: 분홍 별 문과 파란 초승달 문 사이에서 저울과 비교 카드를 내려놓고, 틸리의 손과 가슴 별빛이 선택한 분홍 손잡이를 향한다.

## 3:4 마스터 정규화

- 초기 대표 카드의 1024×1536 결과는 제작 중간본으로만 사용한다.
- 초기 중간본에서는 왼쪽 32px, 위쪽 80px 지점부터 960×1280 영역을 추출한다.
- `aries.love` Orbit·Nebula·Stella는 정확한 3:4인 1086×1448 생성본 전체를 사용한다.
- 3:4 원화는 자르지 않고 균등하게 1080×1440으로 리샘플링한다.
- 가로와 세로를 서로 다른 비율로 늘이지 않는다.
- 최종 PNG만 repo에 저장하고 2:3 중간본은 런타임 자산으로 유지하지 않는다.
