# Guardian card catalog

## 런타임 범위

현재 일일 수호령 런타임은 승인된 전체 카탈로그를 사용한다.

| 테마     | 패밀리 | 패밀리당 에디션 | 합계      |
| -------- | ------ | --------------- | --------- |
| 자기이해 | 12     | 16              | 192       |
| 사랑     | 12     | 40              | 480       |
| 일       | 12     | 16              | 192       |
| 결정     | 12     | 16              | 192       |
| **전체** | **48** | —               | **1,056** |

자기이해·일·결정은 각 목소리별 후보가 패밀리당 4장이다. 사랑의 10개 관계 테마는 `comfort` 3개,
`honesty` 3개, `action` 2개, `possibility` 2개로 연결한다. 각 관계 테마 안의 그림 결은 Orbit 55%,
Nebula 30%, Eclipse 12%, Stella 3% 가중치를 사용한다. 이 가중치는 해석 분량이나 이용권 가치의 차이가
아니며, 별도의 유료 재추첨은 제공하지 않는다.

`worker/guardian/runtime-catalog.generated.json`은 48개 패밀리와 1,056개 에디션을 일일 런타임에 필요한
테마, 맥락, 목소리, 그림 가중치, R2 객체 키와 노출 문구로 정규화한다.

## 불변성

- 에디션 ID는 의미가 같은 원화 교정에서는 유지한다.
- 의미나 문구가 달라지면 새 에디션 ID를 만든다.
- 공개 원화는 콘텐츠 주소형 R2 객체 키를 사용하며 기존 바이트를 덮어쓰지 않는다.
- 이용자가 본 카드는 테마·목소리·그림 버전, 에디션 ID, 객체 키, 제목, 접근성 문구, 한 줄, 행동,
  회고 질문을 DB에 스냅샷한다.
- 라이브 카탈로그가 바뀌어도 이미 본 카드의 내용과 원화 경로는 바뀌지 않는다.

## 배포 책임

- R2 bucket과 custom domain lifecycle은 `../sobok-ops` Terraform이 소유한다.
- 원화 객체 배포는 `.github/workflows/guardian-card-art-deploy.yml`만 수행한다.
- 앱 Worker는 `STELLA_GUARDIAN_ASSET_ORIGIN` binding으로 콘텐츠 주소형 URL을 만든다.
- Cloudflare Dashboard는 조회 전용으로 사용한다.
