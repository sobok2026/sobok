# 카드 카탈로그

## 1. 리포트 기본 구조

한 번의 유료 리포트는 다섯 장으로 구성한다.

| 순서 | 슬롯        | 기본 연결                       | 역할                                    |
| ---- | ----------- | ------------------------------- | --------------------------------------- |
| 1    | 자기이해    | 태양, 달, 상승궁                | 사용자가 “내 카드”라고 느끼는 확정 앵커 |
| 2    | 사랑        | 금성, 7하우스, 사랑 질문        | 관계에서 반복하는 행동                  |
| 3    | 일          | 중천점, 토성, 10하우스, 일 질문 | 결과를 만드는 방식과 막힘               |
| 4    | 결정        | 수성, 화성, 결정 질문           | 현재 선택에서 필요한 행동               |
| 5    | 숨은 동행자 | 달, 현재 하늘, 답변 가중치      | 예상 밖이지만 설명 가능한 확률형 카드   |

### 추첨 원칙

- 자기이해 카드에는 사용자의 태양 별자리 캐릭터를 반드시 포함한다.
- 사랑, 일, 결정은 관련 천체의 별자리와 질문 답변으로 유효 후보군을 먼저 만든 뒤 그 안에서 추첨한다.
- 무작위성은 카드의 관련성이 아니라 유효한 해석 중 어떤 장면이 나타나는지를 결정한다.
- 같은 리포트 안에서는 동일한 카드 ID가 중복되지 않는다.
- 희귀도와 해석의 긍정성, 중요도, 정확도를 연결하지 않는다.
- 다섯 장을 모두 공개하면 각 카드가 하나의 이야기로 연결되는 전체 요약을 제공한다.

## 2. 질문 답변이 바꾸는 축

짧은 질문은 카드 자체를 정답처럼 결정하지 않고 후보 가중치와 장면 변형에 사용한다.

| 축                | 선택 예시                            | 카드에 미치는 영향             |
| ----------------- | ------------------------------------ | ------------------------------ |
| 지금 가장 큰 관심 | 사랑, 일, 나, 결정                   | 숨은 동행자와 전체 요약의 중심 |
| 현재의 움직임     | 시작, 유지, 회복, 놓아주기           | 캐릭터의 행동                  |
| 관계 방향         | 혼자, 함께, 거리를 두기, 다시 만나기 | 보조 캐릭터와 거리             |
| 원하는 답의 온도  | 위로, 솔직함, 행동, 가능성           | 표정, 대사, 해석 문체          |

## 4. 희귀도별 아트 확장

희귀도는 같은 카드 ID의 다른 그림 버전이다. 새 프레임만 씌워 별도 카드처럼 취급하지 않는다.
