# 모바일 카드 리포트 프로토타입

확정한 별자리 수호령 원화를 실제 모바일 참여 흐름에 넣어 보는 첫 프로토타입이다.

## 범위

- 경로: `/[locale]/cards`
- 지원 로케일: `ko`, `zh`, `ja`, `en`
- 공개 상태: 전역 내비게이션과 사이트맵에는 넣지 않고 `noindex`로 유지
- 화면 기준: 모바일 우선, 카드 원화는 3:4만 사용
- 데이터 상태: 결제, 계정, 서버 컬렉션과 연결하지 않은 프런트엔드 검증 화면

## 사용자 흐름

1. 지금 필요한 감정과 마음의 방향을 한 번씩 고른다.
2. 봉인된 카드 팩을 연다.
3. 자기이해, 사랑, 일, 결정 카드를 한 장씩 뒤집는다.
4. 네 카드가 연결된 리포트를 순서대로 읽는다.
5. 완독 진행률이 `4 / 4`가 되면 완독 문구가 열린다.
6. 사랑 카드를 컬렉션에 담거나 결과를 공유한다.
7. 같은 카드를 받은 사용자의 댓글 화면으로 이동하거나 내일의 흐름으로 이어간다.

질문의 답은 현재 프런트엔드 프로토타입의 카드 선택 결과를 바꾸지 않는다. 이 고정 결과는 화면과
상호작용을 검증하기 위한 샘플일 뿐 유료 출시 상품이나 유료 질문지의 규칙이 아니다.

한국 유료 출시에서는 현재 두 질문을 무료 미리보기용으로 유지한다. 결제 전에는 유료 질문의
분량과 예상 소요시간만 안내하고, 서버가 결제를 확인한 뒤 주제별 유료 질문을 제공한다. 전체
답변이 끝나면 네 슬롯의 기본 카드 패밀리를 선택하고 사랑 슬롯의 희귀도를 추첨한다.

## 카드 구성

| 순서 | 주제     | 카드 ID        | 프로토타입 희귀도 |
| ---- | -------- | -------------- | ----------------- |
| 1    | 자기이해 | `cancer.self`  | 고정              |
| 2    | 사랑     | `aries.love`   | 4종 중 1종        |
| 3    | 일       | `taurus.work`  | 고정              |
| 4    | 결정     | `libra.choice` | 고정              |

`aries.love`는 Orbit, Nebula, Eclipse, Stella 네 장면을 사용한다. 프로토타입에서는 네 장면을
같은 비율로 샘플링해 모든 상태를 빠르게 검증한다. 이 값은 실제 유료 상품의 확률이 아니다.

실제 유료 상품에서는 첫 구매가 네 주제 전체 리포트이고 이후에는 사랑 카드만 재추첨한다.
유료 MVP도 위의 4개 패밀리·7개 에디션으로 시작하며, 결제 후 16~20개 선택 답변은 네 주제 상세
리포트 본문과 한 줄을 실질적으로 바꾼다. 자유 입력은 필수가 아니며 전체에서 선택 사항으로 최대
한 개만 제공한다.
재추첨은 일러스트와 카드의 한 줄만 바꾸며 사랑 해석 본문과 나머지 세 카드는 바꾸지 않는다.
가격, 실제 확률, 미보유 보장, 계정과 결제의 현재 권장안은
[유료 카드 리포트 MVP와 확장 전략](./paid-mvp-product-strategy.md)에 정리한다. 한국 첫 유료
연결은 [한국 전체 리포트 결제·공개 수직 슬라이스](./korea-paid-report-vertical-slice.md)를 따른다.

## 표현 원칙

- 3:4 풀 블리드 원화는 그대로 두고 카드 뒷면, 프레임, 배지, 이름, 제목을 UI에서 겹친다.
- 카드 뒤의 어두운 남색은 앱 인터랙션을 위한 UI이며 다운로드 원화에 포함하지 않는다.
- 공개 이름과 카드 제목은 모든 로케일에서 한 줄로 제한한다.
- 희귀도는 색상 배지만으로 구분하지 않고 원화의 사건과 관계 변화로 구분한다.
- 카드 공개는 3D 뒤집기 모션을 사용하되 `prefers-reduced-motion`을 존중한다.

## 프로토타입 상태 저장과 공유

- 컬렉션 저장: 브라우저 `localStorage`의 버전 키 `stella.guardianCards.v1`
- 저장 값: `aries.love:{rarity}`
- 공유 링크: `/{locale}/cards?rarity={rarity}`
- 댓글 주제: `card-aries-love`

공유 링크로 진입하면 같은 희귀도의 리포트를 바로 연다. 실제 상품에서는 구매 내역과 컬렉션을
서버 계정에 귀속하고, 공유용 이미지 합성 및 공개 범위를 별도로 연결해야 한다.

## 측정 이벤트

| 이벤트                     | 의미                         |
| -------------------------- | ---------------------------- |
| `guardian_pack_start`      | 질문을 마치고 카드 팩을 엶   |
| `guardian_card_reveal`     | 카드 한 장을 공개함          |
| `guardian_report_start`    | 리포트 읽기를 시작함         |
| `guardian_section_view`    | 주제별 리포트 섹션을 읽음    |
| `guardian_report_complete` | 네 섹션을 모두 읽음          |
| `guardian_collection_save` | 사랑 카드를 컬렉션에 저장함  |
| `guardian_result_share`    | 결과 공유를 실행함           |
| `guardian_comment_open`    | 카드 전용 댓글 화면으로 이동 |

## 구현 전 남은 결정

- 유료 개인화 질문의 실제 문구·선택지·분기와 장기 문항은행의 제작 범위
- 출생 차트와 무료·유료 질문 응답이 상세 본문과 production 카드 후보를 바꾸는 구체적인 점수 규칙
- 토스페이 live channel key
- Stella 전용 계정의 로그인 제공자와 게스트 컬렉션 귀속 흐름
- 중국 본토의 로그인 제공자, 표시 가격, KICC 청구 통화
- 공유 이미지에 포함할 카드, 개인화 차트, 문구의 범위
