# Stella Zodiac Guardians

Stella의 오늘·내일 운세에서 사용하는 수호령 카드 시스템의 디자인 원본이다.

## 현재 제품

- 오늘의 수호령 카드 한 장은 무료로 전부 공개한다.
- 내일의 수호령 카드는 `guardian-tomorrow-pass-7d-v1` 이용자에게 하루 먼저 공개한다.
- 7일권은 1,900원 일회 결제이며 자동 갱신되지 않는다.
- 권한은 결제 승인 시각부터 정확히 168시간 유지한다.
- 사용자에게 보이는 오늘·내일과 카드 교체는 현지 자정을 기준으로 한다.
- 결제와 권한 시각은 UTC 절대 시각으로 저장하고 화면과 이메일에서 현지 시각으로 표시한다.
- 이전 전체 리포트와 사랑 카드 재추첨 상품은 운영하지 않는다. 기존 SKU를 새 상품에 재사용하지 않는다.

## 카드 선택

- 일일 제품은 자기이해·사랑·일·결정 48개 별자리 패밀리와 1,056개 에디션을 모두 사용한다.
- 출생 차트가 있으면 태양 별자리, 없으면 해당 날짜의 달 별자리가 패밀리를 정한다.
- 네 테마는 브라우저 또는 컬렉션 seed로 정한 사용자별 순서에 따라 날마다 바뀌며 나흘 동안 한 번씩 나타난다.
- 무료 오늘 카드는 그날 테마 안에서 결정적으로 한 장을 선택한다.
- 내일 화면은 결제 전에 테마를 먼저 공개하고, 이용자가 고른 `comfort`, `honesty`, `action`, `possibility`
  목소리 안에서 한 장을 선택한다.
- 사랑 카드는 10개 관계 테마를 네 목소리에 연결하고 기존 그림 가중치를 유지한다.
- 내일 미리 본 카드는 다음 날에도 같은 스냅샷으로 유지한다.
- 카드가 처음 공개되면 고정되며 테마·목소리 변경이나 추가 결제로 재추첨할 수 없다.

## 소유권과 복구

- 첫 구매는 로그인 없이 가능하다.
- 원본 브라우저 식별자는 저장하지 않고 SHA-256 digest만 컬렉션의 안정적인 선택 seed로 보관한다.
- 게스트는 capability로 카드와 이용권에 접근하며 구매 이메일로 일회용 복구 링크를 받을 수 있다.
- 소복 계정에 보관하면 같은 컬렉션의 소유자만 바뀌고 게스트 capability는 폐기한다.
- 이용권 중 본 카드는 서버에 immutable snapshot으로 보관한다.
- 게스트 보관함 복구 기간은 결제일부터 1년이다. 계정에 귀속한 카드는 삭제 요청 또는 계정 삭제까지 보관한다.
