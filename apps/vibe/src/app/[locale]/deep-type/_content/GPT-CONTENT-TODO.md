# DeepType 콘텐츠 작성 요청 (GPT용)

문항 구조가 **축당 4문항 · 정방향 2 / 역문항 2 (2F/2R) 균형 키잉**으로 바뀌었습니다.
코드·채점·스캐폴딩은 모두 완료됐고, **한국어/영어/일본어/중국어 문항 텍스트만** 채우면 됩니다.

작업은 두 가지입니다.

- **Part A** — 신규 역문항 18개(로케일당)의 프롬프트 + 선택지 4개 작성
- **Part B** — 바뀐 문항 수를 참조하는 안내 문구 숫자 수정

기존 문항은 그대로 재사용되고 있으니 건드리지 않아도 됩니다(원하면 다듬어도 되지만 아래 **선택지 순서 규칙**은 반드시 지킬 것).

---

## ⚠️ 선택지 순서 규칙 (가장 중요 — 어기면 채점이 반대로 됨)

각 문항의 선택지 4개는 **한 극 → 반대 극으로 이어지는 순서형 척도**입니다. 위치(1→4)가 곧 점수(value 1→4)이고, 채점은 선택지의 **위치**만 사용합니다(프롬프트 문장은 채점에 영향 없음, 맥락 제공용).

신규 18개는 **전부 역문항(reverse)** 입니다. 역문항의 선택지는 다음 순서로 씁니다:

| 위치  | value | 의미                 |
| ----- | ----- | -------------------- |
| 선택1 | 1     | **first 극** 강하게  |
| 선택2 | 2     | first 극 약하게      |
| 선택3 | 3     | second 극 약하게     |
| 선택4 | 4     | **second 극** 강하게 |

**실제 예시 (기존 역문항 `persona-ei-2`, 축 EI = E 외부교류 ↔ I 내적회복):**

```
프롬프트: 사람들과 시간을 보낸 뒤에는 혼자 있어야 에너지가 돌아오는 편이다.
선택1: 사람들과 더 어울려야 기운이 난다       ← E(first) 강
선택2: 교류의 여운을 즐기며 바로 다른 일을 한다  ← E 약
선택3: 잠깐 혼자 쉬면 기운이 돌아온다          ← I 약
선택4: 충분히 혼자 있어야 비로소 회복된다        ← I(second) 강
```

> 팁: 각 신규 문항과 **같은 축의 기존 형제 문항 3개**(예: `persona-ei-1/2/3`)를 먼저 읽고, 어투·문장 길이·선택지 결을 맞춰 4번째를 쓰세요. 선택지 4개는 서로 **완전히 다른 문장**이어야 합니다(중복 금지).

---

## Part A. 신규 역문항 18개

각 항목은 **로케일 4개 파일 모두** 작성해야 합니다.

- 프롬프트 → `question-prompts/{ko,en,ja,zh}.ts`
- 선택지 4개 → `question-options/{ko,en,ja,zh}.ts`

찾는 법: 각 파일에서 `TODO <id>` 로 검색하면 placeholder가 나옵니다(극 힌트 포함). 그 자리를 실제 문장으로 교체하세요. 배열 위치는 이미 맞춰져 있으니 **순서를 바꾸지 마세요**.

극(pole) 라벨은 각 로케일의 `content.axes[축]` 을 따르세요(아래는 한국어 기준 참고값).

### persona 계층 — 맥락: “사람들 앞 / 역할을 수행할 때”

| -------------- | ---------------- | ------------------ | ------------------- |
| `persona-ei-4` | EI 사회적 에너지 | E 외부 교류        | I 내적 회복         |
| `persona-sn-4` | SN 정보 초점     | S 구체·근거        | N 가능성·패턴       |

## Part B. 문항 수 참조 문구 수정

문항 수가 바뀌어 안내 문구의 숫자가 어긋났습니다. **4개 로케일 콘텐츠 파일(`ko.ts`/`en.ts`/`ja.ts`/`zh.ts`)** 에서 아래를 수정하세요.

| 항목                     | 위치(키)                                                                       | 기존        | 변경                           |
| ------------------------ | ------------------------------------------------------------------------------ | ----------- | ------------------------------ |
| 무료 문항 수             | `ui.analyzingBody`, `methodology.scoringBody`                                  | 50          | **56**                         |
| 보석(gem) 문항 수        | `ui.gemIntroBody`                                                              | 20          | **16**                         |
| 심화(refinement) 문항 수 | `paywall.effortNote`, `paywall.refinementIntroBody`, `methodology.scoringBody` | 24          | **32**                         |
| 소요 시간(무료)          | `ui.landingNote` (`약 7분`)                                                    | 50문항 기준 | 56문항 기준으로 재추정(≈8분)   |
| 소요 시간(심화)          | `paywall.effortNote` (`약 3~4분`)                                              | 24문항 기준 | 32문항 기준으로 재추정(≈4~5분) |

**바꾸지 말 것(그대로 유효):** `4,096` / `16×16×16` 유형 수, “8가지 핵심 축 / eight dimensions”, “다섯 축 / five axes”, “역문항 / reverse-keyed” 설명.
